# 법령 도구 연결 — 말로 부탁하면 됩니다

> **이 문서는 언제 보나**: 루트 `설치프롬프트.md`로 JARVIS 설치를 마친 뒤, 선택적으로 법령 검색 도구를 연결할 때 봅니다.
> **아래는 «Codex 앱» 기준입니다.** 다른 앱을 쓰셔도 원리는 같습니다(앱에 도구 하나 등록) — 메뉴 이름만 다릅니다. ChatGPT 채팅창에서 쓰는 법은 맨 뒤에 따로 적어 두었습니다.
> **무엇을 하나**: AI가 법령·판례·행정규칙을 법제처 원문에서 **직접 조회**하게 만듭니다.
> **소요**: 인증키 발급 1분 + 부탁 한 문장 + 앱 재시작 = 약 5분. **설정 파일을 직접 만지지 않습니다.**

---

## §1. 왜 연결하나 — AI는 이미 정확합니다

먼저 사실부터. **조문 하나 물어보는 정도는 요즘 AI가 도구 없이도 정확하게 답합니다.** 웹 ChatGPT·Claude·Codex 세 곳 모두 「행정사법 제2조」를 물으면 원문과 공포·시행일까지 맞게 내놓고, 법제처 출처 링크를 붙여 주는 곳도 있습니다(2026-07-30 실측). «도구가 없으면 AI가 틀린다»는 이 문서의 전제가 **아닙니다.**

그런데도 연결하는 이유는, 세 가지가 **더해지기** 때문입니다.

| 더해지는 것 | 무슨 뜻인가 |
|---|---|
| **현행성** | 학습 시점 이후의 개정·시행일 변화를 조회 시점 기준으로 확인합니다. **별표·별지서식**까지 가져옵니다 |
| **근거** | 답마다 법제처 원문 근거가 붙습니다 — 어느 법령 몇 조 몇 항인지, 의뢰인에게 나가는 문서에 그대로 옮길 수 있는 수준으로 |
| **재사용** | 조회 결과가 **내 지식창고에 파일로 남습니다.** 채팅창의 답은 대화가 끝나면 사라지지만, 파일은 다음 사건에서 AI가 먼저 읽고 시작합니다 |

세 번째가 핵심입니다. **조회는 이제 누구나 합니다 — 의뢰인도 AI로 조문을 정확히 찾아옵니다.** 값이 나가는 것은 조회가 아니라, 조회한 것을 내 경험과 엮어 **종합적으로 분석·검토**하는 일입니다. 이 도구는 그 재료(원문·시행일·별표)를 내 지식창고에 쌓는 장치입니다.

연결이 되고 나면, 문서·행정절차를 검토시킬 때 AI가 **기본으로 이 도구로 현행 법령을 확인하고 답합니다** — 따로 시키지 않아도 됩니다.

## §2. 말로 부탁하기 — 기본 경로

설정 파일이 어디 있는지 몰라도 됩니다. **Codex에게 말로 부탁하면, 설정은 Codex가 알아서 합니다.** 리듬은 넷입니다: **부탁 → 승인 → 재시작 → 확인.**

### ① 부탁 — 이 문장을 붙여넣습니다

`내인증키` 부분만 아래 「인증키 발급」에서 받은 키로 바꾸세요.

```
한국 법령을 조회하는 korean-law 도구를 연결해줘.
원격 주소는 https://mcp.gomdori.app/law?oc=내인증키 야.
필요한 설치와 설정은 네가 알아서 해줘.
```

> 💡 아직 인증키가 없으면 가운데 주소 줄을 빼고 부탁하셔도 됩니다 — 그러면 Codex가 **«인증키가 필요합니다»라고 물어봅니다.** 그때 아래 절차로 발급받아 알려 주면 됩니다.

### ② 승인 — 창이 뜨면 허용

Codex가 *«설정 파일을 만들거나 고치겠습니다»* 라는 확인 창을 띄웁니다. **허용**을 누르세요.

> *화면의 «나 대신 승인» 토글을 켜 두면 이런 확인 창을 건너뜁니다 — 다만 의뢰인 자료가 있는 폴더에서는 **끄고(매번 확인)** 쓰시기를 권합니다.*

### ③ 재시작 — 껐다 켭니다

새 도구는 **앱이 켜질 때** 붙습니다. 앱을 완전히 종료했다가 다시 실행하세요.
**«연결했는데 안 돼요»의 대부분이 이 단계를 건너뛴 것입니다.**

### ④ 확인 — 이 한 줄

```
행정사법 제2조를 법령 도구로 조회해봐.
```

✅ **성공**: 조문 원문 + 공포일·시행일이 나옵니다.
❗ **도구를 안 쓰고 일반 답변만 하면**: 설정을 아직 못 읽은 것입니다 → ③으로 (앱 완전 종료 후 재실행).

### 인증키(OC) 발급 — 무료, 1분

법령 조회는 법제처 Open API를 씁니다. 인증키는 무료이고, 화면 두 개면 끝납니다.

1. **`open.law.go.kr`** 접속 → 회원가입·로그인 → **「Open API 사용 신청」** 클릭

   > 📸 `img/11-oc-apply.png` — 신청 페이지. **«Open API 사용 신청» 버튼 위치**

2. 신청서를 내면 **인증키(OC)** 가 표시됩니다 (예: `honggildong` 같은 짧은 문자열)

   > 📸 `img/08-law-oc.png` — 발급 완료 화면. **인증키가 표시되는 위치** *(캡처 시 본인 키는 가리고)*

> 💡 이 키는 남에게 보여주지 마세요. 화면 공유·발표 중에는 가립니다.

## §3. 플러그인 메뉴 — 앱스토어 경로

Codex 앱 사이드바에는 **«플러그인»** 메뉴가 있습니다(2026-07-30 메뉴 실재 확인). 완성된 도구를 **클릭으로 설치**하는 목록으로, Box·Notion 등 수십 종이 올라와 있습니다.

- 여기서 법령류 도구가 검색된다면 **이 경로가 가장 쉽습니다** — 클릭 → 설치 → 끝.
- 목록에 없는 도구는 §2(말로 부탁) 또는 §4(설정 화면)로 붙입니다.

> ※ **플러그인 목록에서 korean-law(법령 도구)가 검색되는지는 실측 후 확정합니다** → `실측_점검표.md` **#11**. 확인 전까지는 **§2가 기본 경로**입니다.

## §4. 설정 화면 — 수동 경로

말로 부탁하는 것이 어색하면 공식 설정 화면으로도 됩니다. 파일 편집이 아니라 **입력 칸 채우기**입니다.

1. Codex **설정(Settings)** → **MCP servers** *(한국어 메뉴명은 실측 후 확정 — 초안은 영문 병기 → `실측_점검표.md` #11)*
2. **Add server(서버 추가)** → 칸을 채웁니다
   - 이름: `korean-law`
   - 방식: **원격 URL** → 주소 칸에 `https://mcp.gomdori.app/law?oc=내인증키`
   - *(내 컴퓨터에서 직접 실행하는 STDIO 방식도 있지만, 이 트랙은 원격 주소만 씁니다)*
3. 저장 → **앱 재시작** → §2의 ④로 확인

## 하나 더(선택) — 법령을 «이력»으로 보는 도구

**legalize-kr** — 법령·판례·행정규칙·자치법규를 마크다운으로 모아둔 공개 저장소입니다. 공포·시행일마다 기록이 남아 **«그 사이에 무엇이 바뀌었나»** 에 강합니다. **인증키가 필요 없습니다.**

붙이는 방법도 같습니다 — 말로 부탁합니다.

```
legalize-kr 법령 이력 스킬을 설치해줘.
공개 저장소 legalize-kr/agent-skills 에 있어. 필요한 명령은 네가 알아서 실행해줘.
```

- 이 단계는 **건너뛰어도 됩니다.** §2까지만으로 충분합니다.
- ⚠️ 법률 자문 도구가 아니라 **데이터 아카이브**입니다(저장소 스스로 그렇게 밝히고 있습니다). 판단은 우리가 합니다.

**두 도구의 자리**
- 법령 도구(§2) = **지금 조문이 무엇인가** (별표·서식까지)
- 이력 도구 = **언제 어떻게 바뀌었나** (부칙·경과규정·소급 판단에서 갈립니다)

## §5. 막혔을 때 — 함정 3종

| 함정 | 증상 | 해결 |
|---|---|---|
| **재시작** | 연결했다는데 도구를 안 쓴다 | 설정은 앱이 켜질 때 읽습니다 — **앱 완전 종료 후 재실행** |
| **승인 창** | 부탁했는데 아무 일도 안 일어난다 | 확인 창을 지나쳤거나 거부한 것 — 대화를 다시 보고 **«허용»**. «나 대신 승인» 토글 상태도 확인 |
| **로그인 팝업(OAuth)** | 브라우저 로그인 창이 갑자기 뜬다 | 일부 도구는 연결 때 계정 로그인을 요구합니다 — 어느 서비스인지 확인하고 로그인하면 진행됩니다. **모르는 서비스면 중단** |

이 밖의 증상:

| 증상 | 해결 |
|---|---|
| 「사용자 정보 검증 실패」 | 인증키 오타·앞뒤 공백. 주소의 `oc=` 뒷부분을 다시 확인 |
| 조회가 됐다 안 됐다 한다 | 법제처 서버가 간헐적으로 불안정합니다. 잠시 후 재시도 |
| 답이 너무 길어 잘린다 | "핵심 조문만" / "표로" 같이 형식을 지정 |
| 갑자기 아무것도 안 된다 | 사용량 한도일 수 있습니다 → `문제해결_보충.md` C1 |
| 위 어느 것도 아니다 | 아래 부록(설정 파일 직접 편집)으로 |

## 조회 결과를 지식창고에 남기기 — 이 도구의 진짜 용도

Codex는 **내 폴더에 파일을 쓸 수 있으므로**, 조회한 것을 그대로 지식으로 쌓을 수 있습니다.

```
화장품법 시행규칙 제8조를 조회해서, 자격요건을 표로 정리하고
wiki/ 아래에 「화장품_책임판매관리자_자격.md」로 저장해줘.
맨 위에 조회일과 시행일을 적어줘.
```

→ 다음 사건에서 AI가 그 파일을 먼저 읽고 시작합니다. **이것이 「오래 쓸수록 아는 비서」의 실제 구조입니다.** 단순 조회에 머물지 않고 내 경험·지식을 쌓아 쓰는 쪽으로 가는 첫걸음이기도 합니다.

## 실무 프롬프트 모음 (붙인 뒤 그대로 쓰십니다)

### 조문·별표 확인

```
{법령명} {조문}을 원문으로 조회해줘. 시행일과 최근 개정 여부도 같이.
삭제된 항·호가 있으면 표시해줘.
```

```
{법령명} 별표 {번호}를 조회해서 표로 정리해줘. 원문 항목을 빠뜨리지 마.
```

### 사건 검토 (자료를 붙여서)

```
[상황] 나는 {업무}를 처리하는 행정사다. 아래는 이 사건의 사실관계다.
[자료] (상담 메모를 여기 붙여넣기 — 이름·번호·금액은 가리고)

[요청]
1. 확인된 사실 / 추정 / 확인이 필요한 것으로 나눠라
2. 관련 조문을 도구로 조회해서 조문 번호와 시행일을 붙여라
3. 제출 서류 후보와, 그중 이 사건에서 빠질 수 있는 것을 표시하라
4. 마지막에 내가 직접 확인할 항목만 따로 모아라

[금지] 조회하지 않은 조문을 단정하지 마라. 확인 안 된 기한을 적지 마라.
```

### 보완 요구 대응

```
아래는 받은 보완 요구다. (원문 붙여넣기)

1. 무엇을 요구하는지 한 줄로 정리
2. 근거가 될 조문을 도구로 조회해 확인
3. 회신에 넣을 항목 목록 (자료 / 설명 / 근거조문)
4. 회신문 초안 — 내가 검토할 부분은 [[확인]]으로 표시
```

### 시점 비교 (이력 도구)

```
{법령명}이 {연도}와 {연도} 사이에 어떻게 바뀌었는지 비교해줘.
우리 사건은 {시점} 행위인데, 그때 조문으로 판단해야 하는지 알려줘.
```

### 조회 결과를 지식창고에 남기기

```
지금 조회한 내용을 wiki/ 아래에 정리해서 저장해줘.
파일명은 내용을 알 수 있게, 맨 위에 조회일·시행일·출처를 적고,
관련된 기존 페이지가 있으면 서로 링크해줘.
```

## 보안 — 두 가지만

1. **인증키를 화면에 노출하지 마세요.** 발표·화면 공유 때는 가립니다.
2. **신뢰할 수 있는 도구만 붙입니다.** 도구 연결은 외부 프로그램을 AI에 붙이는 기능이라, 출처가 불분명한 주소를 붙이면 위험할 수 있습니다(프롬프트 인젝션). 이 문서에 적힌 두 도구는 공개 저장소에서 소스를 확인할 수 있습니다.

## 부록(폴백) — 설정 파일 직접 편집

> **위 §2~§4로 안 될 때만 보세요.** 정상 경로에서는 이 절이 필요 없습니다.

Codex는 도구 목록을 `~/.codex/config.toml` 파일에서 읽습니다. 승인이 계속 막히거나 회사 정책으로 Codex가 파일을 만들지 못할 때는 직접 만듭니다.

**파일 위치로 들어가기**

- **Mac**: Finder → `Shift`+`⌘`+`G` → `~/.codex` 입력 → 이동. 폴더가 없으면 홈 폴더에서 `⌘`+`⇧`+`.`(숨은 파일 보기) 후 `.codex` 폴더 생성
- **Windows**: 파일 탐색기 주소창에 `%USERPROFILE%\.codex` 입력. 없으면 홈 폴더에 새 폴더 `.codex` 생성

그 안에 **`config.toml`** 텍스트 파일을 만들고 아래를 적습니다 (이미 있으면 기존 내용은 지우지 말고 맨 아래에 덧붙입니다).

```toml
[mcp_servers.korean-law]
url = "https://mcp.gomdori.app/law?oc=내인증키"
```

> ⚠️ 메모장으로 저장할 때 파일 이름이 `config.toml.txt` 가 되지 않게 하세요 — 저장 창에서 **파일 형식을 «모든 파일»** 로 바꾸고 이름을 `config.toml` 로 정확히 적습니다.

**명령줄이 익숙하다면** 터미널 한 줄로도 등록됩니다 (이 방식은 내 컴퓨터에서 실행하는 STDIO 방식이라 **Node.js 설치가 필요**하고, 인증키는 환경변수로 넣습니다).

```bash
codex mcp add korean-law -- npx -y korean-law-mcp
```

**legalize-kr(이력 도구)을 명령으로 설치하려면**:

```bash
npx skills add legalize-kr/agent-skills --skill legalize-kr
```

어느 방법이든 마지막은 같습니다 — **앱 재시작 → §2의 ④로 확인.**

# (참고) ChatGPT 채팅창에서 쓰고 싶다면

이 문서의 예시는 Codex 앱 기준입니다. 같은 법령 도구를 ChatGPT 웹/앱 채팅창에서도 쓸 수 있어 적어 둡니다.

**설정 → 커넥터 → 고급 설정 → 개발자 모드** → 「커스텀 커넥터 추가」 → 이름 아무거나 + 주소 `https://mcp.gomdori.app/law?oc=본인키` → 추가한 커넥터의 「구성」에서 도구를 **「항상 사용」**으로.

| | Codex 앱 (이 트랙) | ChatGPT 채팅창 |
|---|---|---|
| 붙는 도구 | 원격 주소 + 내 컴퓨터에서 도는 것 | **원격 주소만** |
| 내 폴더 읽고 쓰기 | ✅ | ❌ |
| 조회 결과가 남는가 | ✅ **파일로 남습니다** | 대화가 끝나면 사라집니다 |
| 요금제 | ChatGPT 유료 플랜 | Plus 이상 · 개발자 모드는 베타 |

**«오래 쓸수록 내 업무를 아는 비서»는 파일이 남는 쪽에서만 성립합니다.** 그래서 이 꾸러미는 «내 폴더를 읽고 쓰는 앱»을 전제로 합니다 — Codex든, Claude Code든, 같은 일을 하는 다른 앱이든 상관없습니다.
