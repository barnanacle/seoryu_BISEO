# 명함 디자인표 — 사람마다 다른 명함이 나오는 규칙

> **이 문서는 언제 보나**: "왜 내 명함은 저 사람과 색이 다르지?"가 궁금할 때, 또는 디자인을 다시 뽑고 싶을 때 봅니다. 명함을 만드는 절차 자체는 `명함_만들기.md`에 있습니다.

**AI에게**: 이 문서가 디자인 결정의 표준(SSOT)이다. 여기 적힌 값과 `templates/card_index.html`의 CSS 값·이름은 **1:1로 같아야** 한다. 임의로 색을 지어내거나 다른 글꼴을 쓰지 마라.

---

## 1. 왜 자동으로 정하나

40명이 같은 패킷으로 명함을 만들면, 아무 규칙이 없을 때 결과는 둘 중 하나가 됩니다. **전부 똑같이 생기거나**, **각자 취향대로 손보다 시간을 다 쓰거나.**

그래서 이렇게 합니다.

- 인터뷰 답에서 **씨앗 문자열** 하나를 만듭니다.
- 그 씨앗을 계산해 **6개 축**에서 각각 하나씩 고릅니다.
- 조합은 **8 × 4 × 3 × 6 × 3 × 3 = 5,184가지**입니다.

각 축의 후보는 "어떤 조합이 나와도 명함으로 무리가 없는 것"만 골라 두었습니다. 튀는 색, 읽기 힘든 글꼴, 장난스러운 장식은 후보에 없습니다.

---

## 2. 씨앗 문자열 만들기

인터뷰 답 다섯 조각을 순서대로 이어 붙입니다.

```
이름 + 사무소명 + 직함 + 연락수단 + 느낌단어
```

- 이어 붙인 뒤 **공백과 하이픈(`-`)을 모두 지웁니다.**
- 유니코드 정규화(NFC)를 적용합니다. *유니코드 정규화: 같은 글자를 컴퓨터가 두 가지 방식으로 저장하는 경우가 있어(특히 Mac의 한글), 한 가지 방식으로 통일하는 처리입니다. 이것을 하지 않으면 같은 이름인데 다른 디자인이 나올 수 있습니다.*
- 연락수단은 고른 항목의 이름을 `전화` `이메일` `링크` `카카오` 순서로 붙입니다 (번호·주소 원문은 넣지 않습니다).

예시:

| 조각 | 값 |
|---|---|
| 이름 | 홍길동 |
| 사무소명 | 행정사사무소청효 |
| 직함 | 행정사 |
| 연락수단 | 이메일 |
| 느낌단어 | 든든한 |
| **씨앗** | `홍길동행정사사무소청효행정사이메일든든한` |

## 3. 씨앗 → 6개 번호 (두 가지 계산 방법)

### 방법 ① 정본 — `style_pick.py` (파이썬이 있을 때)

명함 폴더에서 이렇게 실행합니다.

```
python3 style_pick.py
```

계산 방식은 이렇습니다.

1. 씨앗을 SHA-256으로 계산해 64자리 문자열(16진수)을 얻습니다. *SHA-256: 어떤 글을 넣어도 정해진 길이의 문자열 하나로 바꿔 주는 계산법. 같은 글은 언제나 같은 결과가 나옵니다.*
2. 그 문자열의 앞에서부터 두 글자씩 여섯 조각(`c0`~`c5`)을 떼어 숫자로 바꿉니다.
3. 각 조각을 축의 후보 수로 나눈 **나머지**가 그 축의 번호입니다.

| 축 | 계산 |
|---|---|
| 축1 색 조합 | `c0 % 8` |
| 축2 배치 | `c1 % 4` |
| 축3 글자 조합 | `c2 % 3` |
| 축4 장식 모티프 | `c3 % 6` |
| 축5 모서리·여백 | `c4 % 3` |
| 축6 강조 강도 | `c5 % 3` |

### 방법 ② 폴백 — 손계산 (파이썬이 없을 때)

씨앗의 글자를 하나씩 **유니코드 번호**로 바꿔 전부 더합니다. 그 합을 `S`라고 하면:

| 축 | 계산 |
|---|---|
| 축1 색 조합 | `S % 8` |
| 축2 배치 | `(S ÷ 7의 몫) % 4` |
| 축3 글자 조합 | `(S ÷ 13의 몫) % 3` |
| 축4 장식 모티프 | `(S ÷ 17의 몫) % 6` |
| 축5 모서리·여백 | `(S ÷ 23의 몫) % 3` |
| 축6 강조 강도 | `(S ÷ 29의 몫) % 3` |

*몫 = 나눗셈에서 소수점 아래를 버린 값. `%` = 나머지.*

**검산용 예제** — 씨앗이 `가나`인 경우 (실제로는 훨씬 길지만, 방법이 맞는지 확인하는 용도입니다):

| 단계 | 계산 | 결과 |
|---|---|---|
| 유니코드 번호 | 가 = 44032, 나 = 45208 | `S = 89240` |
| 축1 | 89240 % 8 | **0** → 먹지 |
| 축2 | 89240 ÷ 7 = 12748 → 12748 % 4 | **0** → a 세로 카드 |
| 축3 | 89240 ÷ 13 = 6864 → 6864 % 3 | **0** → gothic |
| 축4 | 89240 ÷ 17 = 5249 → 5249 % 6 | **5** → band 좌측 굵은 색띠 |
| 축5 | 89240 ÷ 23 = 3880 → 3880 % 3 | **1** → round 라운드 넉넉 |
| 축6 | 89240 ÷ 29 = 3077 → 3077 % 3 | **2** → vivid 선명 |

**AI에게**: 이 계산을 할 때 **암산하지 마라.** 글자마다 유니코드 번호를 적은 표를 먼저 만들고, 그 표를 더해 `S`를 구한 뒤 나눗셈을 한 줄씩 적어라. 계산이 끝나면 6개 번호를 `style.json`에 적어 두고, 다음부터는 다시 계산하지 말고 그 파일을 읽어라.

### ⚠️ 정직하게 적어 두는 것 — 두 방법은 서로 다른 답을 냅니다

방법 ①과 ②는 **계산법이 다르므로 대개 다른 조합이 나옵니다.** "어느 쪽이든 같은 결과"가 아닙니다.

중요한 것은 각 방법이 **그 자체로 결정적**이라는 점입니다.

- 같은 씨앗 + 같은 방법 = **언제나 같은 디자인** (재현됩니다)
- 한 번 뽑아 명함을 만들었다면, 그 결과는 `style.json`과 `index.html`의 `<body>` 줄에 남습니다. **그 기록이 최종본**입니다.
- 나중에 파이썬을 설치해 방법 ①로 다시 뽑으면 디자인이 바뀔 수 있습니다. **이미 만든 명함이 마음에 드시면 다시 뽑지 마세요.**

## 7. 축4. 장식 모티프 (6종)

`<body data-motif="키">` — 전부 CSS로만 그립니다. **이미지 파일을 쓰지 않습니다.**

| # | 키 | 이름 | 구현 |
|---|---|---|---|
| 0 | `none` | 없음 | 장식 없음 (여백으로만 정리) |
| 1 | `rule` | 얇은 이중선 | 이름 아래 `border-bottom: 3px double var(--line)` |
| 2 | `seal` | 도장 자리 사각 | 오른쪽 위에 `--accent` 테두리 정사각형 + 안쪽에 작은 사각 (28px) |
| 3 | `grid` | 옅은 격자 | 배경에 `repeating-linear-gradient`로 24px 격자, 선 색 `--line` |
| 4 | `slant` | 사선 그라데이션 | 카드 위쪽에 `linear-gradient(135deg, var(--accent-soft), transparent 60%)` |
| 5 | `band` | 좌측 굵은 색띠 | 카드 왼쪽에 `border-left: 6px solid var(--band)` |

### 충돌 조정 규칙 (2건 — CSS에 이미 반영)

같은 자리에 장식이 겹쳐 지저분해지는 두 경우만 자동으로 정리합니다. 조정도 규칙이므로 **결과는 여전히 재현됩니다.**

| 조합 | 조정 |
|---|---|
| 배치 `b`(좌측 사이드바) + 모티프 `band`(좌측 색띠) | 왼쪽 색띠를 생략합니다 (사이드바가 이미 그 역할을 합니다) |
| 배치 `c`(상단 밴드) + 모티프 `slant`(상단 사선) | 사선을 흐리게 깔아 밴드와 겹치지 않게 합니다 |

## 10. 이 방식의 성질 세 가지 (정직한 표기)

**① 같은 답이면 언제나 같은 디자인입니다.**
명함을 다시 만들어도 색과 배치가 바뀌지 않습니다. 파일을 잃어버려도 같은 답으로 다시 뽑으면 같은 명함이 나옵니다.

**② 다른 사람은 거의 다른 디자인이 나옵니다 — 다만 "절대 안 겹친다"는 아닙니다.**
조합이 5,184가지이므로, 40명이 만들면 **여섯 축이 전부 똑같은 한 쌍이 나올 가능성이 대략 7분의 1** 정도입니다. 드물지만 0은 아닙니다. 설령 축이 전부 같아도 이름·사무소명·소개 문장이 다르므로 화면에서 받는 인상은 서로 다릅니다.

**③ 마음에 안 들면 다시 뽑을 수 있습니다.**
씨앗 끝에 `#2`를 붙여 다시 계산하면 다른 조합이 나옵니다. `#3`, `#4`도 같은 방식입니다. 다시 뽑아도 **그 번호를 기억해 두면 언제나 재현**됩니다.

```
python3 style_pick.py --variant 2
```

AI에게 말로 요청하실 때는 이렇게:

```
명함 디자인이 마음에 안 들어. 씨앗에 #2를 붙여 다시 뽑아서 index.html의 body 줄만 바꿔줘.
```

더 구체적으로 바꾸고 싶으실 때의 요청 문장 모음은 `명함_만들기.md` **4절 「디자인이 마음에 안 들 때」** 에 있습니다.

## 11. 결정된 값을 어디에 쓰나

6개 번호가 정해지면, `index.html`에서 **딱 한 줄**만 바뀝니다.

