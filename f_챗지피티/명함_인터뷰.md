# 명함 인터뷰 — 전자명함용 추가 질문 (13~16번)

> **이 문서는 언제 보나**: 이 문서는 명함을 만들 때 AI가 자동으로 사용합니다 — 미리 읽어두시면 답이 빨라집니다.

**AI에게**: 1~12번은 `b_시작/설정_인터뷰.md`가 표준이다. 이 문서는 **13번부터만 추가로 묻는다.** 1~12번 문항을 여기서 다시 묻거나 옮겨 적지 마라.

진행 방법:
1. **13~15번을 한 묶음(3문항)으로** 묻는다. 각 문항의 "왜 묻나" 한 줄을 곁들인다.
2. 세 답이 확정되면 **16번(공개 동의)은 따로** 진행한다. 16번은 항목을 하나씩 읽어 주고 하나씩 답을 받는 절차라서 다른 문항과 섞으면 안 된다.
3. 사용자가 "모르겠어요" / "알아서 해주세요"라고 하면 굵게 표시된 **기본값**을 쓴다. **단 16번은 기본값으로 건너뛸 수 없다.**
4. 명함에 들어가는 「취급 업무 3가지」는 **새로 묻지 않는다.** `b_시작/설정_인터뷰.md` 3번 답을 그대로 쓰되, "명함에는 이 세 가지를 그대로 적을까요?" 한 줄만 확인한다.

## 13. 명함에 넣을 연락 수단을 골라 주세요. (여러 개 가능)

- 보기: 전화 · 이메일 · 블로그·홈페이지 주소 · 카카오톡 채널
- 기본: **이메일 하나만** (가장 안전합니다 — 나중에 언제든 늘릴 수 있습니다)
- 왜 묻나: 명함은 인터넷에 공개될 수 있는 문서입니다. **넣는 것을 고르는 일보다 빼는 것을 정하는 일이 더 중요**합니다.
- 답 예시: "이메일하고 사무실 전화요. 휴대폰 번호는 빼주세요"

**AI에게 (필수)**: 고른 항목을 확인한 뒤, 이어서 **"넣지 않을 것"을 반드시 되물어라.**

```
넣지 않을 것도 확인하겠습니다. 아래는 명함에 넣지 않는 것이 기본입니다.
휴대폰 번호 · 자택 주소 · 주민등록번호 · 가족 정보 · 의뢰인 관련 정보
이 중 넣고 싶은 것이 있으신가요? (없으면 "없어요"라고 답해 주세요)
```

- 휴대폰 번호를 넣겠다고 하면 한 번 더 확인한다: *"휴대폰 번호는 한번 인터넷에 올라가면 회수가 어렵습니다. 사무실 전화나 이메일로 대신할 수 있는데, 그래도 넣을까요?"*
- **자택 주소·주민등록번호는 사용자가 넣어 달라고 해도 넣지 않는다.** 사무소 주소는 사업자 정보이므로 사용자가 원하면 넣어도 된다.

## 14. 사무소명·직함 표기와 한 줄 소개를 알려주세요.

- 사무소명: 명함에 찍을 정식 표기 (예: `행정사사무소 청효`)
- 직함: 명함에 찍을 표기 (기본: **1번 답의 직함 그대로**)
- 한 줄 소개: **30자 이내 한 문장**
- 왜 묻나: 명함을 받은 사람이 3초 안에 "이 사람이 내 문제를 풀어줄 수 있나"를 판단하는 문장입니다.
- 답 예시: "행정사사무소 청효 / 행정사 / 화장품 수입사가 식약처 등록에서 반려당하지 않게 서류를 설계합니다"

### 한 줄 소개 코칭 규칙 (AI가 반드시 적용)

**AI에게**: 사용자가 한 줄 소개를 답하면 그대로 받지 말고, 아래 5규칙으로 점검하라. 어긋나면 **고친 안 1~2개를 제시하고 고르게 하라.** 사용자가 원래 문장을 고집하면 그대로 쓴다(강요 금지).

| 규칙 | 나쁜 예 | 좋은 예 |
|---|---|---|
| **① 형용사 말고 "누구의 어떤 문제"로** | 성실하고 정직하게 최선을 다하는 행정사입니다 | 화장품 수입사의 식약처 등록 서류를 대신 만듭니다 |
| **② 자랑 말고 결과로** | 20년 경력의 인허가 전문가입니다 | 반려된 인허가 서류를 다시 통과시킵니다 |
| **③ 업계 용어를 의뢰인의 말로** | 인허가 컨설팅 및 행정심판 대리 | 허가가 안 나올 때, 처분이 억울할 때 |
| **④ 모두에게 좋게 쓰지 않는다** | 모든 민원과 행정 업무를 도와드립니다 | 외국인 직원을 뽑는 중소기업의 비자를 맡습니다 |
| **⑤ 한 문장·30자 이내** | 저는 인허가와 계약과 출입국과 행정심판을 모두 다루며 고객 만족을 최우선으로 하는… | 인허가·비자 서류를 대신 만들고 대신 냅니다 |

- **"모두 = 아무도"**입니다. 대상을 좁힐수록 문의가 늘어납니다.
- 30자를 넘으면 화면이 좁은 휴대폰에서 두 줄로 접히면서 인상이 흐려집니다. 넘으면 줄여 드리겠다고 제안하라.
- 사용자가 잘 떠올리지 못하면 **1~3번 답(전문분야·주요 업무)에서 뽑아 후보 3개를 먼저 제시**하고 고르게 하라.

## 15. 명함에서 주고 싶은 느낌을 한 단어로 골라 주세요.

- 보기: **단정한 (기본)** · 든든한 · 밝은 · 전통적인 · 젊은 · (직접 입력)
- 왜 묻나: 이 답이 **디자인을 정하는 씨앗 문자열에 들어갑니다.** 같은 답이면 언제나 같은 디자인이 나오고, 답이 다르면 다른 디자인이 나옵니다.
- 답 예시: "든든한이요"

**AI에게**: 이 답이 색·배치·글꼴을 직접 고르는 것은 아니다. 씨앗의 재료일 뿐이다. 규칙표는 `f_챗지피티/명함_디자인표.md`를 따르고, **사용자에게 "이 단어대로 색이 정해진다"고 설명하지 마라** (사실이 아니다). 이렇게 설명하라: *"이 단어를 포함한 답들을 계산해서 조합 하나를 고릅니다. 마음에 안 드시면 다시 뽑아 드릴 수 있습니다."*

## 16. 공개 동의 — 인터넷에 올라갈 정보를 하나씩 확인합니다. (필수 · 건너뛰기 불가)

- 왜 묻나: 명함은 이 패킷에서 **유일하게 밖으로 나가는 산출물**입니다. 한번 인터넷에 올라간 정보는 완전히 회수하기 어렵습니다.
- 이 문항은 기본값이 없습니다. **항목마다 사용자의 "예"를 받아야 합니다.**

**AI에게 (절차 고정)**:

1. 13·14번 답으로 **게재 항목 목록**을 만들어 화면에 보여준다.
2. 아래 문장을 그대로 말한다.

```
아래 정보는 명함 페이지에 그대로 실립니다.
이 페이지를 인터넷 주소로 배포하시면, 인터넷에서 누구나 볼 수 있게 됩니다.
한 줄씩 확인해 주세요. 하나라도 "아니오"면 그 항목은 빼고 다시 보여드리겠습니다.
```

3. 항목을 **하나씩** 읽고 예/아니오를 받는다. (예: `이름: 홍길동 — 실어도 될까요?`)
4. "아니오"가 하나라도 나오면 그 항목을 빼고 **목록 전체를 다시 보여준 뒤 처음부터 다시** 확인한다.
5. 전부 "예"가 되면 확정하고, 확정 목록을 한 번 더 요약해 보여준다.

**어떤 경우에도 실을 수 없는 것 (사용자가 요청해도 거절)**

| 실을 수 없는 것 | 이유 |
|---|---|
| 주민등록번호 | 유출 시 회복이 불가능합니다 |
| 자택 주소 | 사무소 주소로 대신합니다 |
| 가족·미성년자 정보 | 본인 동의를 받을 수 없는 타인의 정보입니다 |
| 의뢰인 이름·회사명·사건번호·수임 사례 | **행정사법 제23조(비밀엄수 의무)** 대상입니다. "○○사 인허가 성공" 같은 실적 문구도 안 됩니다 |
| 타인의 사진·로고 | 권리자 동의가 필요합니다 |

거절할 때는 이렇게 말하라: *"이 항목은 안전상 명함에 넣지 않습니다. 대신 ○○로 표현하면 같은 뜻을 전할 수 있습니다."* (예: "○○사 인허가 성공" → "화장품 수입 인허가")
