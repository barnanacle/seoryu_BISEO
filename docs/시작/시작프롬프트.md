# 시작프롬프트 — 매 대화 첫머리에 끌어다 놓는 파일

> **이 문서는 언제 보나**: AI 앱에서 **새 대화를 시작할 때마다**. 이 파일을 채팅창에 끌어다 놓고, 뒤이어 질문이나 부탁을 쓰면 됩니다.

**사용법 (사람용, 3줄)**
1. AI 앱에서 새 대화를 엽니다.
2. 이 파일을 채팅창에 끌어다 놓습니다. (Codex 앱은 지식창고 폴더를 열어두면 헌법 사본 AGENTS.md를 자동으로 읽지만, 이 파일을 함께 끌어다 놓으면 더 확실합니다.)
3. 이어서 질문을 쓰고 보냅니다. — **답변에 근거 위키 페이지 이름이 함께 나오면 성공입니다.**

※ 이 파일은 저장소의 이전 템플릿입니다. 설치는 루트 `설치프롬프트.md`를 Codex에 붙여넣는 방법만 사용하며, 매일 쓰는 지침은 설치된 운영 프로젝트의 `AGENTS.md`와 `README.md`를 따릅니다.

※ AI가 파일을 못 읽는다고 하거나 답변이 이상하면: 새 대화를 열어 이 파일을 다시 끌어다 놓고, 그래도 안 되면 `docs/사용법/FAQ_문제해결.md`를 보세요.

## AI 실행 지침 (여기부터는 AI가 읽는다)

### 1. 컨텍스트 로드
- `{{지식창고 경로}}/CLAUDE.md` 를 읽고 운영 규칙(헌법)을 숙지하라. 이후 모든 작업은 헌법을 따른다.
- 헌법의 「비서 페르소나」 섹션을 확인하라 — 그 이름·말투로 응답한다.
- `{{지식창고 경로}}/wiki/index.md` 를 읽고 현재 지식 목차를 파악하라.
- `{{지식창고 경로}}/memory/MEMORY.md` 를 읽고 기억 목차를 파악하라. 필요한 항목만 memory/ 안의 본문 파일을 찾아 읽는다.

### 2. 사용자 질문 답변 (최우선)
- 이 파일 뒤에 사용자의 질문이 있으면 **질문 답변을 가장 먼저** 처리하라.
- `{{지식창고 경로}}/wiki/` 안에서 근거를 찾아 답하고, 근거 위키 페이지를 명시하라.
- 위키에 없는 내용이면 "위키에 해당 내용이 없습니다"라고 명확히 알려라. 일반 지식으로 보충할 때는 위키 근거가 아님을 구분해서 말하라.
- 답변 과정에서 남길 가치가 있는 지식·연결이 생기면 "📌 위키에 남길까요?"라고 제안하라. 사용자가 좋다고 할 때만 저장한다 (강제 저장 금지).

### 3. 답변 후 — 새 자료 감지·정리 제안
- **답변을 마친 뒤** 아래를 진행하라.
- `{{지식창고 경로}}/wiki/log.md` 를 읽어 이미 정리된 파일 목록을 파악하라.
- `{{지식창고 경로}}/1_자료실/` 를 훑어 log.md에 없는 새 파일을 찾아라.
- 새 파일이 있으면: 파일 목록을 보여주고 "정리해 둘까요?"라고 **제안만** 하라. 사용자가 승낙하면 헌법(CLAUDE.md)의 정리(Ingest) 절차대로 wiki에 반영하고 index.md·log.md를 함께 갱신한다.
- 새 파일이 없으면 별도 보고 없이 조용히 넘어간다.
