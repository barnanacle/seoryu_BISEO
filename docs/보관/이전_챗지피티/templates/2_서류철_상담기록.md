## 이 파일은 어떻게 채워지나 — 대화 예시

상담이 끝나면 메모를 붙여 넣으세요. AI가 세 갈래로 갈라 줍니다.
**붙여 넣기 전에 세 가지만 바꿉니다** — 이름은 `의뢰인 A`, 번호는 끝 네 자리만(또는 생략), 금액은 `수십만 원대`.
나머지는 다듬지 말고 통째로 넣으셔도 됩니다. **실명이 그대로 들어가는 곳은 아래 「1. 사건 요약」 표 한 곳뿐이고, 그 칸은 내가 직접 적습니다.**
(아래는 형식을 보여주기 위한 **가상 사례**입니다.)

**내가 붙여 넣은 것**

```
오늘 의뢰인 A 상담 (연락처 끝 0000).
일반음식점 영업신고 건. 보수는 수십만 원대, 부가세 별도로 합의. 다음 주 월요일 접수 예정.
구청에서 요즘 정화조 용량 확인서를 추가로 요구한다고 함. 전에 다른 건에서도 그랬음.
그리고 앞으로 견적서는 부가세 별도로 적어 달라고 하심.
```

**AI가 하는 일**

```
세 갈래로 갈랐습니다.

(가) 이 사건만의 사실 → 2_서류철/의뢰인A/상담기록.md
    · 사건 요약 표에 사건명·보수 합의 방식·진행단계를 채웠습니다.
    · 실명·연락처·사업자등록번호 칸은 <직접 적어 주세요>로 비워 두었습니다
      (제가 받은 메모에 없었고, 이 칸은 직접 적으시는 편이 안전합니다).
    · 일지에 "정화조 용량 확인서 요구 / 다음 주 월요일 접수 예정"을 적었습니다.

(나) 다음 사건에도 쓸 지식 → 위키 후보
    · "일반음식점 영업신고 시 관할 구청이 정화조 용량 확인서를 추가로 요구하는 사례가 있다"
      → 이름·번호·금액을 지웠습니다. 두 번째 사례라 아직 위키 페이지로 만들지 않고,
        「4. 일반화해서 위키로 보낼 후보」에 (2회)로 적어 두었습니다.
        한 번 더 나오면 [[인허가_음식점_영업신고]] 페이지로 올리겠습니다.

(다) 내가 일하는 방식 → memory/오늘메모.md
    · "견적서는 부가세 별도로 적는다" 한 줄을 적었습니다.
      반복해서 나오면 업무규칙으로 올리겠습니다.

작업 일지(wiki/log.md)에는 "의뢰인 A 음식점 영업신고 상담 1건 기록" 한 줄만 남겼습니다.
    — 일지도 wiki 안이라 이름·상호는 적지 않습니다(개인정보 9종 점검 대상).
```

**내가 확인할 것 두 가지**

1. (나)에 이름·번호·금액이 남아 있지 않은지 — 남아 있으면 "지워 줘"라고 말하세요.
2. 같은 패턴이 세 번째인지 — 맞으면 "이제 위키 페이지로 만들어 줘"라고 말하세요.
