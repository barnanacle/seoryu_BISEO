# 1_자료실 폴더 안내

1. 여기에 원본 자료를 **넣기만 하세요.** AI는 읽기만 하고 절대 수정하지 않습니다.
2. 하위 폴더는 `wiki/index.md`의 **카테고리와 같은 이름으로** 만듭니다 (예: 인허가/, 계약/, 민원_행정심판/). 자료가 아직 없는 카테고리는 빈 폴더로 두어도 됩니다.
3. AI가 바로 정리하는 대상은 **.md(마크다운) 파일**입니다.
4. 한글(hwp)·PDF 등은 `tools/` 폴더의 변환 도구로 md로 바꾼 뒤 정리됩니다 — AI에게 "이 파일 변환해서 정리해줘"라고 말하면 됩니다 (자세한 방법: 설치 꾸러미의 `tools/안내_파일변환.md`).
5. 자료를 넣은 뒤 AI에게 **"자료 넣었어"** 라고 말하면 위키에 정리됩니다.
6. ⚠️ **의뢰인이 특정되는 원본은 여기에 넣지 않습니다.** 이름·상호가 든 공문·계약서·증빙은 `2_서류철/`로 가세요.
   `1_자료실/`에는 고시·서식·법령·교육자료처럼 **누구에게나 같은 일반 자료**만 넣습니다.
   이유: 여기 넣은 파일의 **경로가 처리 대장(`wiki/.ingest-ledger.tsv`)에 그대로 적히고**, 그 대장은 wiki 안에 있어 백업에 함께 나갑니다. 파일 이름에 이름·상호가 있으면 그것만으로 의뢰인이 특정됩니다.
