# 이전 설치 트랙 — 사용하지 않습니다

이 폴더는 과거 설치 설계의 기록입니다. 현재 수강생 설치는 앱별 트랙으로 나누지 않습니다.

설치 정본은 저장소 루트의 [`설치프롬프트.md`](../../../설치프롬프트.md) 하나입니다.

1. 새 빈 폴더(예: `서류비서`)를 Codex 프로젝트로 엽니다.
2. Python 3이 준비됐는지 확인하고 `설치프롬프트.md`의 회색 상자를 Codex에 붙여넣습니다.
3. 필요한 승인을 허용한 뒤 공식 설치기와 `--verify-only` 검사의 완료 보고를 확인합니다.

설치 후에는 운영 프로젝트의 `README.md`와 `AGENTS.md`를 따릅니다.
