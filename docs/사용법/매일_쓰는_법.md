# 매일 쓰는 법 — 하루 루틴은 세 동작

## 0. 대화를 시작하는 습관 — 딱 하나만 기억하세요

지식창고는 AI가 **운영 규칙(헌법)과 목차**를 읽은 상태에서만 제대로 작동합니다. 그래서 대화를 시작할 때 습관 하나가 필요합니다.

Codex에서 JARVIS 운영 폴더를 프로젝트로 열면 `AGENTS.md`를 기준으로 작업합니다. 새 대화에서 맥락을 확인하고 싶으면 **“AGENTS.md와 memory 인덱스를 읽고 이어서 작업해.”**라고 말합니다.

✅ **이렇게 되면 성공**: AI의 첫 답변에 지식창고의 규칙·목차를 확인했다는 언급이 나옵니다.
❗ AI가 규칙을 무시하는 것 같으면: `docs/사용법/FAQ_문제해결.md`의 Q6을 보세요.

이 습관만 지키면, 나머지는 아래 세 동작이 전부입니다.

## ① 넣는다 — 자료를 1_자료실에 넣고 정리를 부탁하기

업무 중 생기는 자료를 지식창고의 `1_자료실` 폴더(자료 상자)에 넣으세요. 파일 종류는 가리지 않아도 됩니다.

- 스캔한 PDF (공문, 안내문, 별표·서식)
- 한글 파일 (.hwp / .hwpx)
- 엑셀 파일 (수수료표, 체크리스트)
- 웹에서 읽은 좋은 글 (복사해서 메모 파일로 저장해 넣으면 됩니다)

넣은 뒤, AI에게 이렇게 말하세요:

```
자료 넣었어, 정리해줘
```

### AI가 하는 일 6단계

1. `1_자료실` 폴더를 훑어 **아직 정리하지 않은 새 자료**를 찾습니다 (작업 일지 `wiki/log.md`와 대조합니다).
2. 원본을 읽습니다 — PDF·한글·엑셀은 필요하면 `tools`의 변환 도구로 md로 바꿔 읽습니다. *md: 어떤 프로그램에서나 열리는 단순 텍스트 문서 형식.*
3. `wiki`(지식 창고)에 정리 페이지를 만듭니다 — 맨 앞에 `> **핵심**` 3줄 요약이 붙습니다.
4. 기존 페이지들을 훑어, 관련 있는 페이지와 `[[링크]]`로 **서로** 연결합니다. *[[링크]]: 위키 페이지끼리 잇는 연결 표시(교차참조).*
5. `wiki/index.md`(전체 목차)에 새 페이지를 등록합니다.
6. `wiki/log.md`(작업 일지)에 무엇을 언제 정리했는지 기록합니다.

원본은 절대 건드리지 않습니다. `1_자료실`에 넣은 파일은 읽기만 합니다.

✅ **이렇게 되면 성공**: AI가 "무엇을 정리해 어느 페이지를 만들었고, 어떤 페이지와 연결했는지"를 보고합니다. `wiki/index.md`를 열어 보면 새 줄이 보입니다.
❗ 한글 파일 변환이 안 되면: `docs/사용법/FAQ_문제해결.md` Q10을 보세요.

## ② 묻는다 — 평소 말로 질문하기

특별한 명령어가 없습니다. 업무 중 궁금한 것을 그냥 물으세요. 예를 들면:

1. "일반음식점 영업신고에 필요한 서류가 뭐였지?" — 인허가 요건 확인
2. "지난번에 정리한 화장품 표시광고 규제, 핵심만 다시 보여줘." — 예전에 정리한 것 재확인
3. "용역계약서에서 하자담보책임 조항 볼 때 챙길 포인트 정리해줘." — 계약 조항 검토
4. "옥외광고물 무허가 설치하면 과태료가 얼마지?" — 과태료·처분 기준
5. "행정심판 청구기간, 우리가 정리해 둔 페이지 있어?" — 위키 탐색
6. "이 보완요구 공문이랑 비슷한 사례, 예전에 정리한 것 있었나?" — 과거 사례 재활용

### 답변의 특징 — 근거 페이지를 같이 보여줍니다

AI는 지식창고 안에서 근거를 찾아 **"[[어느 페이지]]에 따르면 ~입니다"** 형태로 답합니다. 근거가 없으면 지어내지 않고 **"위키에 해당 내용이 없습니다"** 라고 말합니다. 이것이 인터넷 검색과 다른, 이 창고의 신뢰 기준입니다.

### 대화 중 좋은 내용이 나오면

대화하다가 남길 가치가 있는 지식(노하우, 체크리스트, 아이디어)이 만들어지면 AI가 먼저 **"📌 위키에 남길까요?"** 라고 묻습니다. 좋으면 "응"이라고만 하세요. 강제로 저장하지는 않습니다.

## ③ 점검한다 — 주 1회 건강검진

일주일에 한 번, AI에게 이렇게 말하세요:

```
건강검진해줘
```

### 무엇을 점검하나

- `1_자료실`에 넣어 두고 아직 정리 안 된 자료가 있으면 먼저 흡수합니다.
- 깨진 `[[링크]]` (연결했는데 상대 페이지가 없는 경우)
- 고아 페이지 (만들어졌는데 목차에 빠진 페이지)
- 목차(`index.md`)와 실제 파일의 불일치
- 페이지끼리 내용이 모순되는 곳
- **아직 연결 안 됐지만 이어질 만한 페이지 쌍** — 연결 기회를 제안합니다.

### 무엇이 좋아지나

목차가 실제와 정확히 맞아 떨어지고, 연결이 촘촘해집니다. 목차와 연결이 정확할수록 AI가 근거를 빨리, 정확하게 찾습니다. 즉 건강검진은 **답변 품질을 관리하는 정기 점검**입니다.

✅ **이렇게 되면 성공**: AI가 점검 결과를 요약 보고하고, 고칠 항목은 확인을 받은 뒤 고칩니다.

## "기억해줘" 사용법 — 내 스타일을 가르치기

AI에게 계속 적용됐으면 하는 나의 방식·규칙이 있으면 이렇게 말하세요:

```
기억해줘: 의견서 초안은 개조식으로 써줘
```

AI가 `memory` 폴더(기억 노트)에 적고, `memory/MEMORY.md`(기억 목차)에 한 줄로 색인합니다. 다음 대화부터 자동으로 적용됩니다. 문체, 자주 쓰는 양식, 반복해서 고치게 되는 실수 — 무엇이든 좋습니다.

한 가지 구분만 기억하세요:

| 하는 말 | 어디에 남나 | 용도 |
|---|---|---|
| **"기억해줘: ~"** | `memory/` (기억 노트) | 앞으로 계속 적용할 내 규칙·스타일 |
| **"기록해줘"** | `wiki/log.md` (작업 일지)만 | 오늘 한 일·결정의 기록 |

운영 규칙(헌법) 자체는 내가 명시적으로 "규칙을 바꿔줘"라고 지시할 때만 바뀝니다.

## 쌓일수록 좋아지는 이유

이 창고는 쓸수록 값이 오릅니다. 자료를 넣을 때마다 페이지가 늘고, 페이지가 늘 때마다 새 페이지와 기존 페이지 사이의 `[[링크]]` 연결이 함께 늘기 때문입니다. 연결이 늘면 AI는 질문 하나에 여러 페이지를 겹쳐서 답할 수 있게 되고 — 인허가 지식과 계약서 지식이 한 답변에서 만나는 식으로 — 그 조합은 나만의 자료에서만 나오는 나만의 관점이 됩니다. 오늘 넣는 자료 하나가 미래의 모든 질문의 답을 조금씩 좋게 만듭니다. 이 원리가 궁금하면 `docs/사용법/지식얼개_원리.md`를 읽어 보세요 (몰라도 쓰는 데 지장은 없습니다).
