# 설치 완료 점검표

설치는 저장소 루트의 [`설치프롬프트.md`](../../설치프롬프트.md)를 Codex에 붙여넣는 한 가지 방법만 사용합니다.

- [ ] 새 빈 폴더를 Codex 프로젝트로 열었다. 이름은 자유롭다.
- [ ] Python 3을 실행할 수 있다. Mac은 `python3`, Windows는 `py -3` 또는 `python`이다.
- [ ] `설치프롬프트.md`의 회색 상자를 Codex에 붙여넣었다.
- [ ] 필요한 인터넷 접근과 명령 실행을 승인했다.
- [ ] 공식 설치기와 읽기 전용 `--verify-only` 검사가 모두 성공했다.
- [ ] 보고된 누락·내용 불일치·예상 밖 운영 항목이 모두 0개다. OS 메타데이터는 보존하고 검사에서만 제외했다.
- [ ] `1_자료실`, `2_서류철`, `3_작업실`, `wiki`, `memory`, `tools`와 `AGENTS.md`·`README.md`가 있다.
- [ ] 운영 프로젝트에 원본 설명서 폴더와 `.git`이 생기지 않았다.

설치가 중간에 실패하거나 실제 차이가 있다면 기존 파일을 삭제·덮어쓰거나 같은 폴더에 추측 복사를 반복하지 않습니다. `--verify-only`로 차이를 확인하고 새 빈 폴더에서 다시 설치합니다.
