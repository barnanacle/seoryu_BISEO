# graphify 설정 — 위키의 "지식 지도" 만들기

> **이 문서는 언제 보나**: 위키 페이지가 제법 쌓인 뒤(대략 50페이지 즈음), "건강검진"을 더 똑똑하게 하고 싶을 때 봅니다. **처음 시작 단계에서는 건너뛰어도 됩니다.**

---

## 1. 이게 되면 무엇이 좋아지나

- **지식그래프**: 위키 페이지들을 점으로, 페이지 사이의 연결을 선으로 그린 지도입니다.

위키가 커지면 이런 일이 생깁니다 — 서로 이어져야 할 페이지가 `[[위키링크]]`로 묶이지 않은 채 흩어져 있고, 사람 눈으로는 그걸 다 찾아내기 어렵습니다.

graphify는 `wiki/` 전체를 훑어 지식 지도를 그려 줍니다. 그러면:

- **숨은 연결 발견**: 아직 링크로 안 묶였지만 내용상 가까운 페이지 쌍을 찾아냅니다. (예: 인허가 노하우 페이지와 계약서 검토 페이지가 같은 쟁점을 다루고 있는 경우)
- **건강검진 강화**: AI에게 "건강검진"을 시킬 때 이 지도를 함께 쓰면, 깨진 링크·외딴 페이지 점검에 더해 "이 두 페이지를 이어 보세요" 같은 **연결 기회 제안**이 정확해집니다.
- 분야를 넘는 교차 연결(헌법 원칙 6)이 빨라집니다 — 지식창고의 진짜 힘이 여기서 나옵니다.

---

## 2. 설치 — 이미 되어 있습니다

필요할 때 AI에게 **"tools의 지식그래프 환경을 준비해줘"**라고 말하면 됩니다. 직접 설치 명령을 외울 필요는 없습니다.

확인하고 싶으면 AI에게 이렇게 말하세요:

> "graphify가 설치되어 있는지 확인해줘"

✅ **이렇게 되면 성공**: AI가 "설치되어 있습니다"라고 답하면 끝입니다.

❌ 설치가 안 되어 있다고 나오면: 오류 문구를 AI에게 보여주고 설치 승인을 요청하세요.

---

## 3. 사용법 — 전부 AI에게 말로 시키면 됩니다

직접 조작할 것은 없습니다. 필요할 때 이렇게 말하세요:

> "건강검진하면서 지식 그래프도 갱신해줘"

> "○○와 △△가 어떻게 연결되는지 그래프에서 찾아줘"

> "아직 연결 안 된 페이지 중에 이어줄 만한 것 알려줘"

✅ **이렇게 되면 성공**: AI가 "연결 후보: [[페이지A]] ↔ [[페이지B]] — 이유: …" 같은 목록을 보여 줍니다.

참고로 AI는 **제안만** 합니다. 링크를 실제로 넣을지는 사용자가 "좋아, 연결해줘"라고 답할 때 결정됩니다. 지도가 위키 본문을 마음대로 고치는 일은 없습니다.

---

## 3.5 함께 들어 있는 보조 도구 2개 (자동 사용)

`tools/`에는 지도 품질을 지키는 작은 스크립트 2개가 함께 들어 있습니다. **직접 실행할 일은 없고**, AI가 지도를 갱신할 때 알아서 씁니다.

- `graph_normalize.py` — 같은 페이지가 지도에 점 두 개로 중복 등록되는 문제(한글 이름 변환 편차)를 자동 병합합니다.
- `graph_report_inferred.py` — "내용은 가까운데 아직 링크 안 된 페이지 쌍" 후보를 뽑되, **이미 링크된 쌍은 걸러서** 진짜 후보만 보여 줍니다.

알아두면 좋은 팁 2가지:
- 지도는 위키가 바뀐 뒤에는 살짝 **뒤처질 수 있습니다**. AI가 "지도가 N페이지 뒤처져 있어요"라고 알려주면 "건강검진하면서 지도도 갱신해줘"라고 답하면 됩니다.
- 그래프에서 페이지를 찾을 때 이름이 안 잡히면 **언더바(_)를 공백으로 바꿔** 다시 찾아보세요 (예: "계약서_검토" → "계약서 검토").

---

## 4. 안전 규칙 (꼭 지키세요)

1. **인덱싱(지도에 넣기)은 `wiki/` 폴더만.** `2_서류철/`(의뢰인 실명 자료)과 `1_자료실/`(원본 자료)는 절대 그래프에 넣지 않습니다 — 의뢰인 정보 보호를 위한 규칙입니다. 그래프 작업을 시킬 때 이렇게 덧붙이면 안전합니다:

   > "그래프는 wiki 폴더만 인덱싱해. 2_서류철과 1_자료실은 제외."

2. **extras(추가 기능 묶음) 설치 금지.** graphifyy는 설치 스크립트가 넣어 준 기본(base) 구성만 사용합니다. 추가 기능 묶음은 외부로 데이터를 보낼 수 있는 구성이 섞일 수 있어, 차단이 원칙입니다. AI가 "추가 패키지를 설치할까요?"라고 물어도 거절하세요.

---

## 5. 처음엔 없어도 됩니다

- 위키가 10~20페이지일 때는 AI가 그냥 훑어 읽는 것으로 충분합니다. 지도가 필요 없습니다.
- **대략 50페이지쯤부터** 사람도 AI도 전체를 한눈에 못 보게 되고, 그때부터 graphify가 진가를 발휘합니다.
- 그 전까지는 이 문서를 잊으셔도 됩니다. `1_자료실`에 자료를 넣고 지식을 쌓는 일에 집중하세요.
