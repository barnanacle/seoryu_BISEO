# 의견제출서 서식 꾸러미

- 적용 업무: 행정처분 사전통지에 대한 일반 의견제출
- 근거: 행정절차법 제27조제1항, 행정절차법 시행규칙 별지 제11호서식
- 공식 서식 확인: 2026-09-28, 국가법령정보센터
- 서식 원문: https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=116887859&gubun=

## 사용 전 확인

사전통지인지, 청문·과태료·특별법 절차인지 먼저 분류한다. 별지 제11호가
해당 절차에 맞는지 사건마다 확인한다. 확정된 처분의 불복에는 이 꾸러미를
자동 적용하지 않는다. 통지서의 제출기한·제출처·문서번호와 법령의 적용 시점을
대조한다.

## 작성 자료와 칸

기관 통지서와 붙임, 상담기록, 빈 공식 서식을 준비한다. 이름·주소·기한·처분청은
출처를 확인한 값만 넣는다. 모르는 값은 【확인 필요】로 남긴다. 취지와 결어는
행정사가 정한 신청·대응 방향을 유지한다. 상세 의견의 각 소명은 제목과 본문으로
분리하고, 실제 확보한 자료만 소명자료 목록에 적는다.

## 결과와 검토

공식 서식 첫 페이지 위에 값만 얹고, 뒤에 상세 별지를 붙인 PDF를 만든다.
같은 값으로 편집용 별지 DOCX와 전체 편집용 DOCX도 만든다. 원본 PDF와
서식 템플릿은 수정하지 않는다. 이름·주소·날짜·처분청의 일치, 글자 넘침,
쪽수, 서명, 실제 첨부 자료를 제출 전에 사람이 확인한다. 생성은 접수가 아니다.

다른 기관 서식이나 신청 계열 업무에는 이 꾸러미의 칸·좌표를 재사용하지 않고
해당 서식의 별도 꾸러미를 만든다.
