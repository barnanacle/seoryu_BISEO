# 화장품책임판매업 등록신청서 꾸러미

- 적용 업무: 화장품책임판매업 신규 등록신청
- 법령 확인: 2026-09-28, 화장품법 시행규칙 제4조제2항
- 현행 서식: 화장품법 시행규칙 별지 제3호서식, 서식 본문 개정 2023-06-22
- 공식 서식 원문: https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=157585943&gubun=
- 조문 확인: https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000294795

## 입력 전 확인

이 꾸러미는 공식 빈 등록신청서의 앞쪽 입력 칸에 값을 얹는다. 뒤쪽 자격기준
안내는 원본 그대로 보존한다. 서식 안의 주민등록번호·외국인등록번호는
실제 사건 자료로만 확인하고 공개 예시에는 넣지 않는다. 신청인·업소·
책임판매관리자의 이름과 소재지, 책임판매 유형, 겸업 여부, 신청일은
원문과 상담자료를 대조한다.

## 구비서류

시행규칙 제4조제2항은 품질관리 및 책임판매 후 안전관리에 적합한 기준에
관한 규정과 책임판매관리자의 자격 확인 서류를 열거한다. 시행령 제2조제2호
라목에 해당하는 등록은 제출 예외가 있으므로 사건마다 적용 여부를 확인한다.
법인 등기사항증명서는 담당 공무원의 행정정보 공동이용 확인사항이다.

구비서류 확인표 DOCX는 **강의용 내부 점검표**다. 공식 신청서에 붙여
제출하도록 자동 합본하지 않는다. 실제 첨부 파일은 확보·검토된 것만
표시하고, 담당자가 제출 전에 다시 확인한다.

## 결과와 한계

제출용 PDF는 공식 서식 2쪽만 유지한다. 편집용 전체 DOCX와 내부 확인표
DOCX는 따로 만든다. 출력 파일의 【확인 필요】, 잘림·겹침, 서명권자,
수수료와 첨부 실물을 확인한다. 자동 생성은 등록신청이나 접수 완료가 아니다.
원본 서식이 개정되면 SHA-256 불일치로 중단하고 칸 위치를 다시 확인한다.
