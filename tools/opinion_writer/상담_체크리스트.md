# 행정처분 사전통지 상담 체크리스트

행정사가 잠재 의뢰인에게 받은 사전통지 공문을 먼저 분석하고, 상담에서 사실과 증빙을 확인하여 의견제출서 초안의 방향을 정하는 기록지입니다. 공문에 적힌 사실은 **행정청의 지적**, 상담에서 나온 말은 **진술**, 실제 확인한 서류는 **증빙**으로 구분합니다. 체크되지 않은 항목은 자동으로 인정하거나 해당 없음으로 처리하지 않습니다.

공문 파일 / 전체 쪽수: ______　상담 일시·방법 / 진술자·관계: ______

## 1 공문을 받자마자 확인할 사항

- [ ] 공문·처분내역·위반내역·첨부 서식·별첨을 빠짐없이 받았는가? 빠진 쪽·읽히지 않는 부분 ______.
- [ ] 발신 기관·권한 있는 처분청, 담당 부서·담당자·연락처, 수신인, 문서번호, 시행일을 원문대로 적었다.
- [ ] **송달일·수령인·수령 방법**과 이를 확인할 봉투·전자문서 수신 이력 ______. 시행일을 송달일로 간주하지 않는다.
- [ ] **의견제출기한** ______ / 청문 일시·장소 ______ / 제출 방법·도착 기준 ______. 본문과 붙임의 날짜가 다르면 담당 기관 확인 사항으로 남긴다.
- [ ] 상담일 현재 남은 기간을 실제 사건에서 확인했다. 기한 연장·보완 제출은 필요성, 신청 여부와 승인 여부를 구분하며 자동 연장으로 보지 않는다. 연습 사건은 별도로 표시한다.
- [ ] 처분 대상자와 상담자가 같은가? 법인·개인사업자·개인의 구분, 대표자·직위·위임관계·연락 담당자 ______.
- [ ] 처분의 **종류·대상·범위·기간·금액·개시일** ______. 전체 영업 / 특정 업무 / 사업장 / 품목 / 자격을 구별한다. 예고되지 않은 날짜는 추정하지 않는다.
- [ ] 공표·명단 공개·등록취소·허가 조건·병행 처분이 함께 예고되었는가? 각 처분과 기한을 별도로 기록한다.
- [ ] 공문에 적힌 위반 사실, 일시·장소·기간·횟수, 법률·조문·별표 항목·차수 ______.

## 2 상담 전에 행정사가 할 법률검토

공문에 인용된 법률명부터 법령 도구로 검색합니다. 법률, 시행령, 시행규칙, 처분기준 별표, 위임된 조례·규칙, 관련 고시·훈령을 구분하여 읽습니다. 법령 조회에는 의뢰인의 이름·상호·접수번호·주소·금액을 넣지 않습니다.

| 검토 항목 | 확인할 질문 | 기록할 내용 |
|---|---|---|
| 적용 절차 | 행정절차법 적용 대상인가? 특별법 우선 규정 또는 적용 제외인가? | 법령·조문 / 절차 종류 / 서식 / 적용·비적용 이유 |
| 처분 권한 | 통지 기관에 처분 권한 또는 적법한 위임·위탁 근거가 있는가? | 주체·관할·위임 근거 |
| 행위시법 | 위반행위 시작·종료일은 언제인가? 이후 기준이 가벼워졌는가? | 해당 시점 법령 버전, 부칙·경과조치, 신구 기준 |
| 구성요건 | 지적된 행위가 각 요건에 해당하는가? 대상자·업종·품목·행위·기간이 맞는가? | 요건별 필요한 사실과 증빙, 반대 사실 |
| 처분기준 | 기속·재량 여부, 처분 종류·상한·기간·금액, 가중·병합 규칙이 맞는가? | 일반기준 + 개별기준 + 차수 산정 |
| 위반 횟수 | 재위반 산정기간·기산일·동일 위반/품목의 기준은 무엇인가? | 과거 처분일·적발일·품목·갈음 처분 포함 여부 |
| 감경·면제 | 개별 법령·별표의 요건, 제외 사유, 한도, 필수 자료가 무엇인가? | 각 요건마다 적용 가능 / 불가 / 확인 필요 + 이유 |
| 대체 처분 | 과징금 갈음·경고·시정명령 등 **그 처분에 허용된** 대안이 있는가? | 직접 근거, 재량 기준, 제외 사유, 산식·산정자료 |
| 비례·재량 | 재량이 있는 경우 위반 경위·결과·횟수·시정 노력 등 무엇을 참작하는가? | 법령 근거와 사적 손실·공익을 구별한 평가 |
| 기간 제한 | 제척기간·특별법 기간·예외 및 경과규정이 적용되는가? | 종료일·적발일·처분일, 적용 범위·예외 |
| 의견청취 | 청문 의무, 통지 내용, 의견제출 기회와 기간이 충족되었는가? | 누락·예외 근거·기관 확인 사항 |
| 병행 사건 | 형사절차·과태료·민사분쟁·다른 행정처분이 있는가? | 사건별 단계·상호 영향·진술 일치 여부 |
| 업무 범위 | 행정사의 수행 범위 및 다른 전문자격자의 검토가 필요한 쟁점이 있는가? | 위임 범위·협업 또는 별도 자문 사항 |

## 4 논거에 맞춘 소명자료 요청

사건마다 필요한 자료가 다릅니다. 기본 목록을 그대로 보내지 말고 **어떤 주장을 무엇으로 확인하려는지** 연결하여 요청합니다. 실제 발송은 담당자가 최종 검토한 뒤 별도로 합니다.

| 자료 ID | 연결 주장·입증할 사실 | 요청 자료·범위·기간·필수 페이지 | 보유자·발급처 | 대체 가능 자료 | 요청 기한 | 확보·검토 상태 |
|---|---|---|---|---|---|---|
| E001 | A001 / F001: ______ | ______ | ______ | ______ | ______ | 요청 예정 |

- [ ] 계약서는 서명면·정의·대상·해지·손해배상·특약·별첨까지 요청한다. 유리한 조항만 발췌한 자료인지 확인한다.
- [ ] 사진·게시물은 대상·촬영/게시/수정 시점과 전후 맥락을 확인한다. 원본을 보존한다.
- [ ] 회계자료는 해당 기간·품목·단위·집계 기준을 명시한다. 추정·가결산·확정 자료를 구별한다.
- [ ] 진술서·확인서는 작성자의 직접 경험·일시·관계·서명을 확인한다. 기존 진술에 맞춰 내용을 만들도록 요구하지 않는다.
- [ ] 민감정보는 입증에 필요한 범위만 요청한다. 외부 AI·검색·메신저 전송을 수집과 혼동하지 않는다.
- [ ] **요청 예정 / 요청함 / 수령 / 검토 완료 / 확보 불가 / 교체 / 철회**를 구분한다. 수령만으로 사실이 입증되었다고 처리하지 않는다.
- [ ] 제출용 목록에는 **내용을 검토하고 첨부 예정으로 지정한 자료**만 올린다. 요청 목록·예정 목록과 혼동하지 않는다.

- [ ] 최종 서식 선택, 당사자·서명권자, 실제 작성일, 수신처, 제출기한, 자료 번호가 일치한다.

## 공통 법령 확인 메모

2026년 9월 6일 법령 도구로 원문을 확인한 **상담용 출발점**입니다. 실제 사건에서는 행위시점·부칙·특별법을 다시 확인합니다.

- [행정절차법 제3조](https://www.law.go.kr/법령/행정절차법/제3조): 특별 규정 우선과 적용 제외. 모든 통지를 동일 절차로 처리하지 않는다.
- [행정절차법 제21조](https://www.law.go.kr/법령/행정절차법/제21조): 사전통지 사항, 의견제출기간을 10일 이상으로 고려할 의무, 청문 사전통지 및 통지 예외. 자동으로 “수령일부터 10일”을 기한으로 계산하는 규정으로 사용하지 않는다.
- [행정절차법 제22조](https://www.law.go.kr/법령/행정절차법/제22조): 청문·공청회·의견제출의 구분과 예외. 취소·자격박탈 등 청문 대상 여부를 점검한다.
- [행정절차법 제27조](https://www.law.go.kr/법령/행정절차법/제27조), [제27조의2](https://www.law.go.kr/법령/행정절차법/제27조의2), [시행규칙 제10조](https://www.law.go.kr/법령/행정절차법시행규칙/제10조): 의견·증거 제출, 제출 의견의 반영과 미반영 이유 설명, 별지 제11호 적용 근거. 제27조의2의 이유 설명 요청기간을 불복기간으로 혼동하지 않는다.
- [행정기본법 제14조](https://www.law.go.kr/법령/행정기본법/제14조): 제재처분의 행위시법과 유리한 변경, 특별 규정 검토. [제21조](https://www.law.go.kr/법령/행정기본법/제21조)·[제22조](https://www.law.go.kr/법령/행정기본법/제22조): 재량과 이익 형량·제재 고려사항. [제23조](https://www.law.go.kr/법령/행정기본법/제23조): 정해진 유형의 제재처분에 대한 제척기간·예외·특별법 기간. 모든 처분에 일률 적용하지 않는다.
- [질서위반행위규제법 제16조](https://www.law.go.kr/법령/질서위반행위규제법/제16조)·[제18조](https://www.law.go.kr/법령/질서위반행위규제법/제18조): 과태료의 사전통지·의견제출과 자진납부 감경·절차 종료. 과징금 갈음과 다른 제도이며 납부 전 절차상 영향을 설명한다.

조회 식별자: 행정절차법 MST 239291, 시행규칙 MST 243859, 행정기본법 MST 269955, 질서위반행위규제법 MST 224847. 세부 법령은 사건별 검토표에 별도로 기록합니다.
