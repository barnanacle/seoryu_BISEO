# 식품위생 분야 가상 흐름 시험

모든 당사자·공문·답변은 허구입니다. 실제 사건에 복사하지 않습니다. 법령 요건은 2026-09-06에 법령 도구로 확인한 당시 원문을 기록한 시험 자료이며 새 사건은 해당 시점 법령과 별표를 다시 조회합니다.

시설기준·과거 차수를 알 수 없는 통지, 일부 불명확한 답변, 아직 받지 않은 증빙을 설정했습니다. 통지의 ‘영업정지 1개월’은 허구의 기재 내용이며 법정 제재가 맞다는 결론이 아닙니다. 정확한 개별 처분 기준·특별 면제·과징금 제외사유는 확인 필요로 남깁니다.

`python3 bin/run_flow_demo.py --audience self`로 질문지 우선, 답변 대기, 질문 대조, 전체 편집 DOCX 및 PDF 생성, 자료 변경 후 재검토 차단을 시험합니다. 기본값은 행정사용과 셀프용을 모두 실행합니다. 이 명령은 가상 답변을 자동 입력하는 **개발 시험**이며 실제 대화에서는 이용자 답변을 기다립니다.
