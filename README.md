# 나만의 AI 지식창고 만들기 — install_JAARVIS

이 저장소는 행정사 업무 자료를 쌓고, AI가 재사용 가능한 지식으로 정리하도록 돕는 JARVIS 운영 꾸러미입니다.

## 설치 방법은 하나입니다

강의 수강생은 **빈 폴더를 Codex 프로젝트로 열고, 루트의 [`설치프롬프트.md`](./설치프롬프트.md) 회색 상자를 복사해 Codex에 붙여넣습니다.** Mac과 Windows 모두 같은 방법을 사용합니다.

### 준비물

- Codex 데스크톱 앱과 로그인된 계정
- JARVIS를 둘 빈 로컬 폴더
- 설치 중 저장소를 읽을 수 있는 인터넷 연결

GitHub 계정이나 별도의 설치 프로그램은 필요하지 않습니다.

### 설치 순서

1. 내 컴퓨터에 비어 있는 `JARVIS` 폴더를 만듭니다.
2. Codex에서 그 폴더를 프로젝트로 엽니다.
3. [`설치프롬프트.md`](./설치프롬프트.md)를 열어 회색 코드 상자만 복사합니다.
4. Codex 대화창에 붙여넣고 실행합니다. 인터넷 접근이나 명령 실행 승인이 나타나면 허용합니다.
5. Codex의 완료 보고에서 운영 폴더와 파일을 확인합니다.

설치가 끝난 프로젝트에는 다음 운영 구조만 생깁니다.

```text
JARVIS/
├── DATA/          ← 공식 가이드·공개 참고자료
├── 서류함/         ← 회사·사건별 원본
├── 문서작업/       ← 의견서·검토서 등 작업 결과물
├── wiki/          ← AI가 정리하고 연결한 재사용 지식
├── memory/        ← AI가 관리하는 기억
├── tools/         ← 파일 변환·점검·자동화 도구
├── AGENTS.md      ← 운영 헌법
└── README.md      ← 설치된 꾸러미의 한 장 사용 안내
```

저장소의 `0_설치`부터 `5_챗지피티`까지는 개발·검토 이력을 보존하는 원본 자료입니다. Codex는 이 폴더들과 `.git`을 운영 프로젝트에 넣지 않습니다.

## 설치 직후 시작하기

1. Codex가 묻는 짧은 시작 질문에 답합니다.
2. 공식 자료 한두 개를 `DATA/`에 넣습니다.
3. Codex에 **“자료 넣었어. wiki에 반영해.”**라고 말합니다.

`DATA/`·`서류함/`·`문서작업/`은 정보를 쌓는 세 입력 공간입니다. AI는 사용자가 지정한 범위를 검토하고, 처리 대장과 대조해 아직 반영하지 않은 자료만 `wiki/`로 환류합니다. 사건 고유 정보와 개인정보는 옮기지 않고 재사용 가능한 지식만 익명화해 정리합니다.

다음과 같이 지시할 수 있습니다.

```text
DATA 폴더를 wiki에 반영해.
이 파일을 환류해.
문서작업과 서류함 중 아직 반영되지 않은 자료를 식별해서 인젝션해.
```

## 폴더의 역할

| 구분 | 폴더 | 역할 |
|---|---|---|
| 내가 자료를 넣고 작업 | `DATA/` | 행정기관 가이드·공식 참고자료 |
| 내가 자료를 넣고 작업 | `서류함/` | 수임 회사·사건·업무별 원본 |
| 내가 자료를 넣고 작업 | `문서작업/` | 직접 만드는 문서와 결과물 |
| AI가 관리 | `wiki/` | 입력 자료에서 환류한 지식과 연결 |
| AI가 관리 | `memory/` | 페르소나와 단기·중기·장기 기억 |
| AI가 관리 | `tools/` | 변환·점검·자동화 코드 |

## 설치가 멈췄을 때

- 인터넷 또는 명령 실행 승인이 보이면 허용한 뒤 **“이어서 진행해.”**라고 말합니다.
- 기존 파일 충돌이 보고되면 덮어쓰지 말고 새 빈 폴더에서 같은 `설치프롬프트.md`를 다시 실행합니다.
- 일부 운영 파일만 빠졌다면 같은 프로젝트에서 같은 프롬프트를 다시 붙여넣습니다. 기존 파일은 보존하고 빠진 항목만 보완합니다.
- 운영 프로젝트에 `0_`부터 `5_`까지의 폴더가 보이면 저장소 원본을 프로젝트로 연 것입니다. 새 빈 폴더를 Codex 프로젝트로 열고 설치프롬프트를 실행합니다.

## 운영 원칙

1. 원본은 건드리지 않습니다. `DATA/`와 `서류함/`의 자료는 읽기 전용으로 다룹니다.
2. 지식은 연결될수록 강해집니다. 새 `wiki/` 문서는 기존 지식과 연결합니다.
3. 근거가 없으면 없다고 말합니다. 답변에는 원자료 경로를 남깁니다.
4. 개인정보와 사건 고유 정보는 `wiki/`에 옮기지 않습니다.
5. 자료가 소중해지면 별도의 비공개 저장소 등으로 운영 폴더를 백업합니다.
