# 나만의 AI 지식창고 만들기 — install_JAARVIS

> **이 문서는 언제 보나**: 이 패킷을 처음 받았을 때 가장 먼저 읽는 문서입니다. 전체 흐름을 잡고, 다음에 볼 문서를 안내합니다.

---

## 1. 이게 뭔가요

이 패킷은 **내 컴퓨터 안에 나만의 지식창고를 만드는 설치 꾸러미**입니다. 지식창고란, 내가 자료를 넣으면 AI가 대신 읽고 정리해 두는 폴더 묶음입니다. 법령 해설, 업무 노하우, 검토 자료 — 무엇이든 넣어 두면 AI가 목차를 만들고 서로 연결해 둡니다.

정리가 쌓이면, 궁금할 때 AI에게 그냥 물어보면 됩니다. AI는 지식창고 안에서 근거를 찾아 "어느 페이지에 따르면 ~입니다"라고 답합니다. 근거가 없으면 없다고 말합니다. 인터넷 어딘가의 답이 아니라, **내가 검증해서 넣은 내 자료**가 답의 근거가 됩니다.

그래서 이 지식창고는 쓸수록 똑똑해집니다. 자료를 넣을수록, 질문할수록, 피드백을 줄수록 정리와 연결이 늘어납니다. 남의 환경을 복제하는 것이 아니라, **각자의 자료로, 각자의 분야에 맞는 자기만의 창고**를 세우는 것이 목표입니다.

## 3. 30분 퀵스타트 — 6단계

### [0] 꾸러미 받기 (GitHub Desktop으로 클론)

이 꾸러미는 협회의 비공개 저장소(`github.com/barnanacle/install_JAARVIS`)에서 받습니다. *클론(clone): 인터넷 저장소의 내용을 내 컴퓨터로 통째로 내려받는 일.* 이 폴더가 이미 내 컴퓨터에 있다면(누가 대신 받아 줬다면) [1]로 건너뛰세요.

1. **GitHub 계정 만들기** — 브라우저에서 `https://github.com` 접속 → **Sign up** 클릭 → 이메일·비밀번호·아이디 입력 → 이메일로 온 인증 코드를 입력하면 가입 완료.
2. **협회 초대 수락** — 가입한 이메일 주소(또는 GitHub 아이디)를 협회에 알려주면 초대 메일이 옵니다. 메일 안의 **View invitation** 버튼 → 열린 페이지에서 **Accept** 클릭. *(초대 = 비공개 저장소를 볼 수 있게 해 주는 접근 권한입니다.)*
3. **GitHub Desktop 설치·로그인** — `https://desktop.github.com` 접속 → **Download** → 설치 후 실행 → **Sign in to GitHub.com** 클릭 → 방금 만든 계정으로 로그인 → 브라우저에 **Authorize**(허용) 버튼이 나오면 클릭. *(GitHub Desktop = 명령어 창 없이 마우스 클릭만으로 GitHub를 다루는 공식 앱입니다.)*
4. **클론(내려받기)** — GitHub Desktop에서 **File → Clone Repository**(저장소 복제) → 목록에서 **install_JAARVIS** 선택 → 저장 위치를 확인하고(기본: Mac은 `문서(Documents)/GitHub`, Windows는 `문서\GitHub`) → **Clone** 클릭.

✅ **이렇게 되면 성공**: 내 컴퓨터의 문서 폴더 안 `GitHub/install_JAARVIS` 폴더가 생기고, 그 안에 지금 이 README.md가 들어 있습니다.
❗ 목록에 install_JAARVIS가 안 보이면: 2번의 초대 수락이 아직 안 된 것입니다 — 초대 메일을 다시 확인해 Accept를 누르세요.
💡 명령 실행이 가능한 AI 앱(Codex 데스크톱 등)을 이미 쓰고 있다면, AI에게 이렇게 부탁해도 됩니다: **"이 주소를 내 컴퓨터에 클론해줘: https://github.com/barnanacle/install_JAARVIS"**

> **업데이트 받기** — 협회가 꾸러미를 개선하면 새로 내려받을 필요가 없습니다. GitHub Desktop을 열고 상단의 **Fetch origin** 버튼을 클릭 → 받을 것이 있으면 같은 자리에 나타나는 **Pull origin** 버튼을 한 번 더 클릭. 이것으로 끝입니다. 압축 파일을 주고받는 방식과 달리 **클릭 한 번으로 항상 최신 꾸러미를 유지**하는 것이 이 배포 방식의 장점입니다.

### [1] 설치하기 (0_설치 폴더)

내 컴퓨터에 맞는 가이드를 열어 따라 하세요.

- **Mac** → `0_설치/MAC_설치.md`
- **Windows** → `0_설치/WINDOWS_설치.md`

끝나면 `0_설치/설치_점검표.md`로 확인하세요.
✅ **이렇게 되면 성공**: 점검표의 항목이 모두 통과됩니다.
❗ 막히면: 해당 단계로 돌아가 한 번 더 시도하고, 그래도 안 되면 `3_사용법/FAQ_문제해결.md`를 보세요.

### [2] AI 앱에서 이 패킷 폴더 열기

Claude Desktop(또는 Codex 앱)에서 이 `install_JAARVIS` 폴더를 작업 폴더로 여세요. 여는 방법은 [1]단계 설치 가이드 마지막에 있습니다.

✅ **이렇게 되면 성공**: AI에게 "이 폴더에 어떤 파일이 있어?"라고 물었을 때 파일 목록을 답합니다.

### [3] 지식창고 만들기를 부탁하기

AI에게 이렇게 말하세요:

```
1_시작/BOOTSTRAP.md를 읽고 내 지식창고를 만들어줘
```

✅ **이렇게 되면 성공**: AI가 문서를 읽고, 나에게 몇 가지 질문(인터뷰)을 시작합니다.

### [4] AI 인터뷰에 답하기

AI가 묻는 것에 편하게 답하면 됩니다 — **이름, 직업·전문분야, 주로 다루는 자료 종류** 정도입니다. 답을 바탕으로 AI가 나에게 맞는 지식창고 폴더와 운영 규칙을 만들어 줍니다.

✅ **이렇게 되면 성공**: 지식창고 폴더(기본 이름 JARVIS)가 생기고, AI가 폴더 구조를 보여 줍니다.

### [5] 첫 자료 넣고 정리 부탁하기

지식창고 안의 `DATA` 폴더(자료 상자)에 파일 한두 개를 넣으세요. 그리고 AI에게 이렇게 말하세요:

```
자료 넣었어, 정리해줘
```

✅ **이렇게 되면 성공**: `wiki` 폴더(지식 창고)에 정리된 페이지가 생기고, AI가 무엇을 정리했는지 보고합니다.
💡 PDF·한글(HWP) 파일도 넣을 수 있습니다. AI가 `2_도구`의 변환 도구로 바꿔서 정리합니다 — 방법은 `2_도구/도구_사용법.md` 참조.

여기까지가 시작의 전부입니다. 이후 매일 쓰는 방법은 `3_사용법/매일_쓰는_법.md`를 보세요.

## 4. 폴더 지도 — 언제 어느 문서를 보나

```
install_JAARVIS/
├── README.md            ← 지금 이 문서
├── 0_설치/              ← 처음 1회: 프로그램 설치
├── 1_시작/              ← 처음 1회: 지식창고 생성
├── 2_도구/              ← 필요할 때: 파일 변환·법령 검색·지식그래프

├── 4_확장/              ← 익숙해진 뒤: 백업·지식 연합
└── 5_챗지피티/          ← ChatGPT Desktop으로 쓰실 때
```

> **어느 쪽으로 가야 하나요 (3줄)**
> 1. **Claude Desktop**으로 쓰실 분 → 위 3번 퀵스타트를 그대로 따라가세요 (`0_설치` → `1_시작`).
> 2. **ChatGPT Desktop**으로 쓰실 분 → `5_챗지피티/README.md`를 먼저 여세요. 설치·붙여넣기 방법이 다릅니다.
> 3. 어느 쪽이든 **지식창고의 구조와 규칙은 같고**, `2_도구`·`3_사용법`·`4_확장`은 두 길이 함께 씁니다.

## 5. 이 지식창고의 철학 3줄

1. **원본은 건드리지 않는다** — `DATA`에 넣은 파일을 AI는 읽기만 하고 절대 수정하지 않습니다.
2. **지식은 연결될수록 강해진다** — 정리된 페이지끼리 `[[링크]]`로 잇고, 분야를 넘는 연결을 우선합니다.
3. **기억은 인덱스로 무제한** — 목차(인덱스)만 항상 읽고 본문은 필요할 때만 찾아 읽기 때문에, 지식이 수천 페이지로 늘어도 느려지지 않습니다.

## 6. 시작 전 주의사항

- **의뢰인 개인정보**: 실명·연락처·사업자번호가 든 사건 자료는 지식창고의 `서류함` 폴더에만 두세요. `wiki`(지식 창고)에는 익명화한 노하우만 들어갑니다("한 의뢰인의 경우" 식). 이 규칙은 지식창고 생성 시 운영 규칙에 자동으로 들어갑니다.
- **구독 비용**: Claude Pro 또는 ChatGPT Plus는 유료입니다. 월 구독료를 확인하고 시작하세요.
- **백업 권장**: 지식창고는 내 컴퓨터에만 있습니다. 컴퓨터 고장에 대비해 백업을 권합니다 → `4_확장/GitHub_백업.md`.
