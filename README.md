# 나만의 AI 지식창고 만들기 — seoryu_BISEO

이 저장소는 행정사 업무 자료를 쌓고, AI가 재사용 가능한 지식으로 정리하도록 돕는 서류비서 운영 꾸러미입니다.

## 설치 방법은 하나입니다

강의 수강생은 **빈 폴더를 Codex 프로젝트로 열고, 루트의 [`설치프롬프트.md`](./설치프롬프트.md) 회색 상자를 복사해 Codex에 붙여넣습니다.** Mac과 Windows 모두 같은 방법을 사용합니다.

### 준비물

- Codex 데스크톱 앱과 로그인된 계정
- 원하는 이름의 빈 로컬 폴더 (예: `서류비서`)
- Python 3 실행 환경 (Mac: `python3`, Windows: `py -3` 또는 `python`)
- 설치 중 저장소를 읽을 수 있는 인터넷 연결

GitHub 계정은 필요하지 않습니다. Python 3이 없다면 검증되지 않은 수동 복사 대신 설치를 멈추고 먼저 준비합니다.

### 설치 순서

1. 내 컴퓨터에 비어 있는 `서류비서` 폴더를 만듭니다. 폴더 이름은 달라도 됩니다.
2. Codex에서 그 폴더를 프로젝트로 엽니다.
3. [`설치프롬프트.md`](./설치프롬프트.md)를 열어 회색 코드 상자만 복사합니다.
4. Codex 대화창에 붙여넣고 실행합니다. 인터넷 접근이나 명령 실행 승인이 나타나면 허용합니다.
5. 공식 설치기와 읽기 전용 `--verify-only` 검사가 모두 성공하고, 누락·내용 불일치·예상 밖 운영 항목이 0개인지 확인합니다. OS 메타데이터는 보존한 채 검사에서 제외합니다.

설치가 끝난 프로젝트에는 다음 운영 구조만 생깁니다.

```text
서류비서/
├── 1_자료실/            ← 공식 가이드·공개 참고자료
├── 2_서류철/            ← 회사·사건별 원본
├── 3_작업실/            ← 의견서·검토서 등 작업 결과물
├── wiki/                    ← AI가 정리하고 연결한 재사용 지식
├── memory/                  ← AI가 관리하는 기억
├── tools/                   ← 파일 변환·점검·자동화 도구
├── .agents/skills/          ← 반복 업무를 실행하는 프로젝트 공용 스킬
├── AGENTS.md                ← 운영 헌법
└── README.md                ← 설치된 꾸러미의 한 장 사용 안내
```

저장소의 `a_설치`·`b_시작`·`c_도구`·`d_사용법`·`e_확장`·`f_챗지피티`는 설치·교육 참고자료입니다. Codex는 이 폴더들과 `.git`을 운영 프로젝트에 넣지 않습니다.

## 설치 직후 시작하기

1. Codex가 묻는 짧은 시작 질문에 답합니다.
2. 공식 자료 한두 개를 `1_자료실/`에 넣습니다.
3. Codex에 **“자료 넣었어. wiki에 반영해.”**라고 말합니다.

`1_자료실/`·`2_서류철/`·`3_작업실/`은 정보를 쌓는 세 입력 공간입니다. AI는 사용자가 지정한 범위를 검토하고, 처리 대장과 대조해 아직 반영하지 않은 자료만 `wiki/`로 환류합니다. 사건 고유 정보와 개인정보는 옮기지 않고 재사용 가능한 지식만 익명화해 정리합니다.

다음과 같이 지시할 수 있습니다.

```text
1_자료실 폴더를 wiki에 반영해.
이 파일을 환류해.
3_작업실과 2_서류철 중 아직 반영되지 않은 자료를 식별해서 인젝션해.
```

행정처분 사전통지는 아래 **사전통지로 의견서 준비하기** 경로를 사용합니다. 그 밖의 법정 서식과 서술형 별지를 반복 작성할 때는 다음처럼 요청합니다. 설치 꾸러미의 `.agents/skills/form-template-filler/`가 안전한 작성 순서를 안내하고, 자세한 구현 기준은 `tools/안내_반복서식.md`에서 확인할 수 있습니다.

```text
반복 서식 작성 스킬을 사용해서 이 기관 원문과 상담기록으로
법정 서식 + 상세 별지 PDF 한 파일과 편집용 별지 DOCX를 만들어줘.
확인되지 않은 값은 추측하지 말고 【확인 필요】로 남겨줘.
```

## 폴더의 역할

| 구분 | 폴더 | 역할 |
|---|---|---|
| 내가 자료를 넣고 작업 | `1_자료실/` | 행정기관 가이드·공식 참고자료 |
| 내가 자료를 넣고 작업 | `2_서류철/` | 수임 회사·사건·업무별 원본 |
| 내가 자료를 넣고 작업 | `3_작업실/` | 직접 만드는 문서와 결과물 |
| AI가 관리 | `wiki/` | 입력 자료에서 환류한 지식과 연결 |
| AI가 관리 | `memory/` | 페르소나와 단기·중기·장기 기억 |
| AI가 관리 | `tools/` | 변환·점검·자동화 코드 |
| AI가 관리 | `.agents/skills/` | Codex가 반복 업무에 적용하는 프로젝트 공용 스킬 |

## 설치가 멈췄을 때

- 인터넷 또는 명령 실행 승인이 보이면 허용한 뒤 **“이어서 진행해.”**라고 말합니다.
- 기존 파일 충돌이 보고되면 덮어쓰지 말고 새 빈 폴더에서 같은 `설치프롬프트.md`를 다시 실행합니다.
- 일부 운영 파일만 빠졌다면 `--verify-only`로 차이를 확인합니다. 기존 폴더에 추측 복사를 반복하지 말고 새 빈 폴더에서 다시 설치합니다.
- 운영 프로젝트에 `a_`부터 `f_`까지의 폴더가 보이면 저장소 원본을 프로젝트로 연 것입니다. 새 빈 폴더를 Codex 프로젝트로 열고 설치프롬프트를 실행합니다.

## 운영 원칙

1. 원본은 건드리지 않습니다. `1_자료실/`과 `2_서류철/`의 자료는 읽기 전용으로 다룹니다.
2. 지식은 연결될수록 강해집니다. 새 `wiki/` 문서는 기존 지식과 연결합니다.
3. 근거가 없으면 없다고 말합니다. 답변에는 원자료 경로를 남깁니다.
4. 개인정보와 사건 고유 정보는 `wiki/`에 옮기지 않습니다.
5. 자료가 소중해지면 별도의 비공개 저장소 등으로 운영 폴더를 백업합니다.

## 사전통지로 의견서 준비하기

처분청의 사전통지와 붙임을 대화에 첨부하고 **“행정처분 의견서 작성기로 관련 규정과 대응 요건을 확인한 질문지부터 만들어줘”**라고 요청합니다. 행정사 상담용 또는 본인이 직접 답할 질문지를 선택할 수 있습니다.

같은 대화에 질문지 답변이나 상담 전사문을 넣으면 적용 가능한 공식 의견제출서·상세 별지 PDF, 전체 편집용 DOCX와 소명자료 요청목록을 생성합니다. 새 자료를 받으면 논거와 별지를 다시 검토하여 새 버전으로 만듭니다. 서식·기한·사실·서명·첨부는 제출 전 확인합니다.
