# 이전 Mac 설치 문서 — 사용하지 않습니다

이 문서는 변경 이력 보존용입니다. 현재 Mac 설치 정본은 저장소 루트의 [`설치프롬프트.md`](../설치프롬프트.md) 하나입니다.

1. 이름이 자유로운 새 빈 폴더(예: `서류비서`)를 Codex 프로젝트로 엽니다.
2. `python3`으로 Python 3을 실행할 수 있는지 확인합니다.
3. `설치프롬프트.md`의 회색 상자를 복사해 Codex에 붙여넣고 필요한 승인을 허용합니다.
4. 공식 설치기와 `--verify-only` 검사가 모두 성공했는지 확인합니다. `.DS_Store`는 삭제하지 않고 검사에서만 제외합니다.

이 폴더의 예전 설치 파일을 실행하지 마세요.
