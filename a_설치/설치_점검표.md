# 설치 완료 점검표

설치는 저장소 루트의 [`설치프롬프트.md`](../설치프롬프트.md)를 Codex에 붙여넣는 한 가지 방법만 사용합니다.

- [ ] 비어 있는 폴더를 Codex 프로젝트로 열었다.
- [ ] `설치프롬프트.md`의 회색 상자를 Codex에 붙여넣었다.
- [ ] 필요한 인터넷 접근과 명령 실행을 승인했다.
- [ ] `1_자료실`, `2_업무철`, `3_작업실`, `wiki`, `memory`, `tools`가 생겼다.
- [ ] `AGENTS.md`와 `README.md`가 생겼다.
- [ ] `tools/convert2md.py`와 `tools/hwp2md.py`가 생겼다.
- [ ] 운영 프로젝트에 원본 설명서 폴더와 `.git`이 생기지 않았다.

빠진 항목이 있으면 같은 프로젝트에 같은 설치프롬프트를 다시 붙여넣어 보완합니다. 기존 파일은 덮어쓰지 않습니다.
