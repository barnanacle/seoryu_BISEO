# 1_자료실 폴더 안내

1. 여기에 원본 자료를 **넣기만 하세요.** AI는 읽기만 하고 절대 수정하지 않습니다.
2. 하위 폴더는 `wiki/index.md`의 **카테고리와 같은 이름**입니다 (기본 7개가 이미 만들어져 있습니다 — 행정절차·공통 / 비자·출입국 / 인허가·영업신고 / 건축·토지 / 행정심판·불복 / 계약·문서 / 실무 노하우). 자료가 아직 없는 카테고리는 빈 폴더로 두어도 됩니다. 카테고리를 바꾸면 폴더도 함께 바꿉니다.
3. AI가 바로 정리하는 대상은 **.md(마크다운) 파일**입니다.
4. 한글(HWP·HWPX)·PDF 등은 `tools/` 폴더의 변환 도구로 md로 바꾼 뒤 정리됩니다 — AI에게 "이 파일 변환해서 정리해줘"라고 말하면 됩니다 (자세한 방법: `tools/안내_파일변환.md`).
5. 자료를 넣은 뒤 AI에게 **"자료 넣었어"** 라고 말하면 위키에 정리됩니다.
   특정 파일이나 `1_자료실` 전체를 지목해 **"wiki에 반영해"**, **"환류해"**, **"인젝션해"**라고 말해도 됩니다. 처리 대장과 대조해 이미 반영한 파일은 건너뜁니다.
6. ⚠️ **의뢰인이 특정되는 원본은 여기에 넣지 않습니다.** 이름·상호가 든 공문·계약서·증빙은 `2_서류철/`로 가세요.
   `1_자료실/`에는 고시·서식·법령·교육자료처럼 **누구에게나 같은 일반 자료**만 넣습니다.
   이유: 여기 넣은 파일의 **경로가 처리 대장(`wiki/.ingest-ledger.tsv`)에 그대로 적히고**, 그 대장은 wiki 안에 있어 백업·현황판에 함께 나갑니다. 파일 이름에 이름·상호가 있으면 그것만으로 의뢰인이 특정됩니다.
