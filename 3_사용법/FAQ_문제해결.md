## 설치

### Q1. (Windows) "python을 찾을 수 없습니다"라고 나오거나, 설치 스크립트가 Python을 못 찾아요

Python 설치 때 **"Add python.exe to PATH"** 체크를 빠뜨린 경우가 대부분입니다. *PATH: 컴퓨터가 프로그램을 어느 폴더에서 찾을지 적어 둔 목록.*

**해결**: python.org에서 받은 설치 파일을 다시 실행 → 첫 화면 맨 아래 **"Add python.exe to PATH" 체크** → Install. 그다음 `setup_windows.bat`를 다시 더블클릭하세요.
✅ **이렇게 되면 성공**: 스크립트가 Python 단계를 통과해 다음 단계로 넘어갑니다.
❗ 그래도 안 되면: Microsoft Store에서 "Python"을 설치하는 방법도 있습니다 — `0_설치/WINDOWS_설치.md` 참조.

### Q2. (Mac) "확인되지 않은 개발자" 때문에 열 수 없다고 나와요

Mac의 보안 기능(Gatekeeper)이 처음 보는 파일을 막는 정상 동작입니다.

**해결**: `setup_mac.command` 파일을 **마우스 오른쪽 클릭(또는 control+클릭) → 열기 → 열기**. 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안** 화면 아래쪽의 **"그래도 열기"** 버튼을 누르세요.
✅ **이렇게 되면 성공**: 검은 글자가 올라가는 진행 창이 열립니다.

### Q3. (Windows) 파란 창 "Windows의 PC 보호"가 떠요

Windows의 보안 기능(SmartScreen)이 처음 보는 파일을 막는 정상 동작입니다.

**해결**: 파란 창에서 **"추가 정보"** 를 누르면 **"실행"** 버튼이 나타납니다. "실행"을 누르세요.
✅ **이렇게 되면 성공**: 설치 진행 창이 열립니다.

### Q4. 설치 스크립트 창이 뜨자마자 바로 닫혀요

무언가 첫 단계에서 실패해 즉시 종료된 것입니다. 원인은 대부분 둘 중 하나입니다.

1. Python이 아직 설치되지 않음 → Q1 확인
2. 보안 기능이 차단함 → Mac은 Q2, Windows는 Q3 확인

둘을 해결한 뒤 다시 더블클릭하세요. 그래도 반복되면 `0_설치/설치_점검표.md`를 열어 어느 단계까지 되어 있는지 확인하고, 내 컴퓨터의 설치 가이드(`0_설치/MAC_설치.md` 또는 `0_설치/WINDOWS_설치.md`)에서 그 단계의 수동 설치 안내를 따르세요.

## AI 앱

### Q5. AI가 지식창고 폴더를 못 읽어요 ("파일에 접근할 수 없습니다")

AI 앱과 폴더가 연결되지 않은 상태입니다.

- **Claude Desktop**: 로컬 폴더 작업 기능으로 지식창고 폴더를 열었는지 확인하세요(버전에 따라 메뉴 이름이 다릅니다). 이 기능이 없는 버전이면 filesystem MCP를 설정하는 방법이 있습니다 — 두 방법 모두 `0_설치` 가이드의 "폴더 연결" 부분에 있습니다. 설정에 적힌 폴더 경로가 실제 지식창고 위치와 글자 하나까지 같은지도 확인하세요.
- **Codex 앱**: 지식창고 폴더를 작업 폴더로 열었는지 확인하세요.

✅ **이렇게 되면 성공**: AI에게 "지식창고에 어떤 파일이 있어?"라고 물으면 폴더 목록을 답합니다.

### Q6. AI가 규칙(헌법)을 안 지켜요 — 목차를 안 고치고, 위키에 안 남겨요

십중팔구 **이번 대화에서 헌법을 읽지 않은** 것입니다.

- **Claude Desktop**: 새 대화를 열 때마다 `시작프롬프트.md`를 대화창에 끌어다 놓았는지 확인하세요. 한 번 끌어놓은 것은 그 대화에서만 유효합니다 — **새 대화마다 다시** 끌어놓아야 합니다.
- **Codex 앱**: 지식창고 폴더를 연 상태인지 확인하세요 (열면 `AGENTS.md`를 자동으로 읽습니다).

이미 대화 중이라면, AI에게 이렇게 말하세요:

```
지식창고의 CLAUDE.md(헌법)를 다시 읽고, 그 규칙대로 방금 작업을 마무리해줘
```

### Q7. 설정 파일을 고쳤더니 Claude Desktop이 이상해요 / 연결해 둔 도구가 전부 사라졌어요

설정 파일(JSON)에 오타가 생기면 — 쉼표 하나, 따옴표 하나만 빠져도 — 전체 설정이 무시됩니다. *JSON: 설정을 적는 텍스트 형식. 문법이 엄격합니다.*

설정 파일 위치:

| 컴퓨터 | 위치 |
|---|---|
| Mac | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

**해결**: 설정 파일을 열어 내용 전체를 복사한 뒤, AI에게 이렇게 말하세요:

```
아래 JSON에 문법 오류가 있는지 찾아서, 고친 전체 내용을 다시 보여줘:
(여기에 붙여넣기)
```

AI가 준 내용으로 파일을 통째로 바꿔 저장하고, Claude Desktop을 **완전히 종료 후 재실행**하세요 (Q8의 재시작 방법 참조).

## 법령 검색 (korean-law MCP)

*MCP: AI 앱에 외부 도구(법령 검색 등)를 연결하는 표준 방식.*

### Q8. 법령 검색 도구가 안 보여요

설정을 저장해도 **앱을 완전히 재시작하기 전에는** 반영되지 않습니다. 창만 닫는 것은 재시작이 아닙니다.

| 컴퓨터 | 완전 종료 방법 |
|---|---|
| Mac | Claude Desktop 활성 상태에서 **Cmd+Q** (또는 메뉴 막대 → Claude → 종료) 후 다시 실행 |
| Windows | 창 닫기 후 **작업 표시줄 오른쪽 트레이의 Claude 아이콘 → 마우스 오른쪽 클릭 → 종료(Quit)** 후 다시 실행 |

✅ **이렇게 되면 성공**: 재실행 후 대화창의 도구 목록에 법령 검색(korean-law) 도구가 보이고, "화장품법 최신 조문 찾아줘" 같은 요청에 도구를 사용합니다.
❗ 재시작해도 안 보이면: 설정 파일 오타(Q7) 또는 OC 오타(Q9)를 확인하세요.
❗ 오타가 없는데도 두 번 이상 재시작해도 안 보이면: 내 Claude Desktop이 `url` 한 줄 형식을 지원하지 않는 버전일 수 있습니다 → `2_도구/법령검색_MCP_설정.md`의 대체 형식(`mcp-remote` 방식) 또는 부록 5의 로컬 설치 방식으로 바꿔 다시 시도하세요.

### Q9. 법령 도구는 보이는데 오류가 나거나 빈 결과만 나와요

**OC(인증키) 오타**가 가장 흔한 원인입니다. OC는 국가법령정보 공동활용(open.law.go.kr)에 무료 가입할 때 쓴 **이메일 주소의 @ 앞부분**입니다. 예: 가입 이메일이 `hong123@example.com`이면 OC는 `hong123`.

**해결**: 설정 파일(Q7의 위치)을 열어 주소 속 `oc=` 뒤의 값을 확인하세요:

```
https://mcp.gomdori.app/law?oc=본인OC
```

`본인OC` 자리에 @ 앞부분이 정확히 들어 있는지, `< >` 같은 괄호가 남아 있지 않은지 확인하고, 고친 뒤 완전 재시작(Q8)하세요. 자세한 설정 과정은 `2_도구/법령검색_MCP_설정.md`를 보세요.

## 매일 사용

### Q10. 한글 파일(.hwp)이 변환되지 않아요

**해결 순서**:

1. 지식창고의 `tools/rhwp` 폴더에 변환 프로그램이 들어 있는지 확인하세요 (설치 때 자동으로 들어갑니다).
2. AI에게 이렇게 말하세요:

```
tools 폴더의 hwp2md.py로 DATA 폴더의 (파일이름).hwp를 변환해서 정리해줘
```

3. 그래도 안 되면 **우회 방법**: 한글 프로그램에서 그 파일을 열어 **PDF로 저장**한 뒤, PDF를 `DATA`에 넣고 정리를 부탁하세요. PDF 변환은 별도 도구(markitdown)로 처리됩니다.

자세한 도구 설명은 `2_도구/도구_사용법.md`를 보세요.

### Q11. 질문했는데 "위키에 해당 내용이 없습니다"라고만 해요

고장이 아니라 **정상 동작**입니다. 이 창고의 AI는 근거 없는 답을 지어내지 않도록 되어 있습니다. 셋 중 하나를 하세요.

1. **자료가 아직 없는 경우** — 관련 자료를 `DATA`에 넣고 "자료 넣었어, 정리해줘"라고 하세요. 다음부터는 답합니다.
2. **말만 바꿔 다시 묻기** — 정리 때 쓴 용어와 질문 용어가 다르면 못 찾을 수 있습니다. ("영업신고" ↔ "인허가"처럼 바꿔 보세요.)
3. **대화로 정리하기** — 그 자리에서 AI와 논의해 결론을 만들고, AI가 "📌 위키에 남길까요?"라고 물으면 "응"이라고 하세요.

또 하나: 주 1회 "건강검진해줘"를 하면 목차·연결이 정리되어 찾기 성능이 좋아집니다 (`3_사용법/매일_쓰는_법.md` ③).

### Q12. 의뢰인 실명(개인정보)이 위키에 들어갔어요

위키에는 실명·연락처·사업자번호가 절대 남으면 안 됩니다 (운영 규칙 5번). 발견 즉시 아래 절차대로 지우세요.

**1단계 — AI에게 이렇게 말하세요** (○○○ 자리에 실명):

```
wiki 폴더 전체에서 "○○○"을 검색해줘. 나오는 모든 페이지에서 그 실명을
"한 의뢰인" 같은 익명 표현으로 바꾸고, wiki/index.md와 wiki/log.md에
남아 있으면 거기서도 지워줘. 끝나면 다시 검색해서 0건인지 보여줘.
```

✅ **이렇게 되면 성공**: AI가 재검색 결과 "0건"을 보여줍니다. 전화번호·사업자번호 등 다른 정보도 같은 문장으로 반복하세요.

**2단계 — 원본 격리**: 실명이 든 원본 파일이 `DATA`에 있다면, 직접 `서류함` 폴더로 옮기세요(드래그). 사건 자료의 자리는 처음부터 `서류함`입니다.

**3단계 — 백업 확인**: `4_확장/GitHub_백업.md`의 백업을 이미 쓰고 있다면 백업본에도 남아 있을 수 있습니다. 위 정리를 마친 뒤 백업을 새로 만드는 것이 안전합니다.

**재발 방지**: 사건 자료는 `서류함`에만 넣고, 위키에는 익명화한 노하우만 반영하도록 되어 있습니다. AI가 이 규칙을 어기면 Q6(헌법 재읽기)을 확인하세요.

## 비용

### Q13. 매달 돈이 얼마나 드나요? 쓰다 보면 요금이 더 나오지 않나요?

**드는 비용은 AI 앱 구독료뿐입니다** — Claude Pro 이상 또는 ChatGPT Plus 이상 (금액은 각 서비스 안내 참조).

그 외에는 추가 비용이 없습니다:

- 이 패킷의 도구(변환 도구·지식그래프 등)는 전부 **무료·오픈소스**입니다.
- 법령 검색의 OC(인증키)도 **무료**입니다.
- 별도의 **API 사용료(쓴 만큼 내는 종량 요금)는 발생하지 않습니다.** 이 패킷은 API 방식이 아니라 구독 앱 안에서 작동합니다. *API: 프로그램이 AI를 호출할 때마다 건별로 요금을 내는 방식 — 여기서는 쓰지 않습니다.*

## 백업 · PC 교체

### Q14. 컴퓨터를 바꿉니다. 지식창고를 어떻게 옮기나요?

지식창고의 전부(헌법·위키·기억·자료)는 **폴더 하나 안의 파일**입니다. 폴더를 통째로 복사하면 이사가 끝납니다.

1. 이전 PC에서 지식창고 폴더(기본 이름 JARVIS)를 통째로 외장하드·USB(또는 클라우드 드라이브)에 복사합니다.
2. 새 PC에서 `0_설치`의 설치를 먼저 진행합니다.
3. 복사해 둔 폴더를 새 PC의 원하는 위치(권장: 홈 폴더 아래)에 붙여넣습니다.
4. AI 앱에서 그 폴더를 다시 연결합니다 (Q5 참조). 법령 검색을 쓰고 있었다면 새 PC에서 `2_도구/법령검색_MCP_설정.md`를 한 번 더 진행합니다.

✅ **이렇게 되면 성공**: 새 PC에서 "지난번에 정리한 ○○ 보여줘"라고 물었을 때 예전 그대로 답합니다.

### Q15. 백업을 자동으로 하고 싶어요 / 동료와 지식을 나누고 싶어요

- **자동 백업**: `4_확장/GitHub_백업.md` — GitHub Desktop 앱(무료)으로 지식창고의 변경 이력을 통째로 백업하는 방법입니다. 컴퓨터 고장·실수 삭제에 대비할 수 있어, 자료가 소중해지기 전에 빨리 해 둘수록 좋습니다.
- **지식 공유·연합**: `4_확장/지식연합_토대.md` — 여러 사람이 각자의 지식창고를 유지하면서 익명화된 노하우를 나누는 토대를 설명합니다.
