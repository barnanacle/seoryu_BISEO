### 3. 건강검진 (Audit) — 트리거: "건강검진" / "점검해줘"

**점검 범위는 `wiki/`·`memory/`와 `1_자료실/`의 파일 이름까지다. `2_서류철/`·`3_작업실/`·동봉 설명서 폴더는 열지 않는다** (안전 2).

1. **미처리 자료** — 처리 대장과 `1_자료실/`을 대조해 정리 안 된 파일을 먼저 정리한다. 보류 항목은 매 검진마다 한 줄씩 재보고한다 (말없이 영영 미루지 않기).
2. **깨진 링크** — 존재하지 않는 페이지를 가리키는 `[[위키링크]]`를 찾는다. **백틱(`` ` ``) 안에 있는 예시 표기는 세지 않는다** — `index.md`·허브 템플릿의 서식 설명에 들어 있는 것이라 깨진 링크가 아니다.
3. **고아 페이지** — `index.md`에 없는 페이지 + 링크가 하나도 없는 외딴 페이지 + 허브와 이어지지 않은 페이지를 찾는다.
4. **index 정합** — `index.md` 목록과 실제 `wiki/` 파일이 일치하는지, 서식이 지켜졌는지 확인한다.
5. **내용 모순** — 같은 주제를 다르게 기술한 곳을 찾는다.
6. **페이지 규격** — 맨 앞 `> **핵심**` 콜아웃이 빠진 페이지를 찾는다.
7. **연결 기회** — 아직 링크되지 않았지만 이어질 만한 페이지 쌍을 제안하고, **분야를 넘는 연결의 비율**도 함께 보고한다.
8. **개인정보 자동 점검** — `python3 tools/pii_check.py`를 돌려 `wiki/`·`memory/`에 남은 이름·번호·금액을 찾는다. 실행할 수 없으면 같은 9종을 눈으로 훑는다. 걸린 줄은 사용자에게 보여주고 익명화 수정본을 제안한다. **걸린 것이 없어도 "안전이 확인됐다"고 말하지 않는다** — "규칙에 걸리는 줄은 없었습니다"까지만 보고한다.

이어서 기억 승격(단기 → 장기)을 한 번 돌리고, 마지막으로 현황판을 새로 그릴지 한 줄로 제안한다.
결과를 요약 보고하고, 수정은 사용자 확인 후 반영한다. 이번에 다 못 한 항목은 `wiki/log.md`에 **「건강검진 이월 과제」 체크리스트 블록**으로 남겨 다음 검진 때 맨 먼저 회수한다.

위키 수정 전에는 `운영규칙/위키작성.md`, 기억 승격 전에는 `운영규칙/기억운영.md`를 읽는다.
