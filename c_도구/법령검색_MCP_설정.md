# 법령검색 MCP 설정 — AI가 현행 법령·판례를 직접 찾아 인용하게 만들기

> **이 문서는 언제 보나**: AI 답변에 "현행 법령 원문 근거"를 붙이고 싶을 때 봅니다. 선택 기능입니다 — 연결하지 않아도 지식창고는 잘 돌아갑니다.

> 이 문서는 **Claude Desktop 기준**입니다. Codex 앱을 쓰신다면 이 단계는 건너뛰셔도 됩니다.

---

## 1. 이게 되면 무엇이 좋아지나

먼저 용어 하나만 알고 갑니다.

- **MCP**: AI 앱에 외부 도구를 꽂아 주는 연결 규격입니다. 스마트폰에 앱을 설치하듯, AI에게 "법령 검색 능력"을 설치한다고 생각하시면 됩니다.

AI는 기본적으로 학습 시점의 기억으로 법령을 이야기합니다. 그래서 최근 개정을 모르거나, 조문 번호를 틀리게 말할 수 있습니다.

**법령검색 MCP(korean-law-mcp v4.6.4)** 를 연결하면 달라집니다.

- AI가 법제처 국가법령정보(42개 API)를 **그 자리에서 직접 검색**해 답합니다.
- 9개 도구가 들어 있습니다: `legal_research`(다단계 법령 리서치), `legal_analysis`(인용한 조문이 맞는지 검증), `time_travel`(과거 시점 법령과 현행 비교), `action_plan`(처리 절차 설계) 등.
- 예: "이 조문 지금도 유효한가요?" → AI가 현행 조문을 확인한 뒤 시행일과 함께 답합니다.

행정사 업무에서 근거 조문의 정확성은 생명입니다. 이 기능 하나로 AI 답변의 신뢰도가 크게 올라갑니다.

---

## 2. 준비물 — OC(인증키) 무료 발급

- **OC**: 국가법령정보 OPEN API의 개인 인증키입니다. 법제처가 "이 사람이 검색을 요청했다"를 확인하는 열쇠입니다. 발급은 무료입니다.

발급 절차:

1. 인터넷 브라우저에서 **국가법령정보 공동활용** 사이트 접속 → `open.law.go.kr`
2. **회원가입** (무료). 이메일 주소로 가입합니다.
3. 로그인 후 **OPEN API 활용 신청** 메뉴에서 신청서를 작성합니다. (활용 목적은 "업무 참고용 법령 조회" 정도로 적으면 됩니다)
4. 신청이 완료되면 OC를 쓸 수 있습니다.
5. **OC = 가입한 이메일의 @ 앞부분**입니다. 예: `hong@naver.com`으로 가입했다면 OC는 `hong`.

✅ **이렇게 되면 성공**: 내 OC 문자열(이메일 아이디 부분)을 메모장에 적어 두셨으면 이 단계 완료입니다.

## 3. Claude Desktop에 연결하기 (기본 방법 — 원격 URL 방식, 추가 프로그램 설치 불필요)

### 3-1. 설정 파일 열기

두 가지 방법 중 편한 것을 쓰세요.

**방법 A — 앱 안의 설정 메뉴에서 (권장)**

1. Claude Desktop에서 **설정(Settings)** 을 엽니다.
   - Mac: 화면 맨 위 메뉴바 → **Claude → Settings…**
   - Windows: 앱 왼쪽 위 메뉴 → **Settings**
2. **개발자(Developer)** 탭 → **설정 편집(Edit Config)** 버튼을 누릅니다. (버전에 따라 이름이 조금 다를 수 있습니다)
3. 설정 파일이 들어 있는 폴더가 열립니다. `claude_desktop_config.json` 파일을 **마우스 오른쪽 클릭**으로 엽니다:
   - Mac: 오른쪽 클릭 → **다음으로 열기** → **텍스트 편집기(TextEdit)**. "응용 프로그램 선택" 창이 뜨면 텍스트 편집기를 고르세요.
   - Windows: 오른쪽 클릭 → **연결 프로그램**(또는 "열기 방식") → **메모장**. "이 파일을 열 방법 선택" 창이 떠도 고장이 아닙니다 — 메모장을 고르면 됩니다.

**방법 B — 폴더를 직접 찾아가기**

| 구분 | 방법 |
|---|---|
| **Mac** | Finder → 상단 메뉴 **이동 → 폴더로 이동…** → 아래 경로 붙여넣기 → 파일 오른쪽 클릭 → **다음으로 열기 → 텍스트 편집기** |
| **Windows** | 파일 탐색기 주소창에 아래 경로 붙여넣기 → Enter → 파일 오른쪽 클릭 → **연결 프로그램 → 메모장** |

Mac 경로:

```
~/Library/Application Support/Claude
```

Windows 경로:

```
%APPDATA%\Claude
```

⚠️ Mac의 '텍스트 편집기'로 편집할 때는 **붙여넣기만** 하세요. 따옴표를 직접 타이핑하면 둥근 따옴표(“ ”)로 자동 변환되어 설정이 깨질 수 있습니다.

### 3-2. 내용 붙여넣기

- **JSON**: 컴퓨터가 읽는 설정 문서 형식입니다. 중괄호 `{ }`와 쉼표 `,` 위치가 중요하니, 아래 블록을 그대로 복사해 쓰세요.

**경우 1 — 파일이 비어 있거나 `{}`만 있을 때**: 아래 내용으로 전체를 교체합니다.

```json
{
  "mcpServers": {
    "korean-law": {
      "url": "https://mcp.gomdori.app/law?oc=<본인OC>"
    }
  }
}
```

- `<본인OC>` 자리에 2단계에서 메모한 OC를 넣습니다. **`<`, `>` 기호까지 지우고** 넣으세요. 예: OC가 `hong`이면 → `"url": "https://mcp.gomdori.app/law?oc=hong"`

**경우 2 — 이미 다른 항목이 들어 있을 때** (예: filesystem 등): 전체를 지우지 말고, **korean-law 부분만 추가**합니다. 기존 마지막 항목 뒤에 쉼표(`,`)를 붙이고 그 아래에 넣습니다. 완성 예시:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\hong\\JARVIS"]
    },
    "korean-law": {
      "url": "https://mcp.gomdori.app/law?oc=hong"
    }
  }
}
```

**만약 위 `url` 형식이 동작하지 않는다면** (Claude Desktop 구버전): 아래 형식으로 korean-law 부분만 바꿔 보세요. 단, 이 형식은 **부록(5번)의 Node.js 설치가 먼저** 필요합니다.

```json
"korean-law": {
  "command": "npx",
  "args": ["-y", "mcp-remote", "https://mcp.gomdori.app/law?oc=<본인OC>"]
}
```

저장하는 것을 잊지 마세요. (Mac: ⌘+S / Windows: Ctrl+S)

### 3-3. 앱 완전 재시작 (필수)

창을 닫는 것만으로는 적용되지 않습니다. **완전히 종료 후 다시 실행**해야 합니다.

| 구분 | 완전 종료 방법 |
|---|---|
| **Mac** | 메뉴바 **Claude → Quit Claude** (또는 ⌘+Q) → 다시 실행 |
| **Windows** | 작업 표시줄 오른쪽 끝 트레이의 Claude 아이콘 → 마우스 오른쪽 클릭 → **종료(Quit)** → 다시 실행 |

## 4. 잘 됐는지 확인하기

AI에게 이렇게 말하세요:

> "화장품법 최신 개정 확인해줘"

(본인 분야의 아무 법령이나 물어봐도 됩니다. 예: "행정사법 최신 개정 확인해줘")

✅ **이렇게 되면 성공**: 답변 과정에서 **도구 사용 표시**가 나타납니다 — "korean-law 도구 사용을 허용하시겠습니까?" 같은 팝업(→ 허용을 누르세요)이나 도구 아이콘이 보이고, 답변에 공포일·시행일 등 구체적 정보가 인용됩니다.

❌ **도구 표시가 안 보이면**: 설정 파일의 쉼표·따옴표·OC 오타를 확인하고 다시 완전 재시작하세요. 그래도 안 되면 오류 화면을 AI에게 보여 주세요.

---

## 5. (부록) 로컬 설치 방법 — 원격 방식이 안 될 때만

기본 방법(3번)은 인터넷 너머의 서버를 이용하므로 아무것도 설치할 필요가 없습니다. 사정상 원격 방식이 안 될 때만 아래처럼 내 컴퓨터에 직접 설치합니다.

1. **Node.js LTS 설치** — `nodejs.org` 접속 → **LTS** 버튼 다운로드 → 인스톨러 실행(계속 "다음"만 누르면 됩니다). Mac·Windows 동일합니다.
2. 설정 파일의 korean-law 부분을 아래로 바꿉니다 (내 컴퓨터의 Node가 원격 서버에 연결하는 방식 — `<본인OC>` 치환):

```json
"korean-law": {
  "command": "npx",
  "args": ["-y", "mcp-remote", "https://mcp.gomdori.app/law?oc=<본인OC>"]
}
```

3. 앱 완전 재시작(3-3) → 확인(4번)을 똑같이 진행합니다.

❌ 안 되면: Node.js 설치 후 컴퓨터를 한 번 재부팅하고 다시 시도 → 그래도 안 되면 오류 화면을 AI에게 보여 주세요.

---

## 6. OC 키 취급 주의

- OC는 **본인 명의의 인증키**입니다. 설정 파일 밖으로 공유하지 마세요.
- 특히 단톡방·블로그·질문 게시글에 설정 내용을 붙여넣을 때는 `oc=` 뒷부분을 반드시 가리세요.
- 유출이 의심되면 `open.law.go.kr`에서 키를 변경(재발급)하고, 설정 파일의 OC도 새 값으로 바꾼 뒤 앱을 재시작하면 됩니다.
- 문제가 생겨 원래대로 돌리고 싶으면: 설정 파일에서 korean-law 부분을 지우고 저장 → 앱 완전 재시작. 지식창고에는 아무 영향이 없습니다.
