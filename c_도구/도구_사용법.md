# 도구 사용법 — 자료를 md로 바꾸기

> **이 문서는 언제 보나**: 1_자료실 폴더에 넣은 PDF·워드·엑셀·한글(HWP) 파일이 위키에 정리되지 않을 때, "md 변환"이 뭔지 궁금할 때 봅니다.

---

## 1. 왜 변환이 필요한가요? (30초 설명)

지식창고의 AI는 **md(마크다운)** 형식의 글을 가장 잘 읽습니다.

- *마크다운(md)*: 서식이 아주 단순한 텍스트 문서입니다. 메모장으로도 열립니다.

PDF·워드·한글(HWP) 파일은 그대로는 위키에 정리되지 않습니다.
그래서 먼저 **md로 바꾸는 도구 2개**가 지식창고의 tools 폴더에 들어 있습니다.
(설치 과정에서 변환 코드가 운영 폴더의 `tools/`로 합쳐집니다.)

| 도구 | 하는 일 |
|---|---|
| `convert2md.py` | PDF·워드·엑셀·파워포인트·이미지 → md |
| `hwp2md.py` | 한글 문서(.hwp / .hwpx) → md |

---

## 2. 가장 쉬운 방법 — AI에게 말로 시키기 (권장)

**직접 실행할 필요 없습니다.** AI에게 이렇게 말하세요:

> "1_자료실에 넣은 한글 파일을 md로 변환해줘"

> "1_자료실/인허가 폴더의 PDF 전부 md로 바꿔줘"

> "이 파일 변환하고, 위키에 정리까지 해줘"

**이렇게 되면 성공**: 원본 파일 옆에 같은 이름의 `.md` 파일이 생기고, AI가 "성공 N건"이라고 보고합니다. 원본 파일은 그대로 남아 있습니다.

**안 되면**: AI에게 한 번 더 이렇게 말하세요:

> "tools 폴더의 convert2md.py(일반 문서)와 hwp2md.py(한글 문서)를 사용해서 변환해줘"

그래도 안 되면 AI에게 오류 문구를 그대로 보여주고, `tools/안내_파일변환.md`를 읽어 원인을 점검해 달라고 하세요.

---

## 3. 지원 포맷 표

| 파일 종류 | 확장자 | 사용하는 도구 | 비고 |
|---|---|---|---|
| PDF | .pdf | convert2md.py | 스캔본(사진 찍은 PDF)은 글자가 안 나올 수 있음 |
| 워드 | .docx | convert2md.py | .doc(아주 오래된 형식)은 워드에서 .docx로 다시 저장 후 변환 |
| 엑셀 | .xlsx, .xls, .csv | convert2md.py | 표 형태로 변환됨 |
| 파워포인트 | .pptx | convert2md.py | 슬라이드 글자 위주로 변환됨 |
| 이미지 | .jpg, .png 등 | convert2md.py | 정보가 거의 안 나옴 — AI 대화창에 직접 첨부 권장 |
| 한글 | .hwp, .hwpx | hwp2md.py | 본문·표·그림 추출. 그림은 `<문서명>_img` 폴더에 저장 |

두 도구 모두 **폴더를 주면 하위 폴더까지 한꺼번에** 변환합니다.
이미 `.md`가 있는 파일은 건너뜁니다(다시 변환하려면 AI에게 "force로 다시 변환해줘"라고 말하면 됩니다).

## 4. (참고) 직접 실행하는 법 — 몰라도 됩니다

AI에게 시키는 것으로 충분합니다. 그래도 직접 해보고 싶다면:

**Mac** — Spotlight(돋보기)에서 "터미널"을 열고, 아래를 복사해 붙여넣으세요.
(지식창고를 홈 폴더의 JARVIS로 만든 경우 기준입니다. 위치가 다르면 경로를 바꿔 주세요.)

```
cd ~/JARVIS/tools
python3 convert2md.py ../1_자료실
python3 hwp2md.py ../1_자료실
```

**Windows** — 시작 메뉴에서 "명령 프롬프트"를 열고, 아래를 복사해 붙여넣으세요.

```
cd %USERPROFILE%\JARVIS\tools
python convert2md.py ..\1_자료실
python hwp2md.py ..\1_자료실
```

**이렇게 보이면 성공**: 파일마다 `✅ 완료:` 줄이 나오고, 마지막에 `===== 변환 결과 =====`와 "성공 N건" 요약이 나옵니다.

- 파일 1개만 변환하려면 폴더 대신 파일 경로를 적으세요. 예: `python3 hwp2md.py ../1_자료실/의견서.hwp`
- 다시 변환하려면 뒤에 `--force`를 붙이세요.
- 도구는 필요한 부품(파이썬 패키지·rhwp)을 스크립트가 있는 `tools/`에서 찾습니다. 없으면 AI가 설치 방법을 설명하고 승인을 받은 뒤 준비합니다.

**실패하면**: 화면에 나온 한국어 안내를 AI에게 그대로 보여 주세요. `rhwp를 찾을 수 없습니다`가 나오면 AI에게 "tools의 HWP·HWPX 변환 환경을 준비해줘"라고 요청합니다.

## 5. 변환 품질의 한계 — 솔직하게 알려드립니다

변환은 "지식 정리용"입니다. **원본 서식을 그대로 재현하는 도구가 아닙니다.**

- **표**: 글자 내용은 대부분 살아남습니다. 다만 칸 합치기가 많은 복잡한 표는 모양이 어긋날 수 있습니다.
- **그림**: 한글 문서 속 그림은 `<문서명>_img` 폴더로 꺼내져 본문에 링크됩니다. 하지만 **그림 속 글자는 읽지 못합니다.** 그림 내용이 중요하면 AI 대화창에 그림을 직접 첨부해 물어보세요.
- **스캔본 PDF**: 종이를 사진 찍거나 스캔한 PDF는 글자 추출이 안 될 수 있습니다. 이때는 "내용 없음"으로 표시됩니다 → 파일을 AI에게 직접 첨부하는 편이 낫습니다.
- **암호·배포용 문서**: 암호가 걸렸거나 편집이 제한된 한글 문서는 변환되지 않습니다.
- **도장·서명·줄맞춤**: 재현되지 않습니다.
- **같은 이름 주의**: `보고서.pdf`와 `보고서.docx`가 같은 폴더에 있으면 결과가 둘 다 `보고서.md`가 되어, 먼저 변환된 쪽만 남습니다. 파일 이름을 다르게 해 주세요.

변환 결과가 이상하면 그대로 두지 말고, AI에게 이렇게 말하세요:

> "방금 변환된 md를 원본과 비교해서 이상한 부분을 정리해줘"

---

## 6. 자주 하는 질문 한 줄 요약

- **원본이 지워지나요?** — 아니요. 원본은 절대 수정·삭제되지 않습니다. md가 옆에 하나 더 생길 뿐입니다.
- **변환만 하면 위키에 들어가나요?** — 아니요. 변환된 md를 AI가 읽고 정리해야 위키에 들어갑니다. "자료 넣었어, 정리해줘"라고 말하세요.
- **법령 검색은요?** — 파일 변환이 아니라 별도 기능입니다. `tools/안내_법령검색.md`를 보세요.

그 밖의 문제는 오류 문구와 함께 AI에게 점검을 요청하세요.

## 지식 지도 보조 도구 (AI 자동 사용 — 직접 실행 불필요)

- `graph_normalize.py` — 지식 지도의 중복 점(같은 페이지 이중 등록) 자동 병합. AI가 지도 갱신 직후 실행.
- `graph_report_inferred.py` — 아직 링크 안 된 가까운 페이지 쌍 후보 리포트(이미 링크된 쌍 자동 제외). 건강검진의 「연결 기회」 입력.

상세: `graphify_설정.md` §3.5

## 행정처분 의견서 작성기

사전통지 → 법률 요건을 반영한 질문지 → 같은 대화의 답변·상담기록 → 의견제출서·별지·전체 편집용 DOCX → 증빙 변경 반영 순서로 사용합니다. 설치된 `tools/opinion_writer/README.md`와 `사용_시퀀스.md`를 읽어 주세요. 공문만 받은 단계에서는 의견서보다 질문지가 먼저 출력됩니다.
