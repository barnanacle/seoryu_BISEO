# 지식연합 토대 — 개인 지식창고에서 공동 지식체계로

> **이 문서는 언제 보나**: 내 지식창고가 자리를 잡은 뒤, "회원들의 지식이 모이면 어떤 그림이 되나"가 궁금할 때 읽습니다.

⚠️ **이 문서는 실행 지침이 아니라 비전 문서입니다.** 지금 따라 할 절차는 없습니다. 모든 것의 전제는 **각자의 지식창고가 먼저 서 있는 것** — 즉 이 패킷의 나머지 문서들을 마치는 일입니다.

## 1. 큰 그림 — 개인 위키에서 연합 지식체계로

```
[회원 A의 PC]  wiki (개인 지식창고) ─┐
[회원 B의 PC]  wiki (개인 지식창고) ─┼─ 익명화·일반화된 노하우만 선별 ─→ [공동 저장소] ─→ 회원 전체가 검색·활용
[회원 C의 PC]  wiki (개인 지식창고) ─┘    (GitHub Organization 또는 외부 DB)
```

- 각자의 `wiki/`는 각자의 **단일 진실 공급원(SSOT)** — 자기 지식의 원본은 언제나 자기 PC에 있습니다. 연합이 생겨도 이 원칙은 변하지 않습니다.
- 공동 저장소로 나가는 것은 **익명화·일반화를 마친 노하우 파일뿐**입니다. 의뢰인 자료·`2_업무철/`·`1_자료실/` 원본은 절대 나가지 않습니다.
- 이렇게 모인 파일이 쌓이면, 회원 누구나 검색해 쓰는 **거대 지식체계**가 됩니다. 혼자서는 평생 만나기 어려운 사건 유형의 노하우를, 연합 안에서는 검색 한 번으로 만납니다.

처음 나오는 용어 풀이:

| 용어 | 한 줄 풀이 |
|---|---|
| GitHub Organization(오거나이제이션) | 여러 사람이 함께 관리하는 깃허브 공동 계정·보관함 (`e_확장/GitHub_백업.md`에서 배운 개인 저장소의 단체판) |
| 외부 DB(데이터베이스) | 깃허브 대신 별도 서버에 지식을 모아 검색을 제공하는 방식. 어느 쪽을 택할지는 아래 5번의 미결정 사항입니다 |

## 2. 선별 게이트 — 무엇이 나가고, 무엇이 남는가

연합의 신뢰는 이 게이트 하나에 달려 있습니다.

- **개인정보·의뢰인 식별 정보 제로 원칙**: 실명·회사명·제품명·접수번호·금액·연락처·주소 — 이 중 하나라도 남아 있으면 그 파일은 기여할 수 없습니다.
- 기여하기 전에, 각자 자기 AI에게 익명화 점검을 시킵니다.

AI에게 이렇게 말하세요:

```
이 노하우 파일을 회원 공동 저장소에 올리려고 해.
의뢰인 실명·회사명·제품명·접수번호·금액·연락처·주소가 남아 있는지 전부 점검해 줘.
남아 있으면 "한 의뢰인의 경우" 같은 익명 표현으로 바꾼 수정본을 만들어 줘.
```

- 점검을 통과한 파일만 내보냅니다. **애매하면 올리지 않는다** — 이것이 기본값입니다.
- 이 습관은 이미 여러분의 헌법에 들어 있습니다(원칙 5: 의뢰인 실명·개인정보 wiki 절대 금지, 노하우만 익명화 후 반영). 연합은 그 습관을 밖으로 한 걸음 넓힌 것뿐입니다.

## 3. 단계 로드맵

| 단계 | 내용 | 필요한 것 |
|---|---|---|
| **1단계 — 각자 구축** | 회원 각자가 자기 PC에 지식창고를 세우고 매일 씁니다 | 이 패킷 전체. **지금 우리가 있는 단계** |
| **2단계 — 노하우 교환** | 익명화된 노하우 파일을 회원끼리 파일 단위로 주고받아 각자 wiki에 반영합니다 | 위 2번 선별 게이트의 습관화 |
| **3단계 — 공동 위키 리포** | GitHub Organization에 공동 위키 저장소를 열고, 선별된 파일을 한곳에 쌓습니다 | `e_확장/GitHub_백업.md`로 익힌 GitHub 사용 경험 |
| **4단계 — 공동 그래프·검색** | 공동 위키에 지식그래프(graphify)를 얹어, 분야를 넘는 연결과 검색을 회원 전체에 제공합니다 | `c_도구/graphify_설정.md`로 익힌 경험의 공동 확장 |

각 단계는 앞 단계가 익은 뒤에만 의미가 있습니다. 1단계 없이 3단계는 없습니다.

## 4. 표준이 힘이다

연합이 가능한 이유는 기술이 아니라 **모두가 같은 규격으로 쓰기 때문**입니다. 이 패킷이 정한 규칙이 곧 연합의 호환 규격입니다.

- **콜아웃 규칙** — 모든 페이지 맨 앞 `> **핵심**` 3줄. 어느 회원이 쓴 페이지든 첫 3줄만 읽으면 요지가 잡힙니다.
- **교차참조 규칙** — `[[위키링크]]`. 각자 따로 쓴 파일도 한곳에 모으는 순간 서로 연결됩니다.
- **인덱스 규칙** — `wiki/index.md`의 카테고리별 목차. 저장소를 합쳐도 목차를 기계적으로 병합할 수 있습니다.

이 규격의 원문은 `b_시작/templates/CLAUDE.md`(헌법 템플릿)에 있습니다. **표준을 지켜 쓰는 것 자체가, 아직 오지 않은 연합에 대한 오늘의 기여입니다.**

## 5. 아직 정해지지 않은 것 (정직한 표기)

다음 항목들은 이 문서가 답을 정하지 않습니다. **협회 차원의 논의와 의결이 필요한 미결정 사항**입니다.

| 미결정 사항 | 논의할 질문 |
|---|---|
| 품질 검수 | 기여된 파일을 누가, 어떤 기준으로 검수하나 |
| 기여 크레딧 | 기여자를 어떻게 기록하고, 어떻게 보상하나 |
| 접근 권한 | 회원 등급·참여 수준에 따라 열람·기여 범위를 어떻게 나누나 |
| 운영 주체·비용 | 공동 저장소(Organization 또는 외부 DB)의 관리 책임과 비용은 누가 지나 |

이런 항목이 정해지기 전까지 회원 각자가 할 수 있는 가장 확실한 준비는 두 가지입니다: **1단계(자기 지식창고 구축)를 단단히 하는 것**, 그리고 **2번 선별 게이트(익명화 점검)를 습관으로 만드는 것**입니다.
