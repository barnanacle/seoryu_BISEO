# 붙여넣기 프롬프트 — 이것 하나면 지식창고가 만들어집니다

> 📌 **강의(Codex 앱) 수강자·처음 시작하는 분은 이 문서가 필요 없습니다.** 내려받은 꾸러미의 **ZIP 루트가 이미 완성형 지식창고**입니다(헌법 `AGENTS.md`·목차·일지·처리 대장·memory·서류함 시드 완료) — 그 폴더를 Codex로 열고 "자료 넣었어, 정리해줘" 한 마디면 끝입니다(→ `Codex_설치_상세.md` 3절). 이 문서는 **빈 폴더에 인터뷰로 «내 이름·분야 맞춤» 창고를 새로 짓는 선택 경로**입니다.

> **이 문서는 언제 보나**: 맞춤 구축을 원할 때, `앱설치_설정.md`를 끝낸 직후. 아래 회색 상자를 통째로 복사해 앱에 붙여넣으면 됩니다.

---

## 1. 붙여넣기 전 확인 3가지

세 칸이 모두 체크되어야 합니다. 하나라도 안 되어 있으면 `앱설치_설정.md`로 돌아가세요.

- [ ] **앱이 설치되고 로그인**되어 있다
- [ ] 이 패킷 **ZIP을 받아 압축을 풀었고**, 그 폴더 경로를 알고 있다
- [ ] **폴더를 두 개 연결**했다 — 빈 `JARVIS`(기본·쓰기용) **와** 압축 푼 `install_JAARVIS`(읽기용), 승인 모드는 "승인 요청" (→ `앱설치_설정.md` 4절)

> ⚠️ 세 번째 칸에서 **패킷 폴더를 빠뜨리는 분이 가장 많습니다.** 그러면 아래 [2]의 쓰기 시험은 통과하는데 [3]에서 "설계도를 못 읽겠습니다" 하고 멈춥니다.

---

## 2. 이 프롬프트를 복사해서 붙여넣으세요

**바꿔 넣을 곳은 딱 두 군데입니다** — `<패킷폴더 경로>` 와 `<지식창고 경로>`. 나머지는 그대로 두세요.

```
너는 지금부터 내 개인 지식체계를 만들어 주는 조수다. 한국어로, 나에게는 존댓말로 말해라.
아래 [0]~[6]을 순서대로 그대로 실행하고, 각 단계가 끝날 때마다 한 줄로 결과를 알려라.

[0] 지켜야 할 규칙 (무조건)
  - 이미 있는 파일을 덮어쓰지 않는다. 있으면 건너뛰고 없는 것만 만든다.
  - 아래 두 폴더 밖의 파일은 만들지도 고치지도 않는다.
  - 인터넷에 접속해야 하는 일이 생기면 먼저 나에게 허락을 구한다.
  - 이 패킷 폴더 안의 파일은 절대 고치지 않는다(읽기만).
  - 의뢰인 이름·전화번호·사업자등록번호·접수번호·금액은 서류함 폴더 밖으로 옮기지 않는다.
    내가 가리지 않은 실명·번호를 그대로 적어 보내더라도 거부하지 말고, 저장하기 전에
    가린 형태를 먼저 보여주고 확인을 받아라.

[1] 경로 확인
  - 패킷 폴더: <패킷폴더 경로>            ← 예: /Users/이름/install_JAARVIS
  - 지식창고 폴더: <지식창고 경로>         ← 기본: Mac ~/JARVIS, Windows C:\Users\이름\JARVIS
  두 경로가 비어 있거나 존재하지 않으면 나에게 다시 물어보고 멈춰라.

[2] 두 가지를 먼저 시험 (가장 중요 — 둘 다 성공해야 [3]으로 간다)
  (가) 쓰기 시험: 지식창고 폴더에 빈 파일 `_쓰기점검.txt` 를 만들어 보고, 성공하면 지워라.
  (나) 읽기 시험: <패킷폴더 경로>/5_챗지피티/BOOTSTRAP_CHATGPT.md 의 첫 줄을 읽어서 보여줘라.
  두 결과를 각각 한 줄로 알려라.
  - (가) 실패 → 즉시 멈추고: "이 대화는 아직 제 컴퓨터 폴더에 파일을 만들 수 없습니다.
    5_챗지피티/앱설치_설정.md 의 4절(폴더 연결)과 5절(승인 모드)을 보고 확인한 뒤
    이 프롬프트를 다시 붙여넣어 주세요."
  - (나)만 실패 → 즉시 멈추고: "패킷 폴더가 아직 앱에 연결되지 않았습니다 —
    앱설치_설정.md 4절 5번대로 패킷 폴더도 함께 연결해 주세요.
    (연결하지 않으면 승인 창을 매번 눌러야 하고, 설계도를 읽지 못해 진행이 안 됩니다.)"
```

## 3. 붙여넣은 뒤 무엇이 나와야 정상인가

✅ **이렇게 되면 성공**: AI가 아래 세 가지를 순서대로 보여줍니다.

1. **쓰기 점검 결과** — "지식창고 폴더에 파일을 만들 수 있었습니다" 같은 보고 (승인 창이 떴다면 **허용**을 눌러 주세요)
2. **읽기 점검 결과** — 패킷 폴더의 `BOOTSTRAP_CHATGPT.md` 첫 줄을 실제로 읽어서 보여줍니다
3. **인터뷰 첫 질문** — "성함과 직함이 어떻게 되세요?" 로 시작하는 질문 묶음

이제부터는 묻는 말에 편하게 답하시면 됩니다. 모르겠으면 **"기본값으로 해주세요"** 라고 하셔도 됩니다. 다만 **11번(의뢰인 자료 취급)과 16번(명함 공개 동의)** 두 개는 건너뛸 수 없으니 꼭 읽고 답해 주세요.

인터뷰 12~16문항을 미리 보고 싶으시면 → `1_시작/설정_인터뷰.md` · `5_챗지피티/명함_인터뷰.md`

## 4. 이렇게 나오면 (분기)

### ❗ "패킷 폴더를 찾을 수 없습니다" / "설계도를 읽지 못했습니다" — 다시 시도

**0. 패킷 폴더도 앱에 연결했는지 먼저 확인하세요.** ← 이것이 1순위 원인입니다.
경로를 아무리 정확히 적어도, **연결되지 않은 폴더는 읽지 못하거나 매번 승인 창이 뜹니다.** → `앱설치_설정.md` **4절 5번**.

그다음이 경로 문제입니다.

1. 압축을 **정말 풀었는지** 확인하세요 (ZIP 파일 그대로는 안 됩니다).
2. 경로를 다시 복사해 붙여넣으세요 — 꺾쇠(`< >`)가 남아 있지 않은지, 앞뒤에 따옴표가 붙지 않았는지 봅니다.
3. 폴더 이름에 한글·띄어쓰기가 섞여 있으면 경로가 깨지기 쉽습니다. `다운로드` 안쪽 깊은 곳보다 **홈 폴더 바로 아래**로 옮겨 두고, 옮긴 뒤 **연결도 새 위치로 다시** 하세요.

### ❗ 승인 창이 떴다 — 정상입니다

**허용**을 누르세요. 이 트랙은 "물어보고 실행하는" 방식이 기본입니다(→ `앱설치_설정.md` 5절).

**패킷 폴더처럼 연결된 폴더 밖을 읽을 때 창이 뜨는 것은 정상입니다.** 창이 너무 자주 떠서 힘들다면, 대개 **패킷 폴더를 연결하지 않아서**입니다 — 두 폴더를 모두 연결해 두면 눈에 띄게 줄어듭니다(→ `앱설치_설정.md` 4절 5번). (Mac이라면 지식창고가 바탕화면·다운로드·문서 폴더에 있지 않은지도 함께 보세요.)

### ❌ "파일을 만들 수 없습니다" — 여기서 멈추세요

가장 중요한 갈림길입니다. 이 상태로는 **더 진행해도 지식창고가 만들어지지 않습니다.**

1. `앱설치_설정.md` **4절(폴더 연결)** 과 **5절(승인 모드)** 로 돌아가 다시 확인하세요.
2. 특히 승인 모드가 **읽기 전용**으로 되어 있지 않은지 보세요.
3. Windows에서 폴더 연결이 안 되거나 관리자 승인·회사 정책에 막혔다면 → `문제해결_보충.md` **C3**.
4. 여러 번 해도 안 되면 → `README.md` 3절 **B 레인**(폴더 없이 프로젝트만 쓰기)으로 제한적으로 쓰세요. 지식창고 자동 생성·대시보드·명함은 되지 않습니다.

### ❌ AI가 설계도를 안 읽고 자기 마음대로 만들기 시작한다

바로 멈추게 하세요.

```
잠깐 멈춰. 지금까지 만든 것을 목록으로 알려주고,
<패킷폴더 경로>/5_챗지피티/BOOTSTRAP_CHATGPT.md 를 먼저 읽은 뒤 그 순서대로 다시 진행해줘.
```

이미 만들어진 파일은 지우지 않아도 됩니다. 설계도는 **이미 있는 것은 건너뛰고 빠진 것만 채우도록** 되어 있습니다.

## 5. 프로젝트 지침 칸에 넣을 3줄 (한 번만)

앱의 프로젝트 설정에 **지침(Instructions)** 을 적는 칸이 있습니다. 여기에 아래 3줄을 넣어 두면, 그 프로젝트에서 새 대화를 열 때마다 자동으로 적용됩니다.

```
나는 행정사다. 이 프로젝트의 작업 폴더 안에 있는 AGENTS.md를 일 시작 전에 항상 먼저 읽고 그 규칙을 따라라.
의뢰인 이름·전화번호·사업자등록번호·접수번호·금액은 서류함 폴더 밖으로 옮기지 마라.
내가 가리지 않은 실명·번호를 적어 보내면 거부하지 말고, 저장 전에 가린 형태를 보여주고 확인을 받아라.
새 파일을 만들거나 무엇을 지우거나 밖으로 내보내기 전에는 나에게 한 줄로 확인을 받아라.
```

*이 지침은 **해당 프로젝트 안에서만** 적용되고, 계정 전체에 걸어 둔 설정보다 우선합니다. 그래서 업무용 프로젝트와 개인용 대화를 섞지 않는 것이 좋습니다.*

❗ **지침 칸이 안 보이면**: 넣지 않아도 진행됩니다. 대신 새 대화를 열 때마다 지식창고 안의 `시작프롬프트.md`를 채팅창에 끌어다 놓으세요 — 같은 효과입니다.
