## C1. 잘 쓰다가 갑자기 "잠시 뒤 다시 시도하세요"라고 나와요 (가장 흔함)

**고장이 아니라 사용량 한도입니다.** 정해진 시간 안에 쓸 수 있는 양에 상한이 있고, 넘으면 잠깐 쉬어야 합니다.

- 대체로 **몇 시간 단위(예: 5시간)로 굴러가는 한도** + **주 단위 한도**가 함께 걸립니다.
- 시간이 지나면 **저절로 풀립니다.** 앱을 지우고 다시 깔 필요 없습니다.
- **이미지 생성은 한도를 몇 배 빠르게** 깎습니다. 명함 작업을 몰아서 하면 그날 한도가 금방 찹니다.

**아껴 쓰는 법**

| 방법 | 왜 효과가 있나 |
|---|---|
| 질문을 짧게, 한 번에 하나씩 | 주고받는 양이 곧 소모량입니다 |
| 관련 자료만 올리기 | 안 보는 파일도 읽는 양에 들어갑니다 |
| 규칙서(`AGENTS.md`) 크기 줄이기 | 매번 읽는 파일이라 소모가 반복됩니다 → C5 |
| 가벼운 모델로 바꾸기 | 간단한 정리·질문은 가벼운 쪽으로 충분합니다 |
| 안 쓰는 확장·연결 끄기 | 매 대화에 딸려 들어가는 것을 줄입니다 |
| 인터뷰·정리를 나눠서 하기 | 한 번에 다 안 해도 이어서 할 수 있습니다 |

✅ **이렇게 되면 성공**: 시간이 지난 뒤 다시 보내면 평소처럼 답합니다.

## C2. AI가 파일을 못 만들어요 / 설계도를 못 읽어요

> 📌 이 항목의 0·4번(패킷 폴더·경로)은 **맞춤 구축(붙여넣기_프롬프트) 경로에서만** 해당합니다. 강의 경로(ZIP 루트를 그대로 여는 «바로 쓰기»)는 연결하는 폴더가 **한 개**라 0번이 없습니다 — 그 경우 1·2·3·5번만 보세요.

지식창고가 안 만들어지는 **1순위 원인**입니다. 순서대로 확인하세요.

0. **패킷 폴더도 연결했나** ← **여기서 막히는 분이 가장 많습니다.**
   연결할 폴더는 **두 개**입니다 — 빈 `JARVIS`(쓰기용)와 압축 푼 `install_JAARVIS`(읽기용). 패킷 폴더를 빠뜨리면 **쓰기 시험은 통과하는데 그다음 단계에서 "설계도를 읽지 못했습니다" 하고 멈춥니다.** → `앱설치_설정.md` **4절 5번**.
   확인: `install_JAARVIS 폴더의 README.md 첫 줄을 읽어줘` 라고 물어 실제로 읽어 주는지 보세요.
1. **지식창고 폴더가 연결되어 있나** — 앱에서 `JARVIS` 폴더를 **기본 폴더로** 추가했는지 (`앱설치_설정.md` 4절). "지금 연결된 폴더에 뭐가 있어?"라고 물어 확인하세요.
2. **승인 모드가 읽기 전용은 아닌가** — "승인 요청" 계열이어야 합니다 (`앱설치_설정.md` 5절).
3. **승인 창을 놓치지 않았나** — 창이 떴는데 다른 곳을 클릭해 사라졌을 수 있습니다. 다시 시도하고 **허용**을 누르세요.
4. **경로가 맞나** — 연결한 폴더와 프롬프트에 적은 `<지식창고 경로>`가 **글자 하나까지** 같아야 합니다.
5. **앱을 완전히 닫았다 다시 열기** — 설정 변경은 재시작해야 적용되는 경우가 있습니다.

여기까지 해도 안 되면 → C3, 그래도 안 되면 `README.md` 3절 **B 레인**으로 제한적으로 쓰세요.

## C3. (Windows) 폴더 연결이 안 돼요 / 관리자 승인·회사 정책에 막혔어요

**먼저 볼 것 — 「이 프로젝트를 로컬 채팅에 쓸 수 없습니다」류 오류**
(`Could not use this project for a local chat`)

기존 ChatGPT 프로젝트 **안에서** 로컬 폴더를 만들려 할 때 나는 오류로, **Windows에서 보고된 알려진 문제**입니다. 내 컴퓨터나 계정 잘못이 아닙니다.
→ **프로젝트 밖에서 Codex로 폴더를 새로 연결**해 보세요. 그 경로에서는 정상 동작한다고 보고돼 있습니다. (→ `앱설치_설정.md` 4절)

**관리자 승인(UAC) 창** *(보통은 뜨지 않습니다 — 뜨는 환경에서만 해당)*

- **개인 PC이고 내가 관리자라면**: 앱을 완전히 종료 → 다시 실행 → 승인 창이 뜨면 **예**를 누르세요. 계정이 관리자인지 확인하려면 `설정 → 계정`에서 "관리자"로 표시되는지 보세요.
- **거절한 채로 계속 쓰고 싶다면**: 그래도 앱은 동작합니다. 다만 일부 기능이 제한될 수 있으니, **C2의 쓰기 시험이 통과하는지**로 판단하세요. 통과하면 그대로 진행하셔도 됩니다.
- **회사 지급 노트북이라면**: 보안정책으로 막히는 경우가 많고, 임의로 푸는 것은 권하지 않습니다. **개인 PC에서 하세요.** 회사 PC에 의뢰인 자료를 두는 것 자체가 위험하기도 합니다.

❗ 관리자 권한을 얻으려고 보안 설정을 임의로 끄지 마세요. 이 패킷의 어떤 기능도 그럴 만한 가치는 없습니다.

## C4. (Mac) 승인 창이 계속 떠서 진도가 안 나가요

**작업 폴더 위치가 잘못됐을 가능성이 큽니다.** macOS는 **바탕화면·다운로드·문서** 폴더를 특별히 보호해서, 여기에 지식창고를 두면 파일을 만들 때마다 허용 창이 다시 뜹니다.

**해결**: 지식창고를 **홈 폴더 바로 아래**(`/Users/<내이름>/JARVIS`)로 옮기세요.

1. Finder에서 `⌘`+`⇧`+`H` (홈 폴더)
2. 기존 `JARVIS` 폴더를 여기로 **드래그해 옮깁니다**
3. 앱에서 폴더 연결을 **새 위치로 다시** 합니다 (`앱설치_설정.md` 4절)
4. AI에게 새 경로를 알려 주세요: `지식창고 경로가 /Users/<내이름>/JARVIS 로 바뀌었어. 앞으로 여기를 써줘.`

✅ **이렇게 되면 성공**: 파일을 만들 때 허용 창이 더 이상 뜨지 않습니다.

## C5. AI가 규칙서 뒷부분을 무시해요 (개인정보 점검을 건너뛴다 등)

**규칙서가 너무 커진 것입니다.** AI가 일 시작 전에 읽는 규칙서는 일정 크기를 넘으면 **뒷부분이 조용히 잘려** 나갑니다. 오류 메시지가 없어서 알아채기 어렵습니다.

하필 잘리는 곳이 규칙서 **끝부분** — 이 패킷에서는 개인정보 점검·저장 금지 규칙이 있는 자리라서 위험합니다.

**확인**: AI에게 이렇게 물어보세요.

```
AGENTS.md 파일 크기가 얼마야? 그리고 그 파일 맨 마지막 줄을 그대로 읽어줘.
```

마지막 줄을 못 읽거나 엉뚱한 것을 읽으면 잘린 것입니다.

**해결**

1. **A4 8~10쪽(약 30KB) 아래로 줄이세요.**
2. 줄이는 방법: 지식·법령 설명은 `wiki/`로, 일하는 방식·절차는 `memory/업무규칙.md`로 옮깁니다. 규칙서에는 **규칙만** 남깁니다.
3. AI에게 부탁해도 됩니다: `AGENTS.md가 너무 커. 지식에 해당하는 부분은 wiki로, 일하는 방식은 memory/업무규칙.md로 옮기고 규칙서는 30KB 아래로 줄여줘.`
4. 줄인 뒤 **`CLAUDE.md`도 같은 내용으로** 맞추세요 (두 파일은 항상 같아야 합니다).

## C6. 명함을 만들었는데 공개 주소(Sites) 메뉴가 안 보여요

**계정에 따라 아예 없을 수 있습니다.** 이 기능은 **유료 요금제 + 공개 베타 + 지역 제한**이 겹쳐 있습니다. 특히 유럽경제지역(EEA)·스위스·영국에서는 현재 쓸 수 없는 것으로 안내되고 있습니다.

**메뉴가 없다고 명함을 못 만드는 것이 아닙니다.** 배포 방법이 세 가지이고, 기본 권장은 원래 B입니다.

| 분기 | 방법 | 비고 |
|---|---|---|
| A | 공개 주소로 배포 | 메뉴가 보일 때만 |
| **B** | **로컬 `index.html` 파일을 그대로 전달** (메일 첨부·USB·QR) | **가장 안전하고 확실** |
| C | 별도 공개 저장소 + GitHub Pages | 인터넷 주소가 꼭 필요할 때 |

자세한 절차 → `명함_만들기.md` **8절 「전달하기 — 세 갈래 길」**

## C7. 이미지가 안 만들어져요

- **무료 요금제는 이미지 생성 한도가 매우 작습니다(사실상 몇 장).** 유료로 올리거나, 이미지 없이 진행하세요.
- **이 트랙의 명함은 원래 이미지가 필요 없습니다.** 이름·전화·직함은 **반드시 글자(HTML 텍스트)로** 넣습니다. 그림으로 만들면 글자가 틀리게 그려질 수 있어서 금지하고 있습니다.
- 배경·장식용 이미지가 안 되면 그냥 **색과 선만으로** 만드세요. `명함_디자인표.md`의 디자인 축은 모두 색·배치·글꼴·선으로 구성되어 있어 이미지 없이도 충분히 달라 보입니다.
- 이미지 생성은 **사용량 한도를 몇 배 빠르게** 깎으니, 한도가 걱정되면 안 쓰는 편이 낫습니다(→ C1).

## C8. 레포 주소를 붙여넣었는데 아무 일도 안 일어나요

**주소만 준다고 자동으로 받아오지 않습니다.** 그런 자동 경로는 이 패킷을 만들 때 확인되지 않았습니다. **ZIP으로 받으세요.**

1. 브라우저에서 `https://github.com/barnanacle/install_JAARVIS`
2. 초록색 **Code** → **Download ZIP**
3. 압축 해제 → 그 폴더 경로를 프롬프트의 `<패킷폴더 경로>`에 넣기

**페이지가 404로 안 열린다면**: 저장소는 **공개**라 로그인 없이 열립니다. 주소 오타를 확인하세요 — `github.com/barnanacle/install_JAARVIS` (**JAARVIS**, A가 두 개입니다). 회사 네트워크에서 GitHub가 차단된 경우에는 개인 네트워크나 휴대폰 테더링으로 시도해 보세요.

자세히 → `앱설치_설정.md` 6절

## C9. 대시보드를 열었는데 화면이 비어 있어요

**숫자를 아직 채워 넣지 않은 상태**입니다. 대시보드는 미리 계산해 둔 숫자를 보여주는 방식이라, 한 번은 "새로 그리기"를 해야 합니다.

1. AI에게: `대시보드 새로 그려줘` — 이 말은 규칙서(`AGENTS.md`) 「네 가지 동작」 4번에 절차가 적혀 있어 AI가 알아듣습니다.
2. 파이썬을 못 돌리거나 앱이 프로그램을 실행하지 못하면: `대시보드 숫자만 새로 채워줘` (스크립트 없이 AI가 손으로 채웁니다 → `대시보드_사용법.md` 5-2)
3. 그래도 비어 있으면: 아직 정리된 위키 페이지가 없는 것입니다. 자료를 한 건 넣고 정리한 뒤 다시 해 보세요.

자세히 → `대시보드_사용법.md`

> ⚠️ 대시보드 파일(`dashboard.html`)에는 의뢰인 관련 파일명이 들어갈 수 있습니다. **웹에 올리거나 메일로 보내지 마세요.**

## C10. 법령 원문을 AI가 직접 못 찾아요

**법령 도구를 아직 붙이지 않은 상태입니다.** 이 트랙은 법령 조회 도구를 **부탁 한 문장**으로 연결하게 되어 있습니다 → `법령도구_연결.md` §2. 붙이고 나면 조문·별표·시행일을 AI가 법제처 원문에서 직접 조회합니다.

(참고로 패킷의 `2_도구/법령검색_MCP_설정.md`는 **Claude Desktop 기준**이라 이 트랙에서는 보지 않아도 됩니다.)

**도구를 붙이기 전이거나, 붙였는데 안 될 때**

1. 붙였는데 도구를 안 쓰면 → `법령도구_연결.md` **§5 「막혔을 때」** — 대부분 앱을 완전히 껐다 켜면 해결됩니다.
2. 그동안 법령 원문은 **법제처 국가법령정보센터(`law.go.kr`)** 에서 직접 확인하세요.
3. 확인한 조문을 **복사해 대화창에 붙여넣고** 검토를 부탁하세요. AI가 원문을 근거로 답합니다.
4. 확인한 조문은 위키에 정리해 두세요 — 다음부터는 내 지식창고가 근거가 됩니다.
5. 위키에 근거가 없으면 AI는 "위키에 해당 내용이 없습니다"라고 답하게 되어 있습니다.

❗ 의뢰인에게 나가는 문서에 쓰는 조문은, 도구 조회든 직접 확인이든 **최종본에서 한 번 더 원문과 대조**하는 습관을 권합니다.
