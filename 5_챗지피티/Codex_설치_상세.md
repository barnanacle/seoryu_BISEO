# Codex 앱 설치와 설정 — 화면 하나하나

> **이 문서는 언제 보나**: 가장 먼저. 강의장에서는 「함께 ①·②」 단계에서 같이 합니다.
> **끝나면 무엇이 되나**: 내 컴퓨터 폴더를 읽고 쓰는 AI + 법령을 직접 조회하는 AI
> **걸리는 시간**: 설치·로그인 10분 · 폴더 연결 5분 · 법령 도구 10분 = **25분**
>
> 📌 이 문서는 **«Codex 앱» 기준 안내**입니다. 값이 싸고 설치가 가장 단순해서 예시로 골랐습니다.
> 다른 앱(Claude Code·ChatGPT 채팅창 등)을 쓰셔도 이 꾸러미는 그대로 씁니다 — `README.md`의 「어떤 앱으로 하나」 표를 보세요.

---

## 0. 먼저 — 무엇이 «반드시» 필요한가

가장 많이 받는 질문부터 답합니다.

| 항목 | 필수인가 | 비용 | 설명 |
|---|---|---|---|
| **ChatGPT 계정** | ✅ **필수** | **유료(Plus 이상)** | Codex는 ChatGPT 계정으로 로그인합니다 |
| **Codex 앱** | ✅ **필수** | 무료 | 앱 자체는 무료로 받습니다 |
| **법제처 인증키(OC)** | ✅ 필수 *(법령 도구를 쓸 때)* | **무료** | 법제처 사이트 회원가입이 필요합니다 |
| **GitHub 계정** | ❌ **필요 없습니다** | — | 꾸러미는 공개 저장소라 **로그인 없이 ZIP**으로 받습니다 |
| **Node.js 설치** | ❌ 필요 없습니다 | — | 이 문서는 «원격 주소» 방식이라 설치가 없습니다 |
| **API 키 발급·붙여넣기** | ❌ 필요 없습니다 | — | ChatGPT 계정으로 로그인하면 끝입니다 |
| **파이썬** | 🟡 있으면 좋음 | 무료 | 현황판을 그릴 때만. 없으면 AI에게 시키면 됩니다 |

> ### 정리하면 — **가입해야 하는 곳은 두 곳뿐입니다.**
> ① **ChatGPT**(유료 구독) ② **법제처 Open API**(무료)
> GitHub는 가입도, 로그인도 하지 않습니다.

**⚠️ 유료 구독에 대해 정직하게**: Codex는 ChatGPT 유료 플랜에서 동작합니다. 무료 계정으로는 지식창고를 만드는 도중 사용량 한도에 걸립니다. 이건 우리가 정한 게 아니라 서비스 정책이고, 2026년 7월 확인 기준이며 플랜 정책은 바뀔 수 있습니다.

## 1. Codex 앱 설치

### 🍎 Mac

1. 브라우저에서 **`https://openai.com/codex`** 접속 → **Download for macOS** 클릭
2. 받은 **`Codex.dmg`** 를 더블클릭
3. 열린 창에서 **Codex 아이콘을 `Applications`(응용 프로그램) 폴더로 끌어다 놓기**
4. `Applications` 폴더에서 **Codex** 실행
5. *"인터넷에서 다운로드한 앱입니다"* 경고가 뜨면 **열기** 클릭

> 📸 `img/01-mac-dmg.png` — DMG 창. **왼쪽 Codex 아이콘을 오른쪽 Applications 폴더로 드래그**

```
┌─────────── Codex.dmg ───────────┐
│                                 │
│    [Codex]  ──드래그──▶  [Applications]  │
│     아이콘               폴더            │
└─────────────────────────────────┘
```

### 🪟 Windows

1. **시작 메뉴 → Microsoft Store** 실행
2. 검색창에 **`Codex`** 입력 → OpenAI에서 만든 **Codex** 선택
3. **설치** 버튼 클릭 → 끝나면 **열기**

> 📸 `img/02-win-store.png` — Microsoft Store 검색 결과. **«설치» 버튼 위치**

❗ **Store가 막혀 있거나 안 보이면**: 회사 지급 PC의 정책일 수 있습니다. 개인 PC를 쓰시거나, `https://openai.com/codex` 에서 직접 내려받는 방법을 확인하세요.

## 2. 로그인 — API 키는 없습니다

앱을 처음 열면 로그인 화면이 나옵니다.

1. **`Sign in with ChatGPT`** 버튼 클릭
2. 브라우저가 열리면 **ChatGPT 계정으로 로그인**
3. *"Codex에 계정 정보 연결을 허용하시겠습니까?"* → **계속(Continue)** 클릭
4. 브라우저에 *"이제 앱으로 돌아가셔도 됩니다"* 가 뜨면 Codex 앱으로 돌아옵니다

> 📸 `img/03-signin.png` — 로그인 화면. **«Sign in with ChatGPT» 버튼**
> 📸 `img/04-consent.png` — 브라우저 동의 화면. **«Continue» 버튼**

✅ **이렇게 되면 성공**: 앱 화면에 대화 입력창이 보이고, 오른쪽 위(또는 좌측 하단)에 내 계정이 표시됩니다.

❗ **«API 키를 입력하세요»가 나온다면**: 다른 화면에 들어간 것입니다. 뒤로 가서 **Sign in with ChatGPT** 를 찾으세요. **우리는 API 키를 쓰지 않습니다.**

## 3. 지식창고 폴더 준비 — 내려받은 꾸러미가 곧 창고입니다

이 꾸러미의 ZIP 루트는 **바로 쓰는 완성형 지식창고**입니다. 헌법(`AGENTS.md`)·목차(`wiki/index.md`)·일지·처리 대장·기억 노트(`memory/`)·격리 구역(`서류함/`)이 **이미 세팅**되어 있어, 내려받아 풀고 여는 것으로 끝입니다. (강의 4부 «함께 ②»가 바로 이 절차입니다.)

### 3-1. 꾸러미 ZIP 받기 — GitHub 가입 없이

1. 브라우저에서 **`https://github.com/barnanacle/install_JAARVIS`** 접속
2. 초록색 **`Code`** 버튼 클릭 → **`Download ZIP`**
3. 받은 ZIP을 압축 해제 (Mac: 더블클릭 / Windows: 오른쪽 클릭 → 압축 풀기)

> 📸 `img/05-github-zip.png` — GitHub 페이지. **초록색 «Code» 버튼 → «Download ZIP» 위치**

```
┌── github.com/barnanacle/install_JAARVIS ──┐
│                            ┌──────────┐   │
│                            │ ▾ Code   │◀── 여기
│  README.md                 └──────────┘   │
│  AGENTS.md                  ├ Clone       │
│  DATA/ · wiki/ · memory/    ├ Open with   │
│  0_설치/ … 5_챗지피티/        └ Download ZIP │◀── 이거
└───────────────────────────────────────────┘
```

✅ **로그인 창이 뜨지 않습니다.** 공개 저장소라 누구나 바로 받습니다.

### 3-2. 홈 폴더 바로 아래로 옮기기

압축 푼 폴더를 **홈 폴더 바로 아래로** 옮깁니다. 이름은 그대로 두어도 되고 `JARVIS`로 바꿔도 됩니다.

| | 두는 위치 (예) |
|---|---|
| Mac | `/Users/<내계정이름>/install_JAARVIS` (또는 `/Users/<내계정이름>/JARVIS`) |
| Windows | `C:\Users\<내계정이름>\install_JAARVIS` |

> ❗ **바탕화면·다운로드·문서 폴더에 두지 마세요.** 그 폴더들은 운영체제가 보호해서, AI가 읽고 쓸 때마다 허용 창이 뜹니다. 쓰는 동안 수십 번 뜹니다.

폴더 안의 `0_설치`~`5_챗지피티`와 `README.md`는 **동봉 설명서**입니다 — 그대로 두면 됩니다. 헌법(`AGENTS.md`)이 정리 대상에서 알아서 제외합니다.

### 3-3. (선택) 빈 폴더에 맞춤 구축하는 길

인터뷰에 답해 **내 이름·분야로 맞춤 생성**되는 창고를 원하면, 빈 `JARVIS` 폴더를 따로 만들고 이 꾸러미를 읽기용으로 연결하는 경로도 있습니다 → `붙여넣기_프롬프트.md`. **처음이라면 3-1·3-2의 «바로 쓰기»를 권합니다** — 강의도 그 절차로 진행합니다.

## 4. Codex에 폴더 연결하기

1. Codex 앱에서 **폴더 열기**(Open Folder / 프로젝트 추가)를 찾습니다 — 보통 **좌측 상단 또는 시작 화면의 «Open»**
2. 3-2에서 옮겨 둔 **꾸러미(지식창고) 폴더**를 선택
3. **접근을 허용하시겠습니까?** 창이 뜨면 **허용**
4. (3-3의 맞춤 구축 경로를 쓰는 경우에만) 빈 `JARVIS` 폴더와 꾸러미 폴더 **두 개**를 연결합니다

> 📸 `img/06-open-folder.png` — 폴더 열기 화면. **«Open» 버튼 위치**
> 📸 `img/07-permission.png` — 접근 허용 창. **«허용» 버튼**

```
┌──────────── Codex ─────────────┐
│ ⌂  Open ▾   ⚙︎                 │◀── Open: 폴더 연결 / ⚙︎: 설정
│ ─────────────────────────────  │
│  연결된 폴더                    │
│   • install_JAARVIS (지식창고)  │
│ ─────────────────────────────  │
│  [ 여기에 입력하세요...      ] │◀── 대화 입력창
└────────────────────────────────┘
```

### 승인 모드 — 「물어보고 하기」로 두세요

Codex가 파일을 고칠 때마다 **승인을 요청**하는 모드로 둡니다. 처음에는 번거롭지만, **무엇을 하는지 보면서 배우게 되고 사고를 막습니다.**

의뢰인 자료가 들어갈 폴더이므로 **«전체 허용»은 권하지 않습니다.**

✅ **여기까지 성공 확인** — 대화창에 이렇게 쳐 보세요.

```
자료 넣었어, 정리해줘
```

→ AI가 헌법(`AGENTS.md`)을 읽고 처리 대장과 대조해 **"새 파일 없음"** 을 보고하면 성공입니다. (첫 자료를 넣는 방법은 `지식넣기_사용법.md`)

### 4.5 사이드바 지도 — 메뉴가 뜻하는 것 (실측 2026-07-30)

Codex 앱 왼쪽 사이드바의 메뉴는 다섯 개 + 토글 하나입니다. 이 트랙에서 쓰는 것은 굵게 표시했습니다.

| 메뉴 | 뜻 |
|---|---|
| **새 작업** | 대화(작업)를 새로 시작합니다 — 평소에 쓰는 곳입니다 |
| 풀 리퀘스트 | 개발자용 코드 검토 기능입니다. 이 트랙에서는 쓰지 않습니다 |
| **사이트** | 만든 웹페이지를 인터넷 주소로 올리는 기능입니다. 전자명함 배포에 씁니다 (→ `명함_만들기.md` 8절) |
| 예약됨 | 정해 둔 시각에 작업을 자동 실행하는 예약 기능입니다. 이 트랙에서는 쓰지 않습니다 |
| **플러그인** | 완성된 도구를 클릭으로 설치하는 목록입니다 (→ `법령도구_연결.md` §3) |
| **«나 대신 승인» 토글** | 켜면 확인 창 없이 AI가 알아서 진행합니다 — 의뢰인 자료가 있는 폴더에서는 **끄고(매번 확인)** 쓰시기를 권합니다 |

### 4.6 요금제와 기능 — 어디까지 무엇이 되나

| 하려는 것 | 필요한 것 |
|---|---|
| 조문 조회·문서 검토 등 **기본 대화** | ChatGPT 계정 **로그인만으로** 됩니다 (무료 계정도 동작은 하지만 **한도가 매우 작아** 구축 도중 걸립니다 → 0절) |
| 폴더 연결·지식창고 구축 | 유료 플랜 권장 — 읽고 쓰는 양이 많습니다 |
| 사이트 **«게시»** (명함을 인터넷 주소로) | **유료 플랜 기능** — 무료(Free)·Go 플랜은 안 됩니다. ※2026-07 시점 기준이며 **앱 안에 표시되는 안내가 최종**입니다. 한도는 플랜별로 다르고 수치는 공개돼 있지 않습니다 |

## 5. 법령 도구 붙이기 — 말로 부탁하면 됩니다

AI가 조문·별표를 법제처 원문에서 **직접 조회**하게 만듭니다. 설치도, 설정 파일 편집도 없습니다 — **Codex에게 말로 부탁하면 설정은 Codex가 알아서 합니다.** 리듬은 넷입니다.

1. **부탁** — *«한국 법령을 조회하는 korean-law 도구를 연결해줘. 필요한 설치와 설정은 네가 알아서 해줘.»*
2. **승인** — 설정을 만지겠다는 확인 창이 뜨면 **허용**
3. **재시작** — 앱을 완전히 껐다 켭니다 (새 도구는 켜질 때 붙습니다)
4. **확인** — *«행정사법 제2조를 법령 도구로 조회해봐»*

부탁 문장 원문, 법제처 인증키(무료) 발급 화면, 플러그인 메뉴·설정 화면 경로, 막혔을 때 표까지 —
**전체 절차는 → `법령도구_연결.md` §2 「말로 부탁하기」** 에 있습니다.

## 7. 증상별 문제해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 앱이 안 열린다 (Mac) | 보안 경고 | 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 «확인 없이 열기» |
| Store에 Codex가 없다 (Win) | 회사 정책·지역 | 개인 PC 사용, 또는 `openai.com/codex` 직접 다운로드 |
| «API 키를 입력하세요» | 다른 로그인 화면 | 뒤로 → **Sign in with ChatGPT** |
| 폴더를 못 읽는다 | 연결 안 됨 / 승인 거부 | 폴더를 다시 연결하고 허용 |
| 허용 창이 계속 뜬다 | 바탕화면·다운로드 폴더 사용 | 홈 폴더 바로 아래로 폴더를 옮긴다 |
| 도구를 안 쓴다 | 설정 미반영 | **앱 완전 종료 후 재실행** |
| «사용자 정보 검증 실패» | 인증키 오타·공백 | 키를 다시 복사해 넣는다 |
| 조회가 됐다 안 됐다 | 법제처 서버 불안정 | 잠시 후 재시도 |
| 법령 도구가 그 밖의 이유로 안 붙는다 | 승인·재시작·로그인 팝업 함정 | `법령도구_연결.md` **§5 「막혔을 때」** → 그래도 안 되면 같은 문서 부록(설정 파일 직접 편집) |
| 갑자기 아무 응답 없음 | **사용량 한도** | 시간을 두고 재시도 · `문제해결_보충.md` C1 |
