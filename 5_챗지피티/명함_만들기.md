# 전자명함 만들기 — 링크 하나로 건네는 명함

> **이 문서는 언제 보나**: 지식창고를 다 만든 뒤, 내 소개를 링크 한 줄로 건네고 싶을 때 봅니다. 지식창고가 아직이라면 `README.md`부터 보세요.

---

## ⚠️ 시작 전에 — 명함은 지식창고 **밖**에 만듭니다

이 패킷에서 **밖으로 나가는 산출물은 명함 하나뿐**입니다. 나머지(지식창고·서류함·대시보드)는 전부 내 PC 안에만 있습니다. 그래서 명함은 **아예 다른 폴더**에 따로 만듭니다.

```
내 컴퓨터
├── JARVIS/           ← 지식창고 (절대 공개 금지 · 의뢰인 자료 포함)
└── JARVIS_명함/      ← 명함 (여기만 공개)   ← 형제 폴더. 서로 안에 들어가지 않습니다
```

| 컴퓨터 | 명함 폴더 위치 |
|---|---|
| Mac | `/Users/<사용자이름>/JARVIS_명함` |
| Windows | `C:\Users\<사용자이름>\JARVIS_명함` |

**왜 이렇게까지 하나**: 폴더 하나만 통째로 공개 전환하는 실수가 나도, 의뢰인 자료가 있는 폴더가 애초에 그 안에 없으면 사고가 나지 않습니다. 규칙으로 막는 것보다 **구조로 막는 편이 안전**합니다.

지켜야 할 세 가지:

1. `JARVIS_명함` 폴더에 **지식창고 파일을 복사해 넣지 않습니다.**
2. 나중에 인터넷 저장소(GitHub)에 올린다면, 지식창고 저장소와 **별개의 저장소**를 씁니다.
3. 대시보드(`dashboard.html`)는 이 폴더에 넣지 않습니다 — 대시보드는 비공개, 명함은 공개입니다.

> 💡 **폴더 승인이 한 번 더 필요할 수 있습니다.** 지금 앱에 연결된 폴더는 지식창고(`JARVIS`)와 패킷 폴더(`install_JAARVIS`) 두 개입니다. 명함 폴더는 그 **밖**이라, 파일을 만들려 하면 앱이 승인을 물어봅니다. 창이 뜨면 **명함 폴더만** 허용해 주세요. 승인이 막히면 아래 3절의 「승인이 안 될 때」를 보세요.

## 1. 준비물과 걸리는 시간

| 준비물 | 내용 |
|---|---|
| 지식창고 | 이미 만들어 두셨어야 합니다 (인터뷰 1~12번 답이 있어야 합니다) |
| 이 패킷 폴더 | `5_챗지피티/templates/` 안의 `card_index.html`·`card_style_pick.py`를 씁니다 |
| 파이썬 | **없어도 됩니다.** 없으면 AI가 손으로 계산합니다 |
| 인터넷 주소로 배포 | **필수가 아닙니다.** 파일만으로도 명함 구실을 합니다. 주소를 원하면 사이트 기능으로 게시합니다 (아래 8절) |

| 단계 | 시간 |
|---|---|
| 추가 인터뷰(13~16번) | 약 10분 |
| 디자인 결정 + 파일 생성 | 약 5분 |
| 점검과 전달 | 약 10분 |

```
[1] 인터뷰 13~16번  →  [2] 디자인 자동 결정  →  [3] index.html 만들기  →  [4] 점검 후 전달
```

| 단계 | 무엇 | 자세히 |
|---|---|---|

| [3] | 명함 폴더에 `index.html` 한 장을 만듭니다 | 아래 3절 |
| [4] | 공개 직전 점검을 통과한 뒤 전달합니다 | 아래 4·5절 |

## 3. AI에게 시키기

새 대화에서 아래를 **그대로 복사해 붙여넣으세요.**

**바꿔 넣을 곳은 맨 앞 두 줄입니다** — `<패킷폴더 경로>` 와 `<지식창고 경로>`. `붙여넣기_프롬프트.md` 2절에서 쓰신 것과 **같은 경로**입니다. 꺾쇠(`< >`)까지 지우고 경로만 남기세요.

> **왜 경로를 또 적나**: 새 대화에는 앞 대화의 기억이 남지 않습니다. 같은 프로젝트라도 **파일을 공유할 뿐 대화 내용은 이어지지 않습니다.** 그래서 명함에 쓸 이름·업무는 대화가 아니라 **지식창고 파일에서 다시 읽어 오게** 합니다.

```
전자명함을 만들어줘. 아래 순서를 지켜줘.

패킷 폴더: <패킷폴더 경로>
지식창고 폴더: <지식창고 경로>

0) 먼저 <지식창고 경로>/AGENTS.md 를 읽고 내 이름·직함·주요 업무 3가지를 가져와.
   거기에 없는 항목만 나에게 물어봐. 지어내지 마.

1) <패킷폴더 경로>/5_챗지피티/명함_인터뷰.md 를 읽고 13~16번만 물어봐.
   1~12번은 지식창고 만들 때 이미 답했으니 0)에서 읽은 값을 쓰고 다시 묻지 마.
   16번(공개 동의)은 항목을 하나씩 읽어주고 하나씩 답을 받아줘.

2) <패킷폴더 경로>/5_챗지피티/명함_디자인표.md 규칙대로 디자인 조합 6개를 정하고,
   무엇이 정해졌는지 한국어로 알려줘.
   이 컴퓨터에서 파이썬을 돌릴 수 있으면
   <패킷폴더 경로>/5_챗지피티/templates/card_style_pick.py 를
   JARVIS_명함/style_pick.py 로 복제해서 실행해줘.
   돌릴 수 없으면 명함_디자인표.md 3절의 "방법 2 폴백"으로 손계산하고,
   계산 과정을 표로 보여준 다음 결과를 JARVIS_명함/style.json 에 적어줘.

3) 내 홈 폴더에 JARVIS_명함 폴더를 만들고,
   <패킷폴더 경로>/5_챗지피티/templates/card_index.html 을
   그 안에 index.html 로 복제한 다음
   겹중괄호로 표시된 자리를 내 답으로 전부 채워줘.
   내가 고르지 않은 연락 수단은 그 줄을 통째로 지워줘.
   맨 아래 body 줄의 6개 값을 2)에서 정한 값으로 바꿔줘.

4) 다 만들면 페이지에 실릴 정보 목록을 보여주고, 빠뜨린 게 없는지 확인받아줘.

지식창고(JARVIS) 폴더 안의 파일은 이 명함 폴더로 절대 복사하지 마.
의뢰인 정보는 어떤 형태로도 명함에 넣지 마.
```

❗ **AI가 "파일을 찾을 수 없습니다"라고 하면**: 패킷 폴더가 앱에 연결돼 있는지 확인하세요 (→ `앱설치_설정.md` 4절 5번). 경로만 정확해도 연결이 안 돼 있으면 못 읽습니다.

**✅ 이렇게 되면 성공**: `JARVIS_명함` 폴더 안에 `index.html`이 생기고, 그 파일을 더블클릭하면 브라우저에 명함이 뜹니다.

만들어지는 폴더 모습:

```
JARVIS_명함/
├── index.html      ← 명함 본체 (이것만 있으면 명함은 완성입니다)
├── style.json      ← 디자인 결정 기록 (나중에 같은 디자인을 되살릴 때 씁니다)
├── style_pick.py   ← 디자인 계산 도구 (파이썬이 있을 때만)
└── img/            ← (선택) 배경 이미지를 쓸 때만
```

### 승인이 안 될 때 (폴더를 못 만드는 경우)

회사 보안정책 등으로 지식창고 밖에 파일을 만들지 못할 수 있습니다. 그때는 **손으로 저장**하시면 됩니다.

```
파일을 만들지 말고, 완성된 index.html 내용을 전부 화면에 출력해줘.
```

출력된 내용을 복사해서:

- **Windows**: 메모장 열기 → 붙여넣기 → 파일 → 다른 이름으로 저장 → 파일 형식을 **모든 파일**로 → 파일 이름 `index.html` → 인코딩 **UTF-8** → 바탕화면이 아닌 `JARVIS_명함` 폴더에 저장
- **Mac**: 텍스트 편집 열기 → 포맷 메뉴 → **일반 텍스트로 만들기** → 붙여넣기 → 저장 → 이름 `index.html`

⚠️ 인코딩이 UTF-8이 아니면 한글이 깨집니다. 저장 후 더블클릭해서 한글이 제대로 보이는지 꼭 확인하세요.

## 4. 디자인이 마음에 안 들 때 — 이렇게 말하세요

디자인은 인터뷰 답에서 자동으로 정해집니다(원리는 `명함_디자인표.md`). 바꾸고 싶으실 때 쓰는 문장입니다. **그대로 복사해서 말씀하시면 됩니다.**

| 이럴 때 | 이렇게 말하세요 |
|---|---|
| 전체가 마음에 안 든다 | `명함 디자인 다시 뽑아줘. 씨앗에 #2를 붙여서 계산하고 body 줄만 바꿔줘.` |
| 색만 바꾸고 싶다 | `색만 쪽빛으로 바꿔줘. body의 data-palette를 jjokbit으로.` |
| 너무 화려하다 | `강조를 차분하게 낮춰줘. data-strength를 calm으로.` |
| 너무 밋밋하다 | `강조를 선명하게 올리고 왼쪽에 색띠를 넣어줘. data-strength=vivid, data-motif=band.` |
| 가로로 넓게 쓰고 싶다 | `배치를 좌측 사이드바로 바꿔줘. data-layout을 b로.` |
| 전통적인 느낌을 원한다 | `제목 글꼴을 명조로 바꿔줘. data-type을 myeongjo로.` |
| 모서리를 각지게/둥글게 | `data-shape를 sharp로 바꿔줘.` (둥글게는 `round`) |
| 장식을 빼고 싶다 | `장식을 없애줘. data-motif를 none으로.` |

고를 수 있는 값의 전체 목록은 `명함_디자인표.md` 4~9절에 있습니다.

> ⚠️ **조합표 밖의 색을 직접 지어 달라고 하지 마세요.** 표에 있는 8가지 색은 밝은 화면·어두운 화면 양쪽에서 글자가 읽히는지 확인해 둔 값입니다. 임의로 만든 색은 어두운 화면에서 글자가 안 보이는 일이 생깁니다.

## 5. 이미지 — 배경은 그림으로, 이름은 글자로

명함에 그림을 넣고 싶으실 수 있습니다. **규칙 하나만 지키면 됩니다.**

> **이름·전화번호·직함·사무소명을 그림으로 만들지 않습니다.**
> 그림은 배경·무늬로만 쓰고, 글자는 전부 페이지의 텍스트로 넣습니다.

이유는 두 가지입니다.

1. **글자가 틀리게 그려집니다.** AI가 만든 그림 속 한글은 획이 빠지거나 다른 글자로 바뀔 수 있습니다. 이름과 전화번호가 틀린 명함은 명함이 아닙니다.
2. **무료 요금제는 이미지 생성 한도가 매우 작습니다(사실상 몇 장).** 그림에 의존하는 명함은 도중에 못 만드는 분이 생깁니다.

덤으로, 글자로 넣으면 복사·검색·읽기 프로그램(시각장애인용 화면 낭독기) 모두에서 제대로 동작합니다.

### 배경 이미지를 쓰고 싶다면

`card_index.html` 안에 **상단 띠 이미지** 자리를 미리 만들어 두었습니다. 글자가 그 위에 올라가지 않아 안전합니다.

```
명함 위쪽에 넣을 띠 이미지를 만들어줘.
글자는 하나도 넣지 말고, 가로로 긴 배경 무늬만. 가로 1200 세로 300 정도로.
느낌은 "차분한 한지 질감"으로.
만든 파일을 JARVIS_명함/img/banner.jpg 로 저장하고,
index.html 의 배너 주석을 풀어줘.
```

## 6. 링크 미리보기(og 태그) — 카카오톡에 뜨는 카드

명함 주소를 카카오톡으로 보내면 제목·설명이 담긴 **미리보기 카드**가 뜹니다. 그 카드를 만드는 것이 og 태그입니다. *og 태그: 이 페이지가 어떤 페이지인지 메신저·SNS에 알려주는 표시. 눈에 보이지 않고 파일 안에만 있습니다.*

`card_index.html`에 이미 들어 있으므로 **따로 만들 것은 없고, 값이 제대로 채워졌는지만 확인**하면 됩니다.

| 항목 | 태그 | 무엇이 되나 | 없으면 |
|---|---|---|---|
| 제목 | `og:title` | 미리보기의 굵은 글씨 | 주소만 밋밋하게 뜹니다 |
| 설명 | `og:description` | 제목 아래 회색 글 | 설명 없이 뜹니다 |
| 주소 | `og:url` | 카드를 눌렀을 때 가는 곳 | 미리보기가 안 뜨기도 합니다 |
| 그림 | `og:image` | 카드의 그림 (1200×630 권장) | 글자만 있는 작은 카드가 됩니다 |
| 종류 | `og:type` | 페이지 종류 | 대개 문제없습니다 |
| 언어 | `og:locale` | `ko_KR` | 대개 문제없습니다 |
| X(트위터) | `twitter:card` | X에서의 미리보기 모양 | 기본 모양으로 뜹니다 |

**꼭 알아 두실 것 두 가지**

- `og:url`과 `og:image`는 **인터넷 주소(`https://`로 시작)가 있어야** 동작합니다. 파일로만 쓰실 때는 주소가 없으므로 해당 없습니다 — `card_index.html`에서 이 두 줄은 주석으로 잠가 두었고, 배포한 뒤에만 풀면 됩니다.
- `og:image`에도 **이름·전화번호를 그려 넣지 마세요.** 이름은 `og:title`에 글자로 들어가므로 미리보기에 정확히 뜹니다.

### 카카오톡에서 확인하는 절차

1. 카카오톡에서 **나와의 채팅**을 엽니다.
2. 명함 주소를 보냅니다.
3. 몇 초 안에 미리보기 카드가 뜨는지 봅니다.
4. **제목·설명이 의도한 대로인지** 확인합니다.

✅ **이렇게 되면 성공**: 이름·직함·사무소명이 굵게, 한 줄 소개가 그 아래에 뜹니다.

❗ **안 뜨거나 옛 내용이 뜬다면** — 카카오가 한 번 읽어간 정보를 얼마간 저장해 두기 때문입니다(캐시). 아래를 위에서부터 시도하세요.

1. 주소 끝에 `?v=2`를 붙여서 다시 보냅니다 (예: `https://…/?v=2`). 새 주소로 인식해 다시 읽어옵니다 — **가장 확실한 방법**입니다.
2. 몇 시간~하루 뒤에 다시 보냅니다.
3. 카카오 개발자 사이트에 링크 미리보기를 다시 읽어오게 하는 점검 도구가 있습니다(로그인 필요). *도구 이름과 위치는 바뀔 수 있으니, 없으면 1·2번으로 해결하세요.*

문자메시지·인스타그램 등 다른 앱도 각자 저장해 두므로 같은 현상이 생길 수 있습니다.

## 7. 공개 직전 점검 — 이 단계를 건너뛰지 마세요

배포하기 **전에** 반드시 한 번 돌립니다. 아래를 그대로 복사해 붙여넣으세요.

```
지금 만든 명함 페이지(index.html)에 들어간 정보를 하나씩 읽어줘.
그중에 아래가 있는지 전부 점검해줘.

주민등록번호 · 자택 주소 · 가족 정보 · 생년월일
의뢰인 이름 · 의뢰인 회사명 · 사건번호 · 접수번호 · 수임 금액 · 수임 사례

하나라도 있으면 어디에 있는지 알려주고, 그 부분을 뺀 수정본을 만들어줘.
없으면 "점검 통과"라고만 답해줘.
```

- **"점검 통과"가 나오기 전에는 배포하지 않습니다.**
- 애매하면 빼는 것이 기본값입니다. 나중에 넣는 것은 쉽지만, 한번 올라간 것을 지우는 일은 어렵습니다.

### 올려도 되는 것 / 올리면 안 되는 것

| 올려도 되는 것 | 올리면 안 되는 것 |
|---|---|
| 이름·직함·사무소명 | 주민등록번호 |
| 사무소 전화·이메일 | 자택 주소 |
| 사무소 주소 (사업자 정보) | 휴대폰 번호 *(권하지 않습니다 — 사무소 번호로 대신하세요)* |
| 취급 업무 분야 | 가족·미성년자 정보 |
| 블로그·홈페이지·카카오 채널 주소 | 의뢰인 이름·회사명·사건번호·수임 사례 |
| 한 줄 소개 | 타인의 사진·로고 |

**의뢰인 관련 정보는 어떤 형태로도 넣지 않습니다.** "○○사 인허가 성공" 같은 실적 문구도 의뢰인을 특정할 수 있으므로 안 됩니다 — **행정사법 제23조(비밀엄수 의무)** 대상입니다. 대신 `화장품 수입 인허가`처럼 **분야로만** 적으세요.

> 광고 문구·표현에 관한 규정은 소속 협회의 규정을 따르세요. 이 패킷은 그 내용을 담고 있지 않습니다.

## 8. 전달하기 — 세 갈래 길

| 갈래 | 무엇 | 언제 |
|---|---|---|
| **A** | **사이트 기능으로 인터넷 주소 발급** (Codex 사이드바 «사이트») | 링크 하나로 건네고 싶을 때 — 유료 플랜 필요 (아래 「요금제 확인」) |
| **B** | **파일(PDF)로 전달** | 요금제 무관·언제나 됩니다 — 인터넷 주소가 꼭 필요한 게 아니라면 이걸로 충분합니다 |
| C | 별도 공개 저장소 + GitHub Pages *(참고)* | 인터넷 주소가 필요한데 A가 안 될 때만 |

### 갈래 A — 만든 명함을 인터넷에 올리기 (사이트 기능)

Codex 앱에는 만든 웹페이지를 인터넷 주소로 올리는 **«사이트»** 기능이 있습니다(사이드바 메뉴 실재 확인 — 2026-07-30 실측).

1. 새 작업에서 **「이 `index.html`로 웹페이지를 만들어줘」** 라고 부탁하거나, 명함을 만든 프로젝트에서 이어서 합니다.
2. **사이드바 «사이트»** 를 열면 내 명함 프로젝트가 목록에 보입니다.
3. **저장 = 초안**입니다. 저장만 해서는 인터넷에 공개되지 않습니다.
4. **게시(Publish) = 공개**입니다. 누르면 `<이름>.openai.chatgpt.site` 형태의 주소가 발급되고, 그 주소로는 **로그인 없이 누구나** 접속할 수 있습니다.
5. 내 도메인(예: `내사무소.com`)을 붙이는 **커스텀 도메인** 연결도 됩니다 — 필요해질 때 앱 안내를 따르세요.

**습관 하나 — «저장만 하고, 게시는 한 번 훑어본 뒤».** 게시된 주소는 시험판이 아니라 전부 실제로 동작하는 인터넷 페이지입니다. **7절 점검을 통과하기 전에는 게시 버튼을 누르지 않습니다.** 게시한 뒤 마음이 바뀌면 직접 내려야 하고, 그 사이 누군가 저장해 갔다면 회수할 수 없습니다.

### 요금제 확인 — 게시는 유료 플랜 기능입니다

| | 내용 |
|---|---|
| 게시(Publish) | **유료 플랜 기능** — 무료(Free)·Go 플랜은 안 됩니다 (2026-07-09 정식 제공 기준 — 무료·Go 제외 유료 플랜 제공) |
| 기준 | **2026-07 강의 시점 기준**이며 지역·베타 상태에 따라 다를 수 있습니다. **앱 안에 표시되는 안내가 최종**입니다. 게시 가능 개수 등 한도는 플랜별로 다르고 수치는 공개돼 있지 않습니다 |

**게시 버튼이 안 보이면 내 플랜이 아직 안 되는 것입니다 — 저장까지만 해 두고, 오늘은 갈래 B로 전달하세요.** 나중에 플랜이 되면 그때 게시하면 됩니다.

> 한국 계정에서 게시가 실제로 되는지는 강의 전에 강사가 확인합니다 → `실측_점검표.md` **#12** *(실측 후 확정)*

### 갈래 B — 파일로 전달 (폴백 · 요금제 무관)

인터넷에 아무것도 올리지 않습니다. 요금제와 무관하게 누구나 됩니다.

1. `index.html`을 브라우저에서 엽니다(더블클릭).
2. **인쇄 → 대상을 「PDF로 저장」** → `명함.pdf`로 저장합니다.
3. 그 PDF를 카카오톡·메일로 보냅니다.

**왜 HTML 파일이 아니라 PDF인가**: 휴대폰에서는 HTML 파일이 브라우저로 안 열리고 그냥 내려받아지는 경우가 있습니다. PDF는 어느 기기에서나 그대로 열립니다.

- 종이 명함처럼 인쇄해도 됩니다 (인쇄용 서식을 미리 넣어 두었습니다).
- 이 갈래에서는 링크 미리보기(6절)는 해당 없습니다 — 링크가 없기 때문입니다.

### 다른 방법(참고) — 갈래 C: 별도 공개 저장소 + GitHub Pages

**갈래 A(사이트 기능)가 내 계정에서 안 되는데 인터넷 주소가 꼭 필요할 때만** 씁니다. GitHub 사용법 자체는 `4_확장/GitHub_백업.md`에 있으니 **여기서는 다른 점만** 적습니다.

| 지식창고 백업(`4_확장`) | 명함(여기) |
|---|---|
| **Private**(비공개) 저장소 | **Public**(공개) 저장소 |
| 지식창고 폴더 전체를 올림 | **`JARVIS_명함` 폴더만** 올림 |
| `.gitignore`로 `서류함/` 제외 | 애초에 이 폴더에 의뢰인 자료가 없음 |
| 웹으로 보이게 하지 않음 | Settings → **Pages** → Branch를 `main`으로 → Save |

> ⚠️ **올릴 파일은 `index.html`과 `img/`뿐입니다.** `style.json`·`style_pick.py`는 내 기록용이니 올리지 마세요 — `style.json`에는 이름·사무소명·직함을 이어 붙인 문자열이 그대로 남아 있습니다.
> 명함 폴더에 `.gitignore`를 만들어 두 줄(`style.json`·`style_pick.py`)을 적거나, 올리기 전에 다른 곳으로 옮기세요.
> **"폴더를 통째로 올린다"는 습관 자체가 이 갈래에서 가장 위험한 행동입니다** — 커밋 이력은 지워도 남습니다.

- 주소는 `https://<내아이디>.github.io/<저장소이름>/` 형태로 생깁니다. 반영까지 몇 분 걸립니다.
- **지식창고 저장소와 절대 섞지 마세요.** 한 저장소를 공개로 바꾸는 순간 그 안의 모든 파일이 공개됩니다.
- 공개 저장소에는 커밋 이력도 함께 공개됩니다. 잘못 올린 파일은 지워도 이력에 남으니, **처음부터 명함 폴더만** 올리세요.

### QR 코드가 필요하면 (갈래 A·C에서만)

주소가 생긴 뒤에 만들 수 있습니다. 별도 사이트를 쓰지 않아도 됩니다.

- **Chrome**: 명함 주소를 연 다음 주소창의 **공유 아이콘 → QR 코드 만들기** *(브라우저 버전에 따라 위치가 다를 수 있습니다)*
- 만들어진 QR 이미지를 종이 명함·현수막·발표 자료에 넣으시면 됩니다.
