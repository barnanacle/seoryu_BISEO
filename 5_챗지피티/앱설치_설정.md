# Mac에서 바탕화면·다운로드·문서 폴더를 쓰지 않는 이유

macOS는 이 폴더들을 **특별히 보호**합니다. 여기를 작업 폴더로 잡으면 AI가 파일을 만들 때마다 **추가 허용 창이 계속 떠서**, 처음 쓰시는 분들이 여기서 지치고 그만두게 됩니다. 홈 폴더 바로 아래(`~/JARVIS`)에 두면 그 창이 뜨지 않습니다.

# 4. 앱에 폴더 연결하기 (로컬 프로젝트 만들기)

> **연결할 폴더는 두 개입니다.** 이 절에서 가장 중요한 문장입니다.
> **(1) 빈 `JARVIS` 폴더 — 쓰기용** (지식창고가 여기에 만들어집니다)
> **(2) 압축 푼 `install_JAARVIS` 폴더 — 읽기용** (AI가 설계도와 원본 파일을 여기서 읽습니다)
> 하나만 연결하면 **쓰기 시험은 통과했는데 그다음 단계에서 멈춥니다.** 왜 그런지 몰라 헤매는 사람이 가장 많은 지점입니다.

1. 앱을 열고 **Codex**(로컬 프로젝트) 화면으로 들어갑니다.
   - 왼쪽 목록이나 상단 메뉴에서 **Codex** 를 찾으세요. 일반 대화 화면과는 **별도의 화면**입니다.
   - 이름·위치는 버전에 따라 다릅니다. 안 보이면 아래 ❗를 보세요.
2. **폴더 열기 / 연결**을 누릅니다.
   - 메뉴 이름은 버전에 따라 다릅니다: **Open folder** / **Add project** / **폴더 추가** / **작업 폴더 선택** 등.
   - 단축키가 있는 버전도 있습니다: Mac `⌘`+`O` / Windows `Ctrl`+`O`. *(버전마다 다를 수 있어 강사가 확인 중인 항목입니다 → `실측_점검표.md` #6)*
3. 3절에서 만든 **`JARVIS` 폴더**를 고릅니다. 이것이 **기본(primary) 폴더**가 됩니다.
4. 허용을 묻는 창이 뜨면 **허용**합니다.
5. **패킷 폴더도 함께 연결합니다.**
   - 프로젝트 메뉴 → **Edit project(프로젝트 편집)** → **폴더 추가** → 압축 푼 **`install_JAARVIS`** 폴더 선택.
   - ⚠️ **기본(primary) 폴더는 반드시 `JARVIS`로 두세요.** 규칙서 `AGENTS.md`는 기본 폴더에서만 자동으로 읽힙니다.
   - 나중에 추가한 폴더는 **읽기·편집이 되는 보조 폴더**가 됩니다. 이 트랙에서는 읽기만 하면 됩니다.

✅ **이렇게 되면 성공**: 두 가지가 모두 됩니다.
