아래 10항목은 **요금제·지역·베타·운영체제에 따라 달라져서 문서만으로는 확정할 수 없었던 것들**입니다. 실제 계정으로 확인해 「결과」 칸을 채우세요. 확인 결과에 따라 강의장 시연 순서와 참가자 안내가 달라집니다.

**우선순위**: 청중 대부분이 Windows이므로 **#6이 1순위**, 개인정보 설계의 전제가 걸린 **#10**이 2순위입니다. 그다음이 **#7**(폴더 두 개 연결 — 안 되면 구축이 중간에 멈춥니다)과 **#9**(학습 사용 설정)입니다.

### 확인 뒤 할 일

- **결과가 "안 됨"인 항목** → 해당 문서의 서술을 그 자리에서 낮춰 고칩니다(대체 경로 칸대로). 문서를 그대로 두고 강의장에서 말로 때우면 참가자가 집에서 그대로 막힙니다.
- **결과가 "됨"인 항목** → `README.md` 2절 사실성 기준표의 판정과 확인일을 갱신합니다.
- 10항목 모두 확인이 끝나면 `README.md` 2절 표 아래 문구의 날짜를 바꿉니다.
- **#6 결과에 따라 함께 조정할 곳**: `앱설치_설정.md` 1절(UAC 행)·2절(관리자 승인 블록)·4절(연결 절차와 ❗분기)·`문제해결_보충.md` **C3** 전체. UAC 창이 실제로 뜨지 않는다면 그 서술을 지우고, 그 자리에 **실제로 뜨는 오류**(「이 프로젝트를 로컬 채팅에 쓸 수 없습니다」)를 올리세요.
- **#9 결과** → `앱설치_설정.md` 5.5절의 "메뉴 이름과 위치"를 실제 경로로 채웁니다.
- **#10이 "전체 색인"으로 나오면 강의 전에 반드시 설계를 고쳐야 합니다** — 서류함을 연결 폴더 안에 두는 현재 구조가 성립하지 않습니다.

# [2] 참가자 자가 점검 (설치 직후)

아래 9가지에 모두 체크되면 준비 완료입니다. 하나라도 막히면 각 항목의 안내 문서로 돌아가세요.

- [ ] **1. 내 컴퓨터가 요건에 맞는다**
  - Windows 10(버전 1809) 이상 또는 macOS 14 이상 → 확인법은 `앱설치_설정.md` 1절

- [ ] **2. ChatGPT Desktop이 설치되고 로그인되어 있다**
  - 확인 방법: 앱을 열어 아무 인사나 보내면 답이 온다.

- [ ] **3. 내 요금제로 무엇이 되는지 안다**
  - 확인 방법: `README.md` 2절 표를 읽었고, 무료 요금제면 이미지 생성·공개 주소 배포가 안 된다는 것을 안다.

- [ ] **4. 홈 폴더 아래에 빈 `JARVIS` 폴더를 만들었다**
  - 확인 방법: Mac `/Users/<내이름>/JARVIS` · Windows `C:\Users\<내이름>\JARVIS` 가 실제로 있다. **바탕화면·다운로드·문서 폴더가 아니다.**

- [ ] **5. 폴더를 두 개 연결했고, 승인 모드가 "승인 요청"이다**
  - 확인 방법 ①: AI에게 "지금 연결된 폴더에 뭐가 있어?" → 답한다.
  - 확인 방법 ②: "install_JAARVIS 폴더의 README.md 첫 줄을 읽어줘" → 실제 문장을 읽어 준다.
  - **②가 안 되면 패킷 폴더를 연결하지 않은 것입니다** — 여기서 고치고 가세요. → `앱설치_설정.md` 4절 5번

- [ ] **6. 이 패킷 ZIP을 받아 압축을 풀었고, 그 폴더 경로를 안다**
  - 확인 방법: 압축 푼 폴더 안에 `README.md`·`5_챗지피티` 등이 보이고, 경로를 복사할 수 있다. → `앱설치_설정.md` 6절

- [ ] **7. 쓰기·읽기 시험이 둘 다 통과했다 (가장 중요)**
  - 확인 방법: `붙여넣기_프롬프트.md`의 프롬프트를 붙여넣었을 때 AI가 **"파일을 만들 수 있었습니다"** 와 **설계도 첫 줄**을 둘 다 보고했다.
  - ❌ 실패했다면 여기서 멈추고 `앱설치_설정.md` 4·5절 → `문제해결_보충.md` **C2·C3**.

- [ ] **8. 사용량 한도가 있다는 것을 안다**
  - 확인 방법: 갑자기 안 될 때 고장이 아니라 한도일 수 있다는 것을 안다. → `문제해결_보충.md` **C1**

- [ ] **9. 무엇이 전송되는지 안다**
  - 확인 방법: AI가 읽는 파일 내용과 내가 채팅창에 적는 글은 **서비스 서버로 전송된다**는 것, 그래서 상담내역은 **이름·번호·금액을 가리고** 넣는다는 것을 안다. → `README.md` 7절 · `지식넣기_사용법.md` 1절
