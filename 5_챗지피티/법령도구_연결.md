# 법령 도구 붙이기 — 설치 없이 주소 한 줄

> **이 문서는 언제 보나**: Codex 앱 설치·폴더 연결을 마친 뒤(`Codex_설치_상세.md` 5절과 같은 내용을 더 자세히).
> **아래 ①은 «Codex 앱» 기준 예시입니다.** 다른 앱을 쓰셔도 원리는 같습니다(설정에 도구 한 줄 적기) — 앱마다 설정 파일 위치와 메뉴 이름만 다릅니다. ChatGPT 채팅창에서 쓰는 법은 맨 뒤에 따로 적어 두었습니다.
> **무엇을 하나**: AI가 법령·판례·행정규칙을 **직접 조회**하게 만듭니다. 지어내지 않고 원문을 가져옵니다.
> **소요**: 인증키 발급 1분 + 연결 3분. **아무것도 설치하지 않습니다.**

---

## 왜 붙이나 — 붙이기 전과 후

| | 붙이기 전 (그냥 채팅) | 붙인 뒤 |
|---|---|---|
| 조문 | 대개 정확합니다. 요즘 AI는 조문을 잘 압니다 | 원문을 **조회해서** 가져옵니다 |
| 시행일·개정 | 학습 시점 이후 개정을 모를 수 있습니다 | 현행 시행일을 함께 확인합니다 |
| 별표·서식 | 못 줍니다 | 별표·별지서식까지 가져옵니다 |
| 판례·해석례 | 요약만 | 사건번호·본문을 조회합니다 |
| 근거 제시 | "관련 법령을 확인하십시오" | **어느 조문 몇 항인지** 짚습니다 |

> 정직하게: **조문 하나 물어보는 정도는 붙이지 않아도 잘 나옵니다.** 붙이는 이유는 정확도만이 아니라
> ① 시행일·별표까지 확인되고 ② **조회한 기록이 대화와 폴더에 남아** 다음 사건에서 다시 쓰이기 때문입니다.

---

## 붙이는 방식 두 가지 — 오늘은 ①만

Codex는 설정 파일(`~/.codex/config.toml`)에 적힌 도구를 자동으로 붙입니다. 적는 방식이 두 가지입니다.

| | ① 원격 주소로 (오늘 이 방법) | ② 내 컴퓨터에서 실행 |
|---|---|---|
| 설정 | `url = "..."` 한 줄 | `command = "npx"` + 실행 인자 |
| **Node.js 설치** | **필요 없음** | 필요 |
| 인터넷 | 필요 | 필요(패키지 받을 때) |
| 난이도 | ★ | ★★★ |

**오늘은 ①만 합니다.** ②는 Node 설치에서 버전·권한·경로 문제가 자주 나서, 필요해질 때 `③ 심화` 절을 보시면 됩니다.

> 💡 **설정 파일을 직접 찾을 필요가 없습니다.** Codex에게 말로 시키면 자기 설정 파일을 자기가 고칩니다.

# ① Codex에 붙이기 (설치 없음)

## 0단계. 법제처 인증키(OC) 발급 — 무료, 1분

1. [법제처 Open API 신청 페이지](https://open.law.go.kr/LSO/openApi/guideList.do) 접속
2. 회원가입 후 로그인
3. **「Open API 사용 신청」** 클릭
4. 신청서를 작성하면 **인증키(OC)**가 발급됩니다 (예: `honggildong` 처럼 짧은 문자열)

> 💡 이 키는 비밀번호가 아니지만 남에게 보여주지 마세요. 화면 공유·발표 중에는 가리십시오.

## 1단계. Codex에게 설정을 시킵니다

Codex 대화창에 아래를 **그대로 붙여넣습니다.** `내인증키` 부분만 0단계에서 받은 키로 바꿉니다.

```
~/.codex/config.toml 파일에 아래 내용을 추가해줘.
파일이 없으면 새로 만들고, 기존 내용이 있으면 지우지 말고 맨 아래에 붙여줘.

[mcp_servers.korean-law]
url = "https://mcp.gomdori.app/law?oc=내인증키"
```

→ Codex가 **파일을 만들거나 고치겠다고 승인을 요청**합니다. **허용**을 누르세요.

## 2단계. 앱을 껐다 켭니다

설정은 앱이 켜질 때 읽습니다. **완전히 종료했다가 다시 실행**하세요.

## 3단계. 붙었는지 확인 — 이 한 줄

```
행정사법 제23조 원문 알려줘. 공포일·시행일도 같이.
```

✅ **성공**: 조문 전문 + 공포일·시행일이 나옵니다.
❗ **아직**: 도구를 쓰지 않고 일반 답변만 하면 → 설정을 아직 못 읽은 것입니다. **앱을 완전히 종료 후 재실행**하세요.
❌ **실패**: 「사용자 정보 검증 실패」류 메시지 → 인증키의 오타·앞뒤 공백을 확인하세요.
❌ **설정 파일을 못 찾겠다고 하면**: `Codex_설치_상세.md` 5-5절 「설정 파일을 직접 만들기」를 보세요.

# ② 하나 더 — 법령을 「이력」으로 보는 도구 (인증키 불필요)

**legalize-kr** — 법령·판례·행정규칙·자치법규를 **마크다운으로 모아둔 공개 저장소**입니다. 공포·시행일마다 기록을 남겨서 **「그 사이에 무엇이 바뀌었나」**에 강합니다.

- 저장소: `legalize-kr/agent-skills` · 데이터: `legalize-kr/legalize-kr`(법령) · `precedent-kr`(판례) · `admrule-kr`(행정규칙) · `ordinance-kr`(자치법규)
- **인증키가 필요 없습니다.** 공개 자료를 읽는 방식입니다.
- ⚠️ 법률 자문 도구가 아니라 **데이터 아카이브**입니다(저장소 자체가 그렇게 밝히고 있습니다). 판단은 우리가 합니다.

## 붙이는 방법 — Codex에게 시킵니다

터미널을 직접 열 필요 없이, Codex 대화창에 이렇게 부탁합니다.

```
터미널에서 아래 명령을 실행해줘.

npx skills add legalize-kr/agent-skills --skill legalize-kr
```

> 이 단계는 **건너뛰셔도 됩니다.** ①만으로 충분합니다.

## 붙은 뒤 써보기

```
Legalize-KR로 민법 제750조를 조회해줘.
```
```
근로기준법이 2020년과 2024년 사이에 어떻게 바뀌었는지 비교해줘.
```

**두 도구의 자리**
- 법령 도구(①) = **지금 조문이 무엇인가** (별표·서식까지)
- 이력 도구(②) = **언제 어떻게 바뀌었나** (부칙·경과규정·소급 판단에서 갈립니다)

# 조회 결과를 지식창고에 남기기 (①에서도 됩니다)

Codex는 **내 폴더에 파일을 쓸 수 있으므로**, 조회한 것을 그대로 지식으로 쌓을 수 있습니다.
채팅창만 쓰면 대화가 끝나며 사라지지만, 여기서는 **파일로 남아 다음 사건에서 다시 쓰입니다.**

```
화장품법 시행규칙 제8조를 조회해서, 자격요건을 표로 정리하고
wiki/ 아래에 「화장품_책임판매관리자_자격.md」로 저장해줘.
맨 위에 조회일과 시행일을 적어줘.
```

→ 다음 사건에서 AI가 그 파일을 먼저 읽고 시작합니다. **이것이 「오래 쓸수록 아는 비서」의 실제 구조입니다.**

# 실무 프롬프트 모음 (붙인 뒤 그대로 쓰십니다)

## 조문·별표 확인

```
{법령명} {조문}을 원문으로 조회해줘. 시행일과 최근 개정 여부도 같이.
삭제된 항·호가 있으면 표시해줘.
```

```
{법령명} 별표 {번호}를 조회해서 표로 정리해줘. 원문 항목을 빠뜨리지 마.
```

## 사건 검토 (자료를 붙여서)

```
[상황] 나는 {업무}를 처리하는 행정사다. 아래는 이 사건의 사실관계다.
[자료] (상담 메모를 여기 붙여넣기 — 이름·번호·금액은 가리고)

[요청]
1. 확인된 사실 / 추정 / 확인이 필요한 것으로 나눠라
2. 관련 조문을 도구로 조회해서 조문 번호와 시행일을 붙여라
3. 제출 서류 후보와, 그중 이 사건에서 빠질 수 있는 것을 표시하라
4. 마지막에 내가 직접 확인할 항목만 따로 모아라

[금지] 조회하지 않은 조문을 단정하지 마라. 확인 안 된 기한을 적지 마라.
```

## 보완 요구 대응

```
아래는 받은 보완 요구다. (원문 붙여넣기)

1. 무엇을 요구하는지 한 줄로 정리
2. 근거가 될 조문을 도구로 조회해 확인
3. 회신에 넣을 항목 목록 (자료 / 설명 / 근거조문)
4. 회신문 초안 — 내가 검토할 부분은 [[확인]]으로 표시
```

## 시점 비교 (이력 도구)

```
{법령명}이 {연도}와 {연도} 사이에 어떻게 바뀌었는지 비교해줘.
우리 사건은 {시점} 행위인데, 그때 조문으로 판단해야 하는지 알려줘.
```

## 조회 결과를 지식창고에 남기기

```
지금 조회한 내용을 wiki/ 아래에 정리해서 저장해줘.
파일명은 내용을 알 수 있게, 맨 위에 조회일·시행일·출처를 적고,
관련된 기존 페이지가 있으면 서로 링크해줘.
```

# 문제해결

| 증상 | 원인·해결 |
|---|---|
| 설정을 넣었는데 도구를 안 쓴다 | **앱을 완전히 종료 후 재실행**하세요(설정은 켜질 때 읽습니다) |
| Codex가 설정 파일을 못 만든다 | 승인을 거부했거나 홈 폴더 접근 문제. `Codex_설치_상세.md` 5-5절에서 직접 만들기 |
| 「사용자 정보 검증 실패」 | 인증키 오타·앞뒤 공백. 설정 파일의 주소를 다시 확인 |
| 조회가 됐다 안 됐다 한다 | 법제처 서버가 간헐적으로 불안정합니다. 잠시 후 다시 물어보세요 |
| 답이 너무 길어 잘린다 | "핵심 조문만" 또는 "표로" 같이 형식을 지정하세요 |
| 갑자기 아무것도 안 된다 | 사용량 한도일 수 있습니다. `문제해결_보충.md` C1 |

# 보안 — 두 가지만

1. **인증키를 화면에 노출하지 마세요.** 발표·화면 공유 때는 가립니다.
2. **신뢰할 수 있는 도구만 붙입니다.** 개발자 모드는 외부 도구를 AI에 연결하는 기능이라, 출처가 불분명한 주소를 붙이면 위험할 수 있습니다(프롬프트 인젝션). 이 문서에 적힌 두 도구는 공개 저장소에서 소스를 확인할 수 있습니다.

# (참고) ChatGPT 채팅창에서 쓰고 싶다면

이 문서의 예시는 Codex 앱 기준입니다. 같은 법령 도구를 ChatGPT 웹/앱 채팅창에서도 쓸 수 있어 적어 둡니다.

**설정 → 커넥터 → 고급 설정 → 개발자 모드** → 「커스텀 커넥터 추가」 → 이름 아무거나 + 주소 `https://mcp.gomdori.app/law?oc=본인키` → 추가한 커넥터의 「구성」에서 도구를 **「항상 사용」**으로.

| | Codex 앱 (이 트랙) | ChatGPT 채팅창 |
|---|---|---|
| 붙는 도구 | 원격 주소 + 내 컴퓨터에서 도는 것 | **원격 주소만** |
| 내 폴더 읽고 쓰기 | ✅ | ❌ |
| 조회 결과가 남는가 | ✅ **파일로 남습니다** | 대화가 끝나면 사라집니다 |
| 요금제 | ChatGPT 유료 플랜 | Plus 이상 · 개발자 모드는 베타 |

**«오래 쓸수록 내 업무를 아는 비서»는 파일이 남는 쪽에서만 성립합니다.** 그래서 이 꾸러미는 «내 폴더를 읽고 쓰는 앱»을 전제로 합니다 — Codex든, Claude Code든, 같은 일을 하는 다른 앱이든 상관없습니다.
