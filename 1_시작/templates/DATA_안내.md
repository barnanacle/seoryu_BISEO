# DATA 폴더 안내

1. 여기에 원본 자료를 **넣기만 하세요.** AI는 읽기만 하고 절대 수정하지 않습니다.
2. 하위 폴더는 자유롭게 만드세요 (예: 인허가/, 계약서/, 민원/).
3. AI가 바로 정리하는 대상은 **.md(마크다운) 파일**입니다.
4. 한글(hwp)·PDF 등은 `tools/` 폴더의 변환 도구로 md로 바꾼 뒤 정리됩니다 — AI에게 "이 파일 변환해서 정리해줘"라고 말하면 됩니다 (자세한 방법: 설치 꾸러미의 `2_도구/도구_사용법.md`).
5. 자료를 넣은 뒤 AI에게 **"자료 넣었어"** 라고 말하면 위키에 정리됩니다.
