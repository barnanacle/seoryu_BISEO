# WINDOWS 설치 안내

> **이 문서는 언제 보나:** Windows PC에서 지식창고를 처음 설치하는 날, 위에서부터 순서대로 딱 한 번 따라 하면 됩니다. (Mac 사용자는 `0_설치/MAC_설치.md`를 보세요.)

---

## 시작 전 준비물

| 준비물 | 설명 |
|---|---|
| Windows PC | Windows 10 또는 11 |
| 인터넷 연결 | 프로그램을 내려받는 데 필요합니다 |
| AI 유료 구독 | **Claude Pro 이상(권장)** 또는 **ChatGPT Plus 이상**. 무료 계정으로는 지식창고를 제대로 쓰기 어렵습니다 |
| GitHub 계정 + GitHub Desktop | 이 설치 꾸러미를 받는 데 씁니다. 아직 없다면 아래 ⓪ 단계를 보세요 |
| 시간 | 약 20~30분 |

전체 순서는 준비 + 다섯 단계입니다.

**⓪ 꾸러미 받기(GitHub Desktop) → ① Claude Desktop 설치 → ② Python 설치 → ③ setup_windows.bat 더블클릭 → ④ 성공 화면 확인 → ⑤ (문제가 있을 때만) 실패 대처 → 마지막으로 폴더 연결(이 문서 끝)**

> 폴더 위치는 따로 정할 필요가 없습니다. **GitHub Desktop이 정한 클론 위치(기본: `문서\GitHub\install_JAARVIS`)를 그대로 쓰면 됩니다.** ③에서 설치되는 도구가 이 폴더 안(`2_도구/`)에 자리 잡기 때문에, 설치가 끝난 뒤에는 폴더를 옮기지 마세요 — 옮기면 도구가 어긋날 수 있습니다.

## ⓪ 꾸러미 받기 (GitHub Desktop)

이 문서를 이미 내 PC의 `install_JAARVIS` 폴더에서 열어 보고 있다면, 이 단계는 끝난 것입니다 — ①로 넘어가세요.

아직 꾸러미를 받지 않았다면 `README.md`의 **[0] 꾸러미 받기**를 따라 하세요. 요약하면: GitHub 계정 만들기 → 협회 초대 메일의 **View invitation → Accept** → **GitHub Desktop** 설치·로그인 → **Clone Repository** 목록에서 `install_JAARVIS` 선택 → 클론(내려받기).

**이렇게 되면 성공:** 파일 탐색기에서 `문서\GitHub\install_JAARVIS` 폴더가 열리고, 그 안에 `0_설치` 폴더가 보입니다.

## ① Claude Desktop 설치·로그인

Claude Desktop은 AI 비서 '클로드'를 내 PC에서 쓰게 해 주는 프로그램입니다.

1. 인터넷 브라우저(엣지·크롬)에서 아래 주소로 이동합니다.

   ```
   https://claude.ai/download
   ```

2. **Windows용 다운로드** 버튼을 누르고, 내려받은 설치 파일을 더블클릭합니다.
3. 설치가 끝나면 Claude Desktop을 실행하고 **로그인**합니다.
   - 계정이 없다면 화면 안내에 따라 가입한 뒤, **Claude Pro 이상** 구독(유료)을 신청합니다.

**이렇게 되면 성공:** Claude Desktop을 열었을 때 가운데에 **채팅 입력창**(무엇이든 물어볼 수 있는 칸)이 보이고, 글을 입력하면 답이 옵니다.

실패 시: 로그인이 안 되면 비밀번호 재설정을 먼저 시도하고, 계속 안 되면 `3_사용법/FAQ_문제해결.md`를 보세요.

> **Claude 대신 Codex 앱을 쓰고 싶다면 (ChatGPT 구독자)**
> 이미 **ChatGPT Plus 이상**을 구독 중이라면, Claude Desktop 대신 OpenAI의 **Codex 앱**을 써도 됩니다. Codex 앱은 작업 폴더를 열면 그 폴더의 `AGENTS.md`(헌법 사본 — 내용은 CLAUDE.md와 같습니다)를 자동으로 읽습니다. 이 안내서의 나머지 부분은 Claude Desktop 기준으로 쓰여 있으니, Codex 앱을 쓰신다면 "Claude Desktop → Codex 앱", "CLAUDE.md → AGENTS.md"로 바꿔 읽으면 됩니다. 아래 ②·③ 단계는 어느 앱을 쓰든 똑같이 진행합니다. Codex 앱 설치는 `chatgpt.com`에 로그인 → Codex 메뉴의 앱 다운로드 안내를 따르고, 설치 후 ChatGPT 계정으로 로그인하면 됩니다.

## ② Python 설치

Python(파이썬)은 문서 변환 도구(PDF·한글 파일을 AI가 읽기 좋은 글자 파일로 바꿔 주는 프로그램)를 움직이는 기본 엔진입니다. 한 번만 설치해 두면 됩니다.

1. 브라우저에서 아래 주소로 이동합니다.

   ```
   https://www.python.org/downloads/
   ```

2. 화면 가운데의 노란색 **Download Python 3.x.x** 버튼을 누릅니다. (3.11 이상이면 됩니다)
3. 내려받은 설치 파일을 더블클릭합니다.
4. **★ 이 단계가 가장 중요합니다.** 설치 첫 화면에서 **아무것도 누르기 전에**, 창의 **맨 아래**를 보세요. 가운데의 큰 "Install Now" 글씨 **아래쪽**, 창 하단에 작은 체크박스가 있습니다.

   ```
   ┌────────────────────────────────────────────────┐
   │  Install Python 3.x.x                          │
   │                                                │
   │   →  Install Now        (가운데, 큰 글씨)       │
   │      Customize installation                    │
   │                                                │
   │  ☐ Use admin privileges when installing …     │
   │  ☑ Add python.exe to PATH   ← ★ 여기를 체크!  │
   └────────────────────────────────────────────────┘
   ```

   **"Add python.exe to PATH"** 왼쪽 네모를 클릭해서 **체크 표시(☑)를 켠 다음**, 그제야 **Install Now**를 누릅니다.
   (PATH란 "python이라는 이름을 컴퓨터 어디서든 알아듣게 등록하는 것"입니다. 이 체크가 꺼져 있으면 ③의 자동 설치가 Python을 못 찾습니다.)

5. 설치가 진행되고, 끝나면 완료 화면이 나옵니다.

**이렇게 되면 성공:** 마지막 화면에 **"Setup was successful"** 이라는 문구가 보입니다. Close를 눌러 닫으면 됩니다.

> **체크를 깜빡하고 설치했다면 (재설치법)**
> - **증상:** ③에서 `setup_windows.bat`을 실행했을 때 검은 창에 **"[오류] 이 컴퓨터에서 Python을 찾지 못했습니다"** 라고 나옵니다.
> - **해결(재설치):** ① 아까 내려받은 Python 설치 파일을 **다시 더블클릭** → ② **Uninstall**을 눌러 삭제 → ③ 삭제가 끝나면 설치 파일을 **한 번 더 더블클릭** → ④ 이번에는 **"Add python.exe to PATH"를 체크한 뒤** Install Now. 그다음 ③ 단계를 다시 진행하면 됩니다.

> **다른 방법:** python.org 방식이 어렵게 느껴지면, Windows의 **Microsoft Store** 앱에서 "Python 3.12"(또는 그 이상)를 검색해 설치해도 됩니다. Store 방식은 PATH 체크 과정이 아예 없어서 실수할 일이 없습니다.

## ③ setup_windows.bat 더블클릭 (자동 설치)

이제 문서 변환 도구를 자동으로 설치합니다. 여러분이 할 일은 **더블클릭 한 번**뿐입니다.

1. `install_JAARVIS` 폴더 → `0_설치` 폴더를 엽니다.
2. **setup_windows.bat** 파일을 더블클릭합니다. (확장자가 숨겨져 있으면 그냥 "setup_windows"로 보입니다 — 종류가 "Windows 배치 파일"인 것을 고르세요.)
3. 이때 파란색 경고 창이 뜰 수 있습니다. **겁내지 않으셔도 됩니다.** 이 파일이 인터넷에서 온 새 파일이라 Windows가 한 번 확인하는 것(SmartScreen이라는 보호 기능)일 뿐입니다.

   > **"Windows의 PC 보호" 파란 창이 뜨면:**
   > ① 창 안의 작은 글씨 **"추가 정보"** 를 클릭 → ② 아래에 새로 나타나는 **"실행"** 버튼을 클릭.

4. 검은 명령 창이 열리고 `[1/3] → [2/3] → [3/3]` 순서로 설치가 진행됩니다. 글자가 빠르게 올라가는 것은 정상입니다.
5. **몇 분 걸립니다. 검은 창을 닫지 말고 기다려 주세요.**

이 파일이 자동으로 해 주는 일은 세 가지입니다.

| 단계 | 하는 일 |
|---|---|
| [1/3] | Python 확인 + 도구 전용 작업 공간(venv — 다른 프로그램과 충돌하지 않는 분리된 방) 만들기 |
| [2/3] | 문서 변환 프로그램 설치 (markitdown, graphifyy, olefile) |
| [3/3] | 한글(HWP) 파일 변환 도구 rhwp 내려받기 |

## 폴더 연결 — AI 앱이 내 폴더를 읽게 하기 (마지막 단계)

AI가 파일을 읽고 쓰려면 "이 폴더를 써도 된다"고 앱에 알려줘야 합니다. **연결할 폴더는 두 개**입니다:

1. **이 설치 꾸러미(install_JAARVIS) 폴더** — AI가 설치 지침·템플릿을 읽는 곳
2. **지식창고가 만들어질 폴더** — 지금 미리 만들어 두세요: 파일 탐색기에서 내 사용자 폴더(`C:\Users\<내 이름>`)를 열고 **마우스 오른쪽 클릭 → 새로 만들기 → 폴더**로 `JARVIS` 라는 **빈 폴더**를 만듭니다.

> 왜 미리 만드나요? 구축(BOOTSTRAP) 때 AI가 이 폴더 **안에** 지식창고를 만드는데, 연결되지 않은 폴더에는 AI가 쓸 수 없기 때문입니다. 두 폴더를 처음부터 함께 연결해 두면 구축이 한 번에 끝납니다.

### 방법 1 — Claude Desktop의 폴더 기능 (있으면 가장 쉽습니다)

최신 Claude Desktop에는 내 컴퓨터의 폴더를 열어 작업하는 기능이 있습니다. 버전에 따라 이름과 위치가 조금 다르므로, 대화 입력창 옆의 **+(더하기) 버튼**이나 앱 메뉴에서 **폴더 추가 / 파일 접근** 비슷한 항목을 찾아 이 꾸러미 폴더를 선택하세요.

✅ **이렇게 되면 성공**: AI에게 "이 폴더에 어떤 파일이 있어?"라고 물으면 README.md 등 파일 목록을 답합니다.

### 방법 2 — filesystem 연결 설정 (방법 1이 없거나 안 될 때 — 확실한 방법)

1. **Node.js 설치**: 브라우저에서 `nodejs.org` 접속 → 초록색 **LTS** 버튼 → 내려받은 파일을 더블클릭해 "계속"만 눌러 설치합니다.
2. **설정 파일 열기**: `2_도구/법령검색_MCP_설정.md`의 3-1과 같은 방법입니다 (Claude Desktop 설정 → 개발자 → 설정 편집).
3. 아래 내용을 붙여넣습니다. `<폴더 경로>` 자리는 내 폴더의 실제 경로로 바꿉니다.
   (경로 얻는 법: 파일 탐색기에서 폴더를 연 뒤 **주소창을 한 번 클릭** → 나타난 경로를 복사해 붙여넣기. JSON 안에서는 경로의 `\` 를 `\\` 두 개로 적거나 `/` 로 바꿔 적으세요 — 예: `C:/Users/홍길동/JARVIS`)

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "<폴더 경로>"]
    }
  }
}
```

   이미 다른 항목(korean-law 등)이 있으면 `"filesystem": { ... }` 부분만 쉼표(,)로 이어 추가합니다. **폴더 두 개를 함께 연결하려면** `"args"` 목록 뒤쪽에 경로를 나란히 적으면 됩니다 — 예: `["-y", "@modelcontextprotocol/server-filesystem", "<꾸러미 경로>", "<지식창고 폴더 경로>"]`. 주의: 등록하는 폴더는 **실제로 존재해야** 합니다 (없는 경로를 넣으면 연결 자체가 실패합니다 — 그래서 위에서 빈 JARVIS 폴더를 미리 만들었습니다).
4. 앱을 완전히 종료(작업 표시줄 트레이의 Claude 아이콘 → 오른쪽 클릭 → 종료)한 뒤 다시 실행 → 위와 같은 ✅ 확인을 해보세요.

### Codex 앱을 쓰는 경우

Codex 앱은 **폴더 열기**로 작업 폴더를 지정하면 바로 그 폴더를 읽습니다 (별도 설정이 필요 없습니다). 지식창고 폴더를 열면 그 안의 `AGENTS.md`(헌법)를 자동으로 읽습니다.

**연결이 안 될 때**: `3_사용법/FAQ_문제해결.md`의 앱 관련 문항(Q5 부근)을 보세요.
