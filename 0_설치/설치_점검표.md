# 설치 점검표 (Mac·Windows 공용)

> **이 문서는 언제 보나요?** 설치 안내(`0_설치/MAC_설치.md` 또는 `0_설치/WINDOWS_설치.md`)를 끝낸 직후, 다음 단계로 넘어가기 전에 한 번 확인합니다.

아래 8가지에 모두 체크되면 설치 성공입니다. 하나라도 막히면 각 항목의 "확인 방법"을 다시 해 보고, 그래도 안 되면 `3_사용법/FAQ_문제해결.md`를 보세요.

- [ ] **0. GitHub Desktop으로 클론 완료** (폴더가 `문서/GitHub/install_JAARVIS` 에 있음)
  - 확인 방법: **Mac** = Finder → 문서 → GitHub → `install_JAARVIS` 폴더가 있다 / **Windows** = 파일 탐색기 → 문서 → GitHub → `install_JAARVIS` 폴더가 있다. (클론할 때 다른 위치를 직접 골랐다면 그 위치에 있으면 됩니다.) 아직이라면 `README.md`의 **[0] 꾸러미 받기**를 보세요.

- [ ] **1. AI 앱이 설치되고 로그인되어 있다** (Claude Desktop 권장, 또는 Codex 앱)
  - 확인 방법: 앱을 열면 메시지 입력칸이 보이고, 아무 인사나 보내면 답이 온다.

- [ ] **2. 유료 구독이 켜져 있다** (Claude Pro 이상 / ChatGPT Plus 이상)
  - 확인 방법: 앱의 계정·설정 메뉴에서 구독 상태가 Pro / Plus 등으로 표시된다.

- [ ] **3. Python이 설치되어 있다**
  - 확인 방법: **Mac** = Finder → 응용 프로그램에 "Python 3.x" 폴더가 있다 / **Windows** = 시작 메뉴에서 "Python"을 검색하면 나온다.

- [ ] **4. 설치 스크립트에서 "✅ 설치 완료"를 봤다**
  - 확인 방법: **Mac** = `setup_mac.command` / **Windows** = `setup_windows.bat` 실행 창 마지막에 "✅ 설치 완료"가 나왔다. 못 봤으면 다시 더블클릭 (이미 된 부분은 건너뛰고 이어서 진행됩니다).

- [ ] **5. `2_도구` 폴더 안에 `venv` 폴더가 생겼다**
  - 확인 방법: Finder(Mac) / 파일 탐색기(Windows)에서 `install_JAARVIS` → `2_도구` 를 열면 `venv` 폴더가 보인다.

- [ ] **6. `2_도구` 폴더 안에 `rhwp` 폴더가 생기고, 안에 파일이 있다**
  - 확인 방법: `2_도구` → `rhwp` 폴더를 열었을 때 비어 있지 않다. (한글 HWP 파일 변환기입니다.)

- [ ] **7. 법령검색 기능(MCP)은 별도 설정이라는 것을 알고 있다 — 지금 안 해도 됩니다**
  - 확인 방법: 필요해지면 `2_도구/법령검색_MCP_설정.md`를 따라 하면 된다. (무료 인증키 발급 포함, 약 10분)
