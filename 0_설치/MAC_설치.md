# Mac 설치 안내

> **이 문서는 언제 보나요?** Mac(맥북·아이맥)에서 지식창고를 처음 설치할 때 봅니다. 위에서 아래로 순서대로 따라 하시면 됩니다. (Windows를 쓰신다면 `0_설치/WINDOWS_설치.md`를 보세요.)

---

## 시작하기 전에 — 준비물

| 준비물 | 설명 |
|---|---|
| 인터넷이 되는 Mac | 설치 중 파일을 내려받습니다. |
| 시간 30분 | 대부분 기다리는 시간입니다. |
| AI 유료 구독 | **Claude Pro 이상**(권장) 또는 **ChatGPT Plus 이상**(Codex 앱 사용 시). 무료 계정으로는 지식창고 운영이 어렵습니다. 월 구독료가 든다는 점을 미리 알려드립니다. |
| GitHub 계정 + GitHub Desktop | 이 설치 꾸러미를 받는 데 씁니다. 아직 없다면 아래 0단계를 보세요. |

전체 순서는 준비(0단계) + 5단계 + 마무리입니다. ⓪ 꾸러미 받기 → ① AI 앱 설치 → ② Python 설치 → ③ 설치 스크립트 더블클릭 → ④ 성공 화면 확인 → ⑤ (문제가 있을 때만) 해결 → 마지막으로 **폴더 연결**(이 문서 끝).

## 0단계. 꾸러미 받기 (GitHub Desktop)

이 문서를 이미 내 Mac의 `install_JAARVIS` 폴더에서 열어 보고 있다면, 이 단계는 끝난 것입니다 — 1단계로 넘어가세요.

아직 꾸러미를 받지 않았다면 `README.md`의 **[0] 꾸러미 받기**를 따라 하세요. 요약하면: `https://github.com/barnanacle/install_JAARVIS` 를 열고 초록색 **Code → Download ZIP** → 압축 해제. (공개 저장소라 계정도 로그인도 필요 없습니다. 개선판을 클릭 한 번으로 받고 싶으면 GitHub Desktop으로 클론해 두셔도 됩니다.)

클론된 폴더 위치는 **GitHub Desktop이 정한 그대로**(기본: `문서(Documents)/GitHub/install_JAARVIS`) 쓰면 됩니다. 3단계에서 설치되는 도구가 이 폴더 안(`2_도구/`)에 자리 잡기 때문에, 설치가 끝난 뒤에는 폴더를 옮기지 마세요 — 옮기면 도구가 어긋날 수 있습니다.

✅ **이렇게 되면 성공**: Finder → 문서 → GitHub → `install_JAARVIS` 폴더가 있고, 그 안에 `0_설치` 폴더가 보입니다.

## 1단계. Claude Desktop 설치와 로그인

**Claude Desktop(클로드 데스크톱)** = AI '클로드'와 대화하는 Mac용 프로그램입니다. 지식창고의 '사서' 역할을 맡습니다.

1. 브라우저(Safari 등) 주소창에 `claude.ai/download` 를 입력해 접속합니다.
2. Mac용 다운로드 버튼을 누릅니다.
3. 내려받은 파일(`.dmg`)을 더블클릭합니다.
4. 열린 창에서 Claude 아이콘을 **'응용 프로그램(Applications)' 폴더로 드래그**합니다.
5. Finder → 응용 프로그램 → **Claude**를 실행합니다.
6. 계정으로 로그인합니다. 계정이 없으면 가입 후 **Claude Pro** 구독을 결제합니다.

✅ **이렇게 되면 성공**: Claude 창이 열리고, 아래쪽에 메시지를 입력하는 칸이 보입니다. 아무 인사나 보내 보고 답이 오면 완료입니다.

> **[대안] Codex 앱을 쓰는 경우**
> 이미 ChatGPT Plus를 구독 중이라면, Claude Desktop 대신 OpenAI의 **Codex 앱**을 써도 됩니다. Codex 앱은 작업 폴더를 열면 그 폴더 안의 `AGENTS.md`(헌법 사본)를 자동으로 읽기 때문에, 이 패킷의 지식창고와 그대로 호환됩니다. 아래 2~4단계는 어느 앱을 쓰든 동일합니다. 다만 이 안내서의 화면 설명은 Claude Desktop 기준입니다. Codex 앱 설치는 `chatgpt.com`에 로그인 → Codex 메뉴의 앱 다운로드 안내를 따르고, 설치 후 ChatGPT 계정으로 로그인하면 됩니다.

## 2단계. Python 설치

**Python(파이썬)** = 자료 변환 도구(한글·PDF 파일 → 글자 파일)가 돌아가는 데 필요한 기반 프로그램입니다. 여러분이 직접 다룰 일은 없습니다.

**먼저, 이미 설치되어 있는지 확인하세요 (프로그램 실행 없이 확인하는 법):**

- Finder → **응용 프로그램** 폴더를 엽니다.
- **"Python 3.11"**, **"Python 3.12"** 처럼 숫자가 붙은 Python 폴더가 보이면 → 이미 설치된 것입니다. **3단계로 건너뛰세요.**
- 숫자가 3.11보다 작거나(예: Python 3.9) 폴더가 없으면 → 아래 순서로 설치합니다.

**설치 순서:**

1. 브라우저에서 `python.org` 에 접속합니다.
2. 위쪽 **Downloads** 메뉴에 마우스를 올리면 나오는 **"Download Python 3.x.x"** 노란 버튼을 누릅니다. (버전 숫자는 그때그때 다릅니다 — 3.11 이상이면 됩니다.)
3. 내려받은 파일(`.pkg`)을 더블클릭합니다.
4. 설치 창에서 **"계속"**을 반복해 누르고, 암호를 물으면 Mac 로그인 암호를 입력합니다.
5. "설치가 성공적으로 완료되었습니다"가 나오면 창을 닫습니다.

✅ **이렇게 되면 성공**: Finder → 응용 프로그램에 **"Python 3.x"** 폴더가 새로 보입니다.

## 3단계. 설치 스크립트 실행 (setup_mac.command 더블클릭)

이 패킷의 `0_설치` 폴더에 있는 **`setup_mac.command`** 파일이 나머지 설치를 자동으로 해 줍니다. 하는 일은 세 가지입니다: ① Python 설치 확인 ② 자료 변환 도구 설치 ③ 한글(HWP) 변환기 내려받기. 더블클릭 한 번이면 됩니다.

다만 **처음 실행할 때** Mac이 한 번 막습니다. **Gatekeeper(게이트키퍼)** = 출처가 확인되지 않은 프로그램을 Mac이 일단 막아 주는 보안 기능입니다. 아래처럼 생긴 경고 창이 뜹니다:

```
┌──────────────────────────────────────────────┐
│            ⚠️                                 │
│  “setup_mac.command”은(는) 확인되지 않은      │
│  개발자가 배포했기 때문에 열 수 없습니다.       │
│                                              │
│        [ 휴지통으로 이동 ]      [ 취소 ]       │
└──────────────────────────────────────────────┘
```

이 창이 떠도 고장이 아닙니다. **[취소]**를 누른 뒤, 아래 순서로 열면 됩니다:

1. Finder에서 `install_JAARVIS` → `0_설치` 폴더를 엽니다.
2. `setup_mac.command` 파일 위에서 **마우스 오른쪽 클릭**을 합니다. (트랙패드는 **두 손가락으로 클릭**)
3. 나타난 메뉴 맨 위의 **"열기"**를 누릅니다.

```
   setup_mac.command
   ┌─────────────────┐
   │ 열기          ← 이걸 클릭   │
   │ 정보 가져오기       │
   │ 휴지통으로 이동     │
   │ ...             │
   └─────────────────┘
```

4. 다시 경고 창이 뜨는데, 이번에는 **[열기]** 버튼이 함께 나타납니다 → **[열기]**를 누릅니다.

```
┌──────────────────────────────────────────────┐
│  “setup_mac.command”의 개발자를 확인할 수      │
│  없습니다. 열겠습니까?                         │
│                                              │
│     [ 열기 ]  ← 이걸 클릭      [ 취소 ]        │
└──────────────────────────────────────────────┘
```

> **그래도 안 열리면 (최신 macOS 일부 버전):**
> 애플 메뉴(화면 왼쪽 맨 위 사과 모양) → **시스템 설정** → **개인정보 보호 및 보안**을 열고 아래로 내리면, "setup_mac.command이(가) 차단되었습니다"라는 문구 옆에 **[그래도 열기]** 버튼이 있습니다. 누르고 Mac 암호를 입력한 뒤, 파일을 다시 더블클릭하세요.

실행되면 **글자만 나오는 실행 창이 자동으로 열립니다** (창 이름은 '터미널'로 표시될 수 있습니다). 여러분이 무언가 입력할 필요는 없습니다. 안내 글만 읽으면서 기다리시면 됩니다. 몇 분 걸릴 수 있습니다.

두 번째 실행부터는 경고 없이 더블클릭만으로 열립니다.

## 폴더 연결 — AI 앱이 내 폴더를 읽게 하기 (마지막 단계)

AI가 파일을 읽고 쓰려면 "이 폴더를 써도 된다"고 앱에 알려줘야 합니다. **연결할 폴더는 두 개**입니다:

1. **이 설치 꾸러미(install_JAARVIS) 폴더** — AI가 설치 지침·템플릿을 읽는 곳
2. **지식창고가 만들어질 폴더** — 지금 미리 만들어 두세요: Finder에서 홈 폴더(왼쪽 사이드바의 집 아이콘)를 열고 **파일 → 새로운 폴더**로 `JARVIS` 라는 **빈 폴더**를 만듭니다.

> 왜 미리 만드나요? 구축(BOOTSTRAP) 때 AI가 이 폴더 **안에** 지식창고를 만드는데, 연결되지 않은 폴더에는 AI가 쓸 수 없기 때문입니다. 두 폴더를 처음부터 함께 연결해 두면 구축이 한 번에 끝납니다.

### 방법 1 — Claude Desktop의 폴더 기능 (있으면 가장 쉽습니다)

최신 Claude Desktop에는 내 컴퓨터의 폴더를 열어 작업하는 기능이 있습니다. 버전에 따라 이름과 위치가 조금 다르므로, 대화 입력창 옆의 **+(더하기) 버튼**이나 앱 메뉴에서 **폴더 추가 / 파일 접근** 비슷한 항목을 찾아 이 꾸러미 폴더를 선택하세요.

✅ **이렇게 되면 성공**: AI에게 "이 폴더에 어떤 파일이 있어?"라고 물으면 README.md 등 파일 목록을 답합니다.

### 방법 2 — filesystem 연결 설정 (방법 1이 없거나 안 될 때 — 확실한 방법)

1. **Node.js 설치**: 브라우저에서 `nodejs.org` 접속 → 초록색 **LTS** 버튼 → 내려받은 파일을 더블클릭해 "계속"만 눌러 설치합니다.
2. **설정 파일 열기**: `2_도구/법령검색_MCP_설정.md`의 3-1과 같은 방법입니다 (Claude Desktop 설정 → 개발자 → 설정 편집).
3. 아래 내용을 붙여넣습니다. `<폴더 경로>` 자리는 내 폴더의 실제 경로로 바꿉니다.
   (경로 얻는 법: Finder에서 폴더를 클릭 → **Option 키를 누른 채** 마우스 오른쪽 클릭 → **"…의 경로 이름 복사"** → 붙여넣기)

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "<폴더 경로>"]
    }
  }
}
```

   이미 다른 항목(korean-law 등)이 있으면 `"filesystem": { ... }` 부분만 쉼표(,)로 이어 추가합니다. **폴더 두 개를 함께 연결하려면** `"args"` 목록 뒤쪽에 경로를 나란히 적으면 됩니다 — 예: `["-y", "@modelcontextprotocol/server-filesystem", "<꾸러미 경로>", "<지식창고 폴더 경로>"]`. 주의: 등록하는 폴더는 **실제로 존재해야** 합니다 (없는 경로를 넣으면 연결 자체가 실패합니다 — 그래서 위에서 빈 JARVIS 폴더를 미리 만들었습니다).
4. 앱을 완전히 종료(**Cmd+Q**)한 뒤 다시 실행 → 위와 같은 ✅ 확인을 해보세요.

### Codex 앱을 쓰는 경우

Codex 앱은 **폴더 열기**로 작업 폴더를 지정하면 바로 그 폴더를 읽습니다 (별도 설정이 필요 없습니다). 지식창고 폴더를 열면 그 안의 `AGENTS.md`(헌법)를 자동으로 읽습니다.

**연결이 안 될 때**: `3_사용법/FAQ_문제해결.md`의 앱 관련 문항(Q5 부근)을 보세요.
