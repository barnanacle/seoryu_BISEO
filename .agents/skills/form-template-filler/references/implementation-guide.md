# 반복 서식 구현 지침

서류비서의 반복 서식은 `tools/form_engine/bin/build.py`와
`tools/form_packs/<id>/`로 구현합니다. 새 업무를 추가할 때는
[꾸러미 만들기](create-pack.md)를 따릅니다. 사건마다 `bin/build_pdf.py`를
새로 작성하는 이전 방식은 사용하지 않습니다.

## 공통 계약

- 공식 빈 PDF는 수정하지 않고 SHA-256으로 변경을 감지합니다.
- 승인한 칸 좌표만 `pack.json`에 넣습니다. 칸을 넘친 문자는 잘라내지 않고 오류를 냅니다.
- `fields.json` 한 벌을 PDF와 DOCX에 함께 사용합니다.
- 붙임은 `narrative`, `list`, `none` 중 업무에 맞는 구조를 선택합니다. 별도 생성한 내부 확인표는 공식 제출 PDF에 자동 합본하지 않습니다.
- 벡터 PDF에 입력값을 합치는 것이 기본입니다. 래스터 대체를 사용했다면 결과에 표시합니다.
- 실제 사건의 입력값·기관 원문·증빙·산출물은 공개 저장소나 스킬 폴더에 넣지 않습니다.
- 렌더링으로 공식 서식의 문구·선·쪽 수·입력값을 확인하고 행정사가 제출 전 최종 검토합니다.

기존 의견제출서용 `tools/opinion_writer/bin/build_pdf.py`는 같은 엔진을 호출하는
호환 명령입니다. 신규 서식은 꾸러미 CLI를 직접 사용합니다.
