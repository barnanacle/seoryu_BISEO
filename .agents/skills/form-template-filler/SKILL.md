# 행정처분 의견제출서 작성

이 스킬은 `tools/opinion_writer/`의 행정절차법 시행규칙 별지 제11호 의견제출서 전용입니다. 공식 서식 PDF 원본은 바꾸지 않고 확인된 값만 얹습니다. 다른 법정 서식이나 신청서에 이 작성기를 적용하지 않습니다. 실제 사건 자료와 산출물은 공개 저장소에 넣지 않습니다.

## 시작 전에

1. 현재 프로젝트의 `AGENTS.md`와 사건 폴더 지침을 먼저 읽습니다.
2. `tools/opinion_writer/AGENTS.md`와 `tools/opinion_writer/사용_시퀀스.md`를 읽고 사전통지·상담기록·공식 의견제출서 적용 여부를 확인합니다.
3. 사전통지 대응이 아닌 업무라면 이 스킬로 새 서식이나 임시 빌더를 만들지 않습니다.

## 작성 절차

1. 기관 원문과 상담기록을 대조하고, 관련 규정·대응 요건을 확인할 질문지를 먼저 만듭니다. 사용자가 정한 대응 방향은 임의로 바꾸지 않습니다.
2. 법령 조회에는 법령명·조문·별표 번호만 넣습니다. 업체명, 개인명, 주소, 연락처, 사건번호는 외부 도구나 웹 검색에 넣지 않습니다.
3. 답변을 받은 뒤 `python3 tools/opinion_writer/bin/build_pdf.py --keys`로 필드를 확인합니다. 같은 `fields.json`으로 공식 의견제출서와 상세 별지를 만듭니다. 확인되지 않은 값은 추측하지 않고 `【확인 필요】`로 남깁니다.
4. `python3 tools/opinion_writer/bin/build_pdf.py fields.json --no-open`으로 생성·검증합니다. 출력은 작성기의 `산출/`에 두고 중간 파일은 `산출/_tmp/`에 둡니다.
5. 의견제출서·별지 합본 PDF와 전체 편집용 DOCX를 확인합니다. HWP·HWPX는 별도 요청과 지원 경로가 있을 때만 만듭니다.

## 필수 검증

- 공식 서식의 선·문구·유의사항·서명란과 PDF 쪽 수를 확인합니다. 벡터 합치기인지 래스터 대체인지 보고합니다.
- 남은 `{{필드명}}`, `【확인 필요】`, 잘림·겹침·빈 페이지를 PDF와 DOCX 렌더링으로 확인합니다.
- 실제 확보한 자료만 소명자료 목록에 넣습니다.
- 결과 경로, 미확인 항목, 근거, 래스터 대체 여부를 보고하고 행정사 검토 전에는 제출 완성본이라고 표현하지 않습니다.

## 공개·공유 금지

실제 `fields.json`, 기관 원문, 상담기록, 사건별 참고본, 렌더 이미지, 중간 파일, 완성 PDF·DOCX를 공개 저장소나 스킬 폴더에 넣지 않습니다. 공유 가능한 것은 익명화한 지침, 필드명과 빈 템플릿뿐입니다.
